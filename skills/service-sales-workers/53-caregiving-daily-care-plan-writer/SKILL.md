# Caregiving Daily Care Plan Writer

Skill นี้ช่วยเขียนแผนกิจวัตรการดูแลประจำวันและบันทึกส่งต่อเวรสำหรับผู้ให้บริการดูแลส่วนบุคคล (ISCO-08 กลุ่มย่อย 53) ให้เป็นระบบ อ่านง่าย และส่งต่อระหว่างผู้ดูแลแต่ละคนได้อย่างครบถ้วน **สำคัญ: เอกสารที่ได้เป็นเครื่องมือจัดระเบียบกิจวัตรและการสื่อสารเท่านั้น ไม่ใช่แผนการรักษาทางการแพทย์ ไม่ใช้แทนคำสั่งแพทย์หรือพยาบาลวิชาชีพ**

## เมื่อไหร่ควรใช้ skill นี้

- ต้องการตารางกิจวัตรประจำวันสำหรับพี่เลี้ยงเด็กหรือผู้ช่วยครูปฐมวัย
- ต้องการแผนดูแลผู้สูงอายุที่บ้านที่ครอบคลุมมื้ออาหาร การเคลื่อนไหว และกิจกรรม
- ต้องการบันทึกส่งต่อเวรระหว่างผู้ดูแลผู้ป่วยที่บ้านหรือผู้ช่วยพยาบาล เพื่อให้คนดูแลกะถัดไปรู้สถานการณ์ต่อเนื่อง
- ต้องการเอกสารสรุปสิ่งที่ทำไปแล้วในแต่ละวันเพื่อรายงานให้ครอบครัวหรือหัวหน้างานทราบ
- ต้องการ checklist กิจวัตรที่ช่วยไม่ให้ลืมขั้นตอนสำคัญ เช่น เวลาทานอาหาร เวลาพักผ่อน หรือกิจกรรมกระตุ้นพัฒนาการ/ความจำ

## ขั้นตอนการทำงาน

### 1. ระบุตัวผู้รับการดูแลและข้อมูลพื้นฐานที่จำเป็น
สอบถามอายุ สภาพร่างกายทั่วไป (เดินเองได้/ต้องช่วยพยุง) และข้อจำกัดที่ผู้ใช้แจ้งมาเอง เช่น แพ้อาหารบางชนิด หรือกิจวัตรที่คุ้นเคย — **ห้ามสอบถามหรือสรุปข้อมูลการวินิจฉัยโรคเอง ให้ใช้เฉพาะข้อมูลที่ผู้ใช้ให้มา**

### 2. จัดโครงกิจวัตรตามช่วงเวลาในวัน
แบ่งเป็นช่วงเช้า สาย บ่าย เย็น และก่อนนอน ระบุกิจกรรมหลักของแต่ละช่วง เช่น อาหารเช้า เวลาอาบน้ำ เวลาทำกิจกรรม เวลาพักผ่อน

### 3. เขียนรายละเอียดกิจวัตรความปลอดภัยพื้นฐาน
ระบุสิ่งที่ต้องระวังตามข้อมูลที่ผู้ใช้ให้ เช่น ป้องกันการลื่นล้ม การดูแลขณะทานอาหารสำหรับผู้ที่กลืนลำบาก หรือการดูแลเด็กใกล้อุปกรณ์อันตราย โดยอ้างอิงเฉพาะสิ่งที่ผู้ใช้ระบุมาเท่านั้น

### 4. ระบุจุดที่ต้องสังเกตอาการและแจ้งเตือน
เขียนรายการอาการหรือพฤติกรรมที่ควรสังเกตและบันทึกไว้ (เช่น กินได้น้อยกว่าปกติ อารมณ์เปลี่ยนแปลง) พร้อมระบุชัดเจนว่า **หากพบอาการผิดปกติหรือมีข้อสงสัยด้านสุขภาพ ต้องแจ้งพยาบาลวิชาชีพหรือแพทย์ทันที ห้ามผู้ดูแลตัดสินใจเรื่องการรักษาหรือใช้ยาเอง**

### 5. เขียนบันทึกส่งต่อเวร (handover note)
สรุปสิ่งที่เกิดขึ้นในกะ: กิจกรรมที่ทำแล้ว ปริมาณอาหาร/น้ำที่ทาน อารมณ์และพฤติกรรมทั่วไป และสิ่งที่กะถัดไปต้องติดตามต่อ

### 6. จัดทำ checklist ประจำวันที่ผู้ดูแลกาเครื่องหมายได้
แปลงกิจวัตรทั้งหมดเป็นรายการเช็คสั้นๆ ตามลำดับเวลา เพื่อให้ผู้ดูแลติดตามได้ว่าทำครบทุกขั้นตอนหรือไม่

### 7. ตรวจทานเพื่อคัดกรองเนื้อหาทางการแพทย์ออก
อ่านทวนเอกสารทั้งหมดอีกครั้ง ตัดข้อความใดๆ ที่เข้าข่ายการวินิจฉัย การสั่งยา หรือแผนการรักษาออก แล้วแทนที่ด้วยข้อความแนะนำให้ปรึกษาผู้เชี่ยวชาญแทน

## โครงสร้าง Output

```
=== แผนกิจวัตรการดูแลประจำวัน ===
ผู้รับการดูแล: [ชื่อ/วัย ตามที่ผู้ใช้ระบุ]
ผู้จัดทำ: [ชื่อผู้ดูแล] | วันที่: [วันที่]

หมายเหตุสำคัญ: เอกสารนี้เป็นแผนกิจวัตรและการสื่อสารระหว่างผู้ดูแลเท่านั้น
ไม่ใช่แผนการรักษาทางการแพทย์ หากมีข้อสงสัยด้านสุขภาพให้ปรึกษาพยาบาล/แพทย์ทันที

1) กิจวัตรตามช่วงเวลา
   - [ ] ช่วงเช้า: [กิจกรรม]
   - [ ] ช่วงสาย: [กิจกรรม]
   - [ ] ช่วงบ่าย: [กิจกรรม]
   - [ ] ช่วงเย็น/ก่อนนอน: [กิจกรรม]

2) สิ่งที่ต้องระวัง (ตามข้อมูลที่ได้รับ)
   - [รายการ]

3) จุดสังเกตอาการที่ต้องบันทึก
   - [รายการอาการที่ต้องเฝ้าระวัง]
   - ⚠ หากพบสิ่งผิดปกติ: แจ้งพยาบาล/แพทย์ทันที ไม่ตัดสินใจเรื่องยาหรือการรักษาเอง

4) บันทึกส่งต่อเวร
   วันที่/เวลา: [วันที่-เวลา]
   กิจกรรมที่ทำแล้ว: [สรุป]
   อาหาร/น้ำที่ทาน: [สรุป]
   อารมณ์/พฤติกรรมทั่วไป: [สรุป]
   สิ่งที่กะถัดไปต้องติดตาม: [สรุป]
```

## ตัวอย่าง

**Input:** ขอแผนดูแลคุณยายวัย 78 ปี เดินได้แต่ต้องมีคนช่วยพยุง ทานอาหารอ่อนเพราะฟันไม่ค่อยดี

**Output (คร่าวๆ):**
```
1) กิจวัตรตามช่วงเวลา
   - [ ] ช่วงเช้า: ช่วยลุกจากเตียง พยุงเดินไปห้องน้ำ เตรียมอาหารเช้าเนื้อนุ่ม
   - [ ] ช่วงบ่าย: พาเดินออกกำลังกายเบาๆ ในบ้านพร้อมพยุงตลอดเวลา

2) สิ่งที่ต้องระวัง
   - เดินต้องมีคนพยุงเสมอ ป้องกันการลื่นล้ม
   - อาหารต้องนุ่ม เคี้ยวง่าย ตามที่แจ้งไว้

3) จุดสังเกตอาการที่ต้องบันทึก
   - ทานอาหารน้อยกว่าปกติผิดสังเกต หรือมีอาการเวียนศีรษะ
   - ⚠ หากพบอาการดังกล่าว แจ้งพยาบาลหรือแพทย์ทันที ไม่ให้ยาหรือวินิจฉัยเอง
```

## เกณฑ์คุณภาพ

- [ ] ใช้เฉพาะข้อมูลสุขภาพ/ข้อจำกัดที่ผู้ใช้ให้มาจริง ไม่เดาหรือสมมติอาการ การวินิจฉัย หรือขนาดยาใดๆ ทั้งสิ้น
- [ ] มีข้อความเตือนชัดเจนอย่างน้อยหนึ่งจุดว่านี่ไม่ใช่แผนการรักษาทางการแพทย์
- [ ] มีขั้นตอนบอกให้ส่งต่อพยาบาล/แพทย์ทันทีเมื่อพบความผิดปกติ
- [ ] กิจวัตรครอบคลุมครบทุกช่วงเวลาในวันตามบริบทของผู้รับการดูแล
- [ ] บันทึกส่งต่อเวรมีข้อมูลครบพอให้ผู้ดูแลคนถัดไปทำงานต่อได้ทันทีโดยไม่ต้องถามซ้ำ
- [ ] ภาษาที่ใช้เข้าใจง่าย เหมาะกับผู้ดูแลที่อาจไม่มีพื้นฐานการแพทย์
