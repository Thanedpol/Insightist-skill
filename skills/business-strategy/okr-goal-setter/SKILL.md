# OKR Goal Setter

Skill นี้ช่วยแปลงเป้าหมายธุรกิจ (ที่มักเริ่มต้นแบบกว้างๆ เช่น "อยากโตขึ้น" "อยากให้ลูกค้าพอใจมากขึ้น") ให้กลายเป็นกรอบ OKR ที่มี Objective ที่สร้างแรงบันดาลใจ และ Key Results ที่วัดผลได้จริงตามหลัก SMART เหมาะสำหรับผู้บริหาร, หัวหน้าทีม, หรือผู้ประกอบการที่ต้องการวางแผนเป้าหมายรายไตรมาส/รายปี และต้องการให้ทีมรู้ชัดว่า "สำเร็จ" หน้าตาเป็นอย่างไร

หัวใจของ skill นี้คือการไม่ปล่อยให้ Key Result หลุดเป็น "งานที่ต้องทำ" (task) แต่ต้องเป็น "ผลลัพธ์ที่วัดได้" (outcome) และต้องผ่านการเช็ค SMART อย่างเข้มงวดทุกตัว

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้มีเป้าหมายธุรกิจ/ทีมที่ยังเป็นประโยคกว้างๆ และต้องการแปลงให้วัดผลได้
- ผู้ใช้กำลังวางแผน OKR รายไตรมาสหรือรายปีสำหรับบริษัท ทีม หรือตัวเอง
- ผู้ใช้มี Key Result อยู่แล้วแต่ไม่แน่ใจว่า "วัดผลได้จริง" หรือ "ทะเยอทะยานพอ" หรือไม่
- ทีมสับสนระหว่าง "สิ่งที่ต้องทำ" (task/initiative) กับ "ผลลัพธ์ที่ต้องได้" (outcome)
- ผู้ใช้ต้องการเช็คว่า OKR ของแต่ละแผนก/ทีมย่อย เชื่อมโยงกับเป้าหมายใหญ่ของบริษัทหรือไม่

## ขั้นตอนการทำงาน

### 1. เก็บข้อมูลเป้าหมายตั้งต้น
ถามผู้ใช้:
- เป้าหมายที่อยากบรรลุคืออะไร (คำตอบเริ่มต้นมักกว้าง เช่น "อยากเพิ่มยอดขาย" — ให้รับไว้ก่อน แล้วค่อยเจาะลึกในขั้นถัดไป)
- ระยะเวลาของ OKR นี้คือกี่เดือน (ปกติ 1 ไตรมาส หรือ 1 ปี)
- นี่คือ OKR ระดับบริษัท, ระดับทีม, หรือระดับบุคคล
- มีข้อมูล baseline ปัจจุบันไหม (ตัวเลขตอนนี้อยู่ที่เท่าไหร่ ก่อนจะตั้งเป้าว่าจะไปถึงเท่าไหร่)
- ถ้าเป็น OKR ระดับทีม: OKR ของบริษัท/ระดับบนคืออะไร (เพื่อเช็ค alignment ในขั้นตอนที่ 4)

### 2. เกลากลายเป็น Objective ที่มีคุณภาพ
Objective ที่ดีต้อง:
- เป็นเชิงคุณภาพ สร้างแรงบันดาลใจ จำง่าย (ไม่ใช่ตัวเลข — ตัวเลขอยู่ใน Key Results)
- มีกรอบเวลาชัดเจนแฝงอยู่ในบริบท (เช่น "ของไตรมาสนี้")
- ตอบคำถาม "ทำไมเรื่องนี้ถึงสำคัญตอนนี้" ได้
- ถ้าผู้ใช้ให้เป้าหมายที่จริงๆ เป็น Key Result มา (เช่น "เพิ่มยอดขาย 20%") ให้ช่วยถอยกลับไปหา Objective ที่เป็นภาพใหญ่กว่า เช่น "ยอดขาย 20%" อาจเป็นผลลัพธ์ของ Objective ที่แท้จริงคือ "ขยายฐานลูกค้ากลุ่มใหม่ให้แข็งแรง"

### 3. ออกแบบ Key Results (2-5 ตัวต่อ Objective) และเช็ค SMART ทุกตัว
สำหรับแต่ละ Key Result ให้ตรวจตามเกณฑ์ SMART นี้ทีละข้อ และปรับแก้จนผ่านครบ:

- **S – Specific (เจาะจง)**: ระบุตัวชี้วัดที่ชัดเจน ไม่กำกวม (เช่น "ปรับปรุงความพึงพอใจลูกค้า" ยังไม่ specific พอ ต้องบอกว่าวัดด้วยอะไร เช่น NPS หรือ CSAT)
- **M – Measurable (วัดผลได้)**: มีตัวเลข/หน่วยวัดชัดเจน มี baseline และ target (เช่น "NPS จาก 32 เป็น 45")
- **A – Achievable (ทำได้จริง)**: ท้าทายแต่ไม่ไกลเกินจริงจนทีมรู้สึกว่าเป็นไปไม่ได้ (เทียบกับ baseline, ทรัพยากร, และเวลาที่มี)
- **R – Relevant (เกี่ยวข้อง)**: การบรรลุ KR นี้ต้องส่งผลโดยตรงต่อ Objective ไม่ใช่แค่ทำเพราะทำง่าย
- **T – Time-bound (มีกรอบเวลา)**: ระบุว่าต้องบรรลุภายในเมื่อไหร่ (สอดคล้องกับระยะเวลาของ OKR รอบนี้)

กฎเสริม: KR ต้องเป็น **outcome ไม่ใช่ task** — ถ้า KR เขียนแบบ "ทำแคมเปญการตลาด 3 แคมเปญ" ให้ถามต่อว่า "แล้ววัดความสำเร็จของแคมเปญนั้นด้วยอะไร" แล้วเปลี่ยนเป็น outcome เช่น "จำนวนลูกค้าใหม่จากแคมเปญเพิ่มเป็น X ราย"

### 4. เช็ค Alignment (ถ้าเป็น OKR ระดับทีม/บุคคล)
ตรวจว่า Objective ของทีมนี้เชื่อมโยงกับ OKR ระดับบนอย่างไร ระบุให้ชัดว่า Key Result ของทีมนี้ตัวไหนสนับสนุน Key Result ของบริษัทตัวไหน หากไม่มีความเชื่อมโยงชัดเจน ให้ flag ไว้และถามผู้ใช้ว่าจำเป็นต้องมี OKR ข้อนี้จริงหรือไม่

### 5. ประเมินจำนวนและความสมดุล
เช็คว่า:
- มี Objective ไม่เกิน 3-5 ข้อต่อรอบ (มากกว่านี้จะโฟกัสไม่ได้)
- แต่ละ Objective มี KR 2-5 ตัว (มากไปจะกระจายความสนใจ)
- มีความสมดุลระหว่าง KR เชิงการเติบโต (growth) กับ KR เชิงคุณภาพ/ความเสี่ยง (quality/guardrail) ไม่ใช่เน้นตัวเลขโตอย่างเดียวจนละเลยคุณภาพ

## โครงสร้าง Output

```
# OKR: [ชื่อทีม/บริษัท] — [ช่วงเวลา เช่น Q1 2026]

## Objective 1: [ประโยคสร้างแรงบันดาลใจ]
เหตุผลที่สำคัญตอนนี้: ...

| Key Result | Baseline | Target | เช็ค SMART |
|---|---|---|---|
| KR1: ... | ... | ... | S✅ M✅ A✅ R✅ T✅ |
| KR2: ... | ... | ... | S✅ M✅ A⚠️ R✅ T✅ (หมายเหตุ: ...) |
| KR3: ... | ... | ... | ... |

การเชื่อมโยงกับ OKR ระดับบน: ...

## Objective 2: [...]
(รูปแบบเดียวกัน)

## สรุปความสมดุลของ OKR ชุดนี้
- จำนวน Objective: ... (แนะนำ 3-5)
- สัดส่วน KR เชิง growth vs เชิง quality/guardrail: ...
- ข้อควรระวัง/สมมติฐานที่ต้องติดตามระหว่างรอบ: ...
```

## ตัวอย่าง

**Input:** "ทีม Customer Success อยากตั้งเป้าไตรมาสหน้าว่าลูกค้าต้อง happy ขึ้นและ churn น้อยลง"

**Output (คร่าวๆ):** Objective: "สร้างประสบการณ์ลูกค้าที่ทำให้พวกเขาอยากอยู่กับเราต่อ" — KR1: "NPS จาก 28 เป็น 40 ภายในสิ้น Q1" (ผ่าน SMART ครบ) — KR2: "Churn rate ลดจาก 6% เหลือ 4% ต่อเดือน ภายในสิ้น Q1" (ผ่าน SMART ครบ) — KR3 เดิมที่ผู้ใช้เสนอ "จัดอบรมทีม support 4 ครั้ง" ถูก flag ว่าเป็น task ไม่ใช่ outcome จึงปรับเป็น "เวลาตอบกลับลูกค้าเฉลี่ยลดจาก 6 ชม. เหลือ 2 ชม." แทน

## เกณฑ์คุณภาพ

- [ ] Objective เป็นประโยคเชิงคุณภาพ สร้างแรงบันดาลใจ ไม่ใช่ตัวเลข
- [ ] ทุก Key Result ผ่านเกณฑ์ SMART ครบ 5 ข้อ หรือถ้าไม่ผ่านข้อใด ต้องระบุเหตุผลและวิธีแก้ไว้ชัดเจน
- [ ] Key Result เป็น outcome ที่วัดผลได้ ไม่ใช่ task/initiative ที่แค่บอกว่า "จะทำอะไร"
- [ ] มีจำนวน Objective และ KR อยู่ในช่วงที่โฟกัสได้ (3-5 Objective, 2-5 KR ต่อตัว)
- [ ] ถ้าเป็น OKR ระดับทีม มีการเช็ค alignment กับเป้าหมายระดับบนอย่างชัดเจน
- [ ] มีความสมดุลระหว่าง KR เชิงเติบโตกับ KR เชิงคุณภาพ/ความเสี่ยง ไม่ใช่ไล่ล่าตัวเลขอย่างเดียว
