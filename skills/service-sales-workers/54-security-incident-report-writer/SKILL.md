# Security & Incident Report Writer

Skill นี้ช่วยเขียนรายงานเหตุการณ์ด้านความปลอดภัยและบันทึกส่งเวรสำหรับผู้ให้บริการด้านการป้องกันภัย (ISCO-08 กลุ่มย่อย 54) ให้เป็นเอกสารที่ครบถ้วน ตรงตามลำดับเวลาจริง และใช้อ้างอิงหรือส่งต่อได้ **สำคัญ: เอกสารที่ได้เป็นเครื่องมือช่วยบันทึกและสื่อสารเหตุการณ์เท่านั้น ไม่ใช่ขั้นตอนปฏิบัติการฉุกเฉินจริง ไม่ใช่คำแนะนำทางกฎหมาย และไม่ใช้แทนดุลยพินิจของเจ้าหน้าที่ที่ผ่านการฝึกอบรมเฉพาะทาง**

## เมื่อไหร่ควรใช้ skill นี้

- ต้องการเขียนรายงานเหตุการณ์ที่เจ้าหน้าที่รักษาความปลอดภัย (รปภ.) พบเจอระหว่างเวร เช่น บุคคลแปลกปลอมหรือทรัพย์สินเสียหาย
- ต้องการบันทึกส่งเวรระหว่างเจ้าหน้าที่รักษาความปลอดภัยแต่ละกะให้ข้อมูลต่อเนื่องกัน
- ต้องการสรุปเหตุการณ์ที่พนักงานดับเพลิงหรือเจ้าหน้าที่ช่วยชีวิตทางน้ำเข้าช่วยเหลือ เพื่อจัดเก็บเป็นบันทึกหลังเหตุการณ์
- ต้องการเอกสารบันทึกเหตุการณ์ผิดปกติสำหรับผู้คุมเรือนจำที่ต้องรายงานตามลำดับเวลา
- ต้องการโครงเรื่องรายงานที่ช่วยจัดระเบียบข้อเท็จจริงให้ครบก่อนส่งต่อผู้บังคับบัญชาหรือหน่วยงานที่เกี่ยวข้อง

## ขั้นตอนการทำงาน

### 1. รวบรวมข้อมูลพื้นฐานของเหตุการณ์
สอบถามหรือระบุ วัน เวลา สถานที่ ผู้รายงาน และประเภทเหตุการณ์เบื้องต้นตามที่ผู้ใช้แจ้งมาเท่านั้น — **ห้ามเดาหรือเติมรายละเอียดที่ผู้ใช้ไม่ได้ให้มา**

### 2. เรียบเรียงลำดับเหตุการณ์ตามเวลาจริง
จัดเรียงสิ่งที่เกิดขึ้นเป็นลำดับเวลา (timeline) ตั้งแต่สังเกตเห็นความผิดปกติครั้งแรกจนถึงการจัดการเบื้องต้นและจบเหตุการณ์ ใช้เฉพาะข้อเท็จจริงที่ผู้รายงานให้มา ไม่ใส่ความเห็นส่วนตัวหรือการคาดเดาสาเหตุ

### 3. บันทึกบุคคลและทรัพย์สินที่เกี่ยวข้อง
ระบุบุคคลที่เกี่ยวข้อง (ถ้าทราบ) ความเสียหายของทรัพย์สินที่สังเกตเห็น และพยานที่อยู่ในเหตุการณ์ โดยแยกส่วน "สิ่งที่เห็นเอง" กับ "สิ่งที่ได้ยินจากผู้อื่น" ให้ชัดเจน

### 4. ระบุการดำเนินการเบื้องต้นที่ทำไปแล้ว
เขียนสิ่งที่เจ้าหน้าที่ทำจริงระหว่างเหตุการณ์ เช่น แจ้งหัวหน้างาน โทรแจ้งหน่วยงานที่เกี่ยวข้อง หรือกันพื้นที่ **โดยไม่ระบุข้อกล่าวหาทางกฎหมาย ฐานความผิด หรือข้อสรุปว่าใครผิดใครถูก** ให้ใช้คำอธิบายเชิงข้อเท็จจริงแทน เช่น "พบบุคคลอยู่ในพื้นที่หวงห้ามโดยไม่มีบัตรอนุญาต" แทนการระบุชื่อความผิดทางกฎหมาย

### 5. ระบุจุดที่ต้องส่งต่อผู้มีอำนาจหรือหน่วยงานที่เกี่ยวข้อง
เขียนให้ชัดว่ากรณีใดต้องแจ้งตำรวจ หน่วยดับเพลิง หน่วยแพทย์ฉุกเฉิน หรือผู้บังคับบัญชาโดยตรง และย้ำว่าการตัดสินใจทางกฎหมายหรือการปฏิบัติการฉุกเฉินจริงต้องเป็นไปตามระเบียบขององค์กรและเจ้าหน้าที่ที่มีอำนาจ ไม่ใช่จากเอกสารนี้

### 6. เขียนบันทึกส่งเวร (shift handover log)
สรุปสถานการณ์ปัจจุบัน สิ่งที่ต้องเฝ้าระวังต่อ และสิ่งที่กะถัดไปต้องติดตาม ให้ผู้รับเวรเข้าใจสถานการณ์ได้ทันทีโดยไม่ต้องถามซ้ำ

### 7. ตรวจทานความถูกต้องและคัดกรองข้อความที่เป็นการคาดเดา
อ่านทวนรายงานทั้งหมด ตัดข้อความที่เป็นความเห็นส่วนตัว การกล่าวหา หรือข้อสรุปทางกฎหมายที่ไม่มีข้อมูลยืนยันออก ให้เหลือเฉพาะข้อเท็จจริงที่ตรวจสอบย้อนกลับได้

## โครงสร้าง Output

```
=== รายงานเหตุการณ์ด้านความปลอดภัย ===
สถานที่: [สถานที่] | วันที่: [วันที่] | ผู้รายงาน: [ชื่อ-ตำแหน่ง]

หมายเหตุ: เอกสารนี้เป็นบันทึกเหตุการณ์เพื่อการสื่อสารและอ้างอิงเท่านั้น
ไม่ใช่ขั้นตอนปฏิบัติการฉุกเฉินจริงหรือข้อสรุปทางกฎหมาย

1) ลำดับเหตุการณ์ (Timeline)
   [เวลา] - [สิ่งที่เกิดขึ้น]
   [เวลา] - [สิ่งที่เกิดขึ้น]

2) บุคคล/ทรัพย์สินที่เกี่ยวข้อง
   - บุคคลที่เกี่ยวข้อง: [รายละเอียดเท่าที่ทราบ]
   - ความเสียหายที่สังเกตเห็น: [รายละเอียด]
   - พยาน: [ถ้ามี]

3) การดำเนินการเบื้องต้น
   - [รายการที่ทำไปแล้ว]

4) การส่งต่อ
   - แจ้งแล้ว: [หน่วยงาน/บุคคล] เวลา [เวลา]
   - ยังต้องติดตาม: [รายการ]

5) บันทึกส่งเวร
   สถานการณ์ปัจจุบัน: [สรุป]
   สิ่งที่กะถัดไปต้องเฝ้าระวัง: [สรุป]
```

## ตัวอย่าง

**Input:** รปภ. พบประตูหลังอาคารเปิดค้างตอนตี 2 ระหว่างตรวจรอบ ไม่พบคนอยู่ในบริเวณ

**Output (คร่าวๆ):**
```
1) ลำดับเหตุการณ์
   02:00 - เดินตรวจรอบด้านหลังอาคารตามรอบปกติ พบประตูหนีไฟเปิดค้าง
   02:05 - ตรวจสอบบริเวณโดยรอบ ไม่พบบุคคลหรือร่องรอยความเสียหาย
   02:10 - ปิดประตูและแจ้งหัวหน้าเวรทางวิทยุสื่อสาร

3) การดำเนินการเบื้องต้น
   - ปิดล็อกประตูหนีไฟ และเพิ่มความถี่การตรวจรอบจุดดังกล่าวในช่วงที่เหลือของเวร

4) การส่งต่อ
   - แจ้งแล้ว: หัวหน้าเวร รปภ. เวลา 02:10
   - ยังต้องติดตาม: ตรวจสอบกล้องวงจรปิดบริเวณประตูหลังในเช้าวันถัดไป
```

## เกณฑ์คุณภาพ

- [ ] ใช้เฉพาะข้อเท็จจริงที่ผู้รายงานให้มา ไม่เดาสาเหตุ ไม่ระบุฐานความผิดทางกฎหมาย หรือข้อสรุปว่าใครผิด
- [ ] ลำดับเหตุการณ์เรียงตามเวลาจริง ระบุเวลาที่ชัดเจนในทุกจุดสำคัญ
- [ ] แยกส่วน "สิ่งที่เห็นเอง" กับ "สิ่งที่ได้ยินจากผู้อื่น" อย่างชัดเจน
- [ ] มีข้อความเตือนว่านี่ไม่ใช่ขั้นตอนปฏิบัติการฉุกเฉินจริงหรือคำแนะนำทางกฎหมาย
- [ ] ระบุชัดเจนว่ากรณีใดต้องส่งต่อผู้มีอำนาจหรือหน่วยงานภายนอก
- [ ] บันทึกส่งเวรมีข้อมูลครบพอให้ผู้รับเวรเข้าใจสถานการณ์ได้ทันที
