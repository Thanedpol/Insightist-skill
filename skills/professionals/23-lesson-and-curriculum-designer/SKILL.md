# Lesson and Curriculum Designer

Skill นี้ช่วยครูและอาจารย์ทุกระดับออกแบบแผนการสอนหรือโครงร่างหลักสูตรที่มีวัตถุประสงค์การเรียนรู้ กิจกรรม และการวัดผลสอดคล้องกันเป็นเนื้อเดียว (constructive alignment) ลดเวลาเตรียมการสอนและเพิ่มโอกาสที่ผู้เรียนจะบรรลุเป้าหมายที่ตั้งไว้จริง

## เมื่อไหร่ควรใช้ skill นี้

- อาจารย์มหาวิทยาลัยหรือครูอาชีวศึกษา ต้องออกแบบแผนการสอนรายคาบหรือโครงร่างรายวิชาทั้งเทอม
- ครูมัธยมหรือครูประถม ต้องการแผนการสอนตามหลักสูตรที่มีวัตถุประสงค์ กิจกรรม และแบบประเมินครบถ้วน
- ครูปฐมวัย ต้องการออกแบบกิจกรรมการเรียนรู้ผ่านการเล่นที่มีเป้าหมายพัฒนาการชัดเจน
- ครูการศึกษาพิเศษ ต้องการปรับแผนการสอนให้เหมาะกับผู้เรียนที่มีความต้องการพิเศษ
- ครูสอนภาษาหรือติวเตอร์ ต้องการวางโครงสร้างคอร์สหรือแผนบทเรียนเป็นชุด

## ขั้นตอนการทำงาน

### 1. ระบุบริบทและผู้เรียน
สอบถาม/ยืนยันระดับชั้น วิชา จำนวนผู้เรียน ระยะเวลาที่มี (ต่อคาบ/ต่อคอร์ส) และพื้นฐานความรู้เดิมของผู้เรียน เพื่อออกแบบให้เหมาะสมกับบริบทจริง

### 2. เขียนวัตถุประสงค์การเรียนรู้ (Learning Objectives)
เขียนวัตถุประสงค์ที่วัดผลได้จริงโดยใช้คำกริยาเชิงพฤติกรรม (เช่น อธิบายได้, คำนวณได้, วิเคราะห์ได้, สร้างได้) แทนคำกว้างๆ เช่น "เข้าใจ" หรือ "รู้จัก" จัดลำดับความยากง่ายให้เหมาะกับระดับผู้เรียน (อ้างอิงแนวคิดลำดับขั้นการเรียนรู้ เช่น จำ-เข้าใจ-ประยุกต์-วิเคราะห์-ประเมิน-สร้างสรรค์)

### 3. ออกแบบโครงสร้างเนื้อหาและลำดับการสอน
แบ่งเนื้อหาเป็นหน่วยย่อยที่เรียงลำดับจากง่ายไปยาก หรือจากพื้นฐานไปประยุกต์ ระบุเวลาที่ใช้โดยประมาณของแต่ละช่วง (นำเข้าสู่บทเรียน, สอนเนื้อหา, ฝึกปฏิบัติ, สรุป)

### 4. ออกแบบกิจกรรมการเรียนรู้ที่สอดคล้องกับวัตถุประสงค์
เลือกกิจกรรมที่ทำให้ผู้เรียนได้ฝึกทักษะตรงกับวัตถุประสงค์ในขั้นตอนที่ 2 จริง (เช่น ถ้าวัตถุประสงค์คือ "วิเคราะห์ได้" กิจกรรมควรเป็นการวิเคราะห์กรณีศึกษา ไม่ใช่แค่ฟังบรรยาย) คำนึงถึงรูปแบบการเรียนรู้ที่หลากหลายและการมีส่วนร่วมของผู้เรียน

### 5. ออกแบบวิธีการวัดและประเมินผล
กำหนดวิธีวัดผลที่ตรวจสอบได้ว่าผู้เรียนบรรลุวัตถุประสงค์แต่ละข้อหรือไม่ (เช่น แบบทดสอบ, ใบงาน, การนำเสนอ, การสังเกตพฤติกรรม) ระบุเกณฑ์การให้คะแนนหรือเกณฑ์ผ่าน/ไม่ผ่านให้ชัดเจนเท่าที่ทำได้

### 6. เตรียมสื่อและทรัพยากรการสอน
ระบุสื่อ อุปกรณ์ หรือใบงานที่ต้องเตรียมล่วงหน้า รวมถึงแนวทางปรับกิจกรรมสำหรับผู้เรียนที่มีความต้องการพิเศษหรือระดับความสามารถต่างกันในห้องเดียวกัน (differentiated instruction)

### 7. ทบทวนความสอดคล้องทั้งแผน (Alignment Check)
ตรวจว่าวัตถุประสงค์ กิจกรรม และการวัดผลสอดคล้องกันครบทุกข้อ ไม่มีวัตถุประสงค์ใดที่ไม่มีกิจกรรมหรือการประเมินรองรับ และเวลารวมของกิจกรรมไม่เกินเวลาที่มีจริง

## โครงสร้าง Output

```
=== แผนการสอน: [ชื่อวิชา/หน่วยการเรียนรู้] ===
ระดับชั้น: [...]   ระยะเวลา: [...]   จำนวนผู้เรียน: [...]

1) วัตถุประสงค์การเรียนรู้
   - [ผู้เรียนสามารถ...]
   - [ผู้เรียนสามารถ...]

2) ลำดับการสอน (Timeline)
   [เวลา | หัวข้อ/กิจกรรม | หมายเหตุ]

3) กิจกรรมการเรียนรู้
   - กิจกรรม: [...]  → สอดคล้องกับวัตถุประสงค์ข้อ [...]

4) สื่อและทรัพยากรที่ต้องเตรียม
   - [...]

5) การวัดและประเมินผล
   - วิธีวัด: [...]  → ตรวจสอบวัตถุประสงค์ข้อ [...]
   - เกณฑ์การให้คะแนน/ผ่าน: [...]

6) การปรับสำหรับผู้เรียนกลุ่มพิเศษ (ถ้ามี)
   - [...]
```

## ตัวอย่าง

**Input:** ครูมัธยมต้นต้องการแผนการสอนวิชาวิทยาศาสตร์ เรื่อง "วัฏจักรน้ำ" 1 คาบ (50 นาที) สำหรับนักเรียน ม.1

**Output (คร่าวๆ):**
- วัตถุประสงค์: "นักเรียนสามารถอธิบายขั้นตอนของวัฏจักรน้ำได้ถูกต้อง" และ "นักเรียนสามารถวาดแผนภาพวัฏจักรน้ำพร้อมระบุชื่อแต่ละขั้นตอนได้"
- ลำดับการสอน: นำเข้าสู่บทเรียนด้วยคำถามกระตุ้นความคิด 5 นาที → อธิบายเนื้อหา 15 นาที → กิจกรรมกลุ่มวาดแผนภาพ 20 นาที → สรุปและถาม-ตอบ 10 นาที
- การวัดผล: ตรวจแผนภาพวัฏจักรน้ำที่นักเรียนวาด เทียบกับเกณฑ์ที่กำหนด (ครบ 4 ขั้นตอนหลัก + ระบุทิศทางลูกศรถูกต้อง)

## เกณฑ์คุณภาพ

- [ ] วัตถุประสงค์การเรียนรู้เขียนด้วยคำกริยาที่วัดผลได้จริง ไม่ใช่คำกว้างๆ ที่ประเมินไม่ได้
- [ ] กิจกรรมทุกอย่างเชื่อมโยงกลับไปยังวัตถุประสงค์ข้อใดข้อหนึ่งได้ชัดเจน (constructive alignment)
- [ ] มีวิธีวัดผลที่ตรวจสอบได้ว่าผู้เรียนบรรลุวัตถุประสงค์แต่ละข้อหรือไม่
- [ ] เวลารวมของทุกกิจกรรมไม่เกินระยะเวลาที่มีจริง
- [ ] เนื้อหาและตัวอย่างที่ใช้ถูกต้องตามหลักวิชาที่สอน ไม่แต่งข้อเท็จจริงทางวิชาการขึ้นเองหากไม่แน่ใจ ให้ระบุว่าควรตรวจสอบกับตำรา/หลักสูตรอ้างอิง
- [ ] มีทางเลือกหรือแนวทางปรับกิจกรรมสำหรับผู้เรียนที่มีความต้องการหรือความสามารถต่างกัน
