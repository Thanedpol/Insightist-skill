# Subsistence Farming Household Planning Assistant

Skill นี้ช่วยเกษตรกร ประมง ล่าสัตว์ และเก็บของป่าเพื่อยังชีพ (ISCO-08 กลุ่ม 63) ทำแผนง่ายๆ ว่าแต่ละฤดูครัวเรือนควรปลูกอะไร จับอะไร หรือเก็บอะไรจากป่า เพื่อให้มีอาหารพอกินตลอดปี และประมาณคร่าวๆ ว่ามีส่วนเหลือขายได้บ้างหรือไม่ เขียนด้วยภาษาที่เข้าใจง่าย ไม่ใช้ศัพท์เทคนิค เหมาะกับครัวเรือนที่ทำเพื่อยังชีพเป็นหลักไม่ใช่ทำการค้าขนาดใหญ่ กลุ่มอาชีพเกษตร ป่าไม้ และประมง (ISCO-08 กลุ่มใหญ่ที่ 6) เป็นกลุ่มอาชีพที่ใหญ่ที่สุดของประเทศไทย คิดเป็น 27.40% ของกำลังแรงงานทั้งหมด (ข้อมูลสำนักงานสถิติแห่งชาติ)

## เมื่อไหร่ควรใช้ skill นี้

- เกษตรกรรายย่อยที่ปลูกพืชเพื่อกินเองในครัวเรือนเป็นหลัก ต้องการวางแผนว่าปลูกอะไรบ้างให้พอกินทั้งปี
- ชาวประมงพื้นบ้านยังชีพ ต้องการวางแผนว่าช่วงไหนจับปลาได้มาก ช่วงไหนควรพักหรือหารายได้เสริมทางอื่น
- ผู้เก็บของป่า (เห็ด หน่อไม้ น้ำผึ้งป่า) ต้องการรู้ว่าแต่ละฤดูควรเก็บอะไร และเก็บได้พอกินหรือเหลือขาย
- ครัวเรือนที่ทำทั้งปลูกพืชและเลี้ยงสัตว์เล็กน้อยผสมกัน ต้องการเห็นภาพรวมทั้งปีในแผ่นเดียว
- ต้องการรู้คร่าวๆ ว่าปีนี้พอกินเองไหม หรือควรวางแผนหารายได้เสริมช่วงไหน

## ขั้นตอนการทำงาน

### 1. ทำความเข้าใจสิ่งที่ครัวเรือนมีอยู่แล้ว
ถามง่ายๆ ว่าครัวเรือนมีที่ดินกี่ไร่/มีเรือหรือแหล่งน้ำแบบไหน/อยู่ใกล้ป่าหรือไม่ มีสมาชิกกี่คนที่ต้องกิน และเคยปลูก/จับ/เก็บอะไรมาก่อนบ้าง

### 2. เลือกสิ่งที่จะปลูก/จับ/เก็บตามฤดูกาลของพื้นที่
แนะนำตามฤดูฝน-แล้ง-หนาวของพื้นที่นั้นๆ เน้นของที่ปลูก/หาได้ง่ายในท้องถิ่นและครอบครัวกินเป็นประจำอยู่แล้ว ไม่แนะนำพืช/สัตว์แปลกใหม่ที่ต้องลงทุนสูงหรือดูแลยาก

### 3. ทำตารางง่ายๆ ว่าแต่ละเดือนทำอะไร
ใช้ตารางที่ดูปุ๊บเข้าใจปั๊บ เช่น เดือนไหนปลูก เดือนไหนดูแล เดือนไหนเก็บกิน/เก็บขาย ไม่ต้องมีศัพท์เทคนิคหรือตัวเลขซับซ้อน

### 4. ประมาณคร่าวๆ ว่าพอกินไหม
เทียบปริมาณที่คาดว่าจะได้ (นับเป็นหน่วยง่ายๆ เช่น "พอหุงกินได้กี่มื้อ/กี่วัน") กับจำนวนคนในบ้าน เพื่อให้เห็นว่าปีนี้พอกินเองหรือต้องหาซื้อเพิ่มบางช่วง

### 5. ประมาณส่วนที่อาจเหลือขาย
ระบุคร่าวๆ ว่าถ้าผลผลิตดีกว่าที่กินเอง มีส่วนไหนพอเอาไปขายหรือแลกเปลี่ยนในหมู่บ้านได้บ้าง โดยไม่ต้องระบุราคาตลาดที่แน่นอน เพราะราคาขึ้นลงตามฤดูกาลและพื้นที่

### 6. เตือนเรื่องความเสี่ยงง่ายๆ ที่ควรระวัง
เช่น ฝนแล้งกว่าปกติ น้ำท่วม หรือปีที่ของป่าออกน้อย ให้มีทางเลือกสำรอง (ปลูกอย่างอื่นเสริม หรือหารายได้เสริมช่วงนั้น) แต่ไม่ต้องลงรายละเอียดทางเทคนิค

### 7. สรุปเป็นแผ่นเดียวที่ดูง่าย
รวมทุกอย่างไว้ในหน้าเดียวหรือสองหน้า ใช้ภาษาพูดธรรมดา หลีกเลี่ยงคำศัพท์วิชาการ เพื่อให้คนในครัวเรือนทุกคนอ่านและเข้าใจได้ง่าย

## โครงสร้าง Output

```
=== แผนการผลิตอาหารครัวเรือน [ชื่อครัวเรือน/หมู่บ้าน] ===
จำนวนคนในบ้าน: [ระบุ]   พื้นที่/แหล่งทำมาหากิน: [ระบุ]

1) ปลูก/จับ/เก็บอะไรบ้างแต่ละเดือน
   [เดือน]: [สิ่งที่ปลูก/จับ/เก็บ] — [ทำอะไรช่วงนี้]

2) พอกินเองไหม
   [ชนิดอาหาร]: คาดว่าได้ประมาณ [...] พอกิน [...] เดือน/มื้อ

3) มีเหลือขายไหม
   [ชนิดอาหาร]: ถ้าได้ผลดีอาจเหลือขาย/แลกเปลี่ยนได้บ้าง (ราคาต้องดูตามฤดูกาลจริง)

4) เดือนที่ต้องระวัง / มีแผนสำรอง
   - [เดือน]: [ความเสี่ยง] → [ทางเลือกสำรอง]
```

## ตัวอย่าง

**Input:** ครอบครัว 4 คนที่จังหวัดน่าน มีที่ดิน 2 ไร่ ปลูกข้าวไร่กินเอง เก็บหน่อไม้และเห็ดจากป่าใกล้บ้านช่วงหน้าฝน อยากได้แผนทั้งปี

**Output (คร่าวๆ):**
- พ.ค.-มิ.ย.: ปลูกข้าวไร่ ดูแลแปลง / เริ่มมีหน่อไม้ให้เก็บช่วงต้นฝน
- ก.ค.-ส.ค.: ดูแลข้าวไร่ เก็บเห็ดป่าและหน่อไม้ต่อเนื่อง กินสดและเก็บบางส่วนไว้ทำหน่อไม้ดอง
- พอกินไหม: ข้าวไร่ 2 ไร่ คาดว่าได้พอหุงกินได้เกือบทั้งปีสำหรับ 4 คน หน่อไม้/เห็ดกินสดพอตลอดหน้าฝน
- เหลือขาย: หน่อไม้ดองและเห็ดส่วนเกินอาจเอาไปขายในตลาดนัดหมู่บ้านได้บ้างช่วง ก.ค.-ส.ค.
- เดือนที่ต้องระวัง: หากฝนมาช้าในเดือน พ.ค. ข้าวไร่อาจปลูกช้ากว่าปกติ ควรเตรียมพืชผักอายุสั้นปลูกเสริมไว้ก่อน

## เกณฑ์คุณภาพ

- [ ] ใช้ภาษาง่าย เป็นกันเอง ไม่มีศัพท์เทคนิคหรือศัพท์วิชาการเกษตร/ประมง
- [ ] มีตารางรายเดือนที่ครอบคลุมทั้งปีและสอดคล้องกับฤดูกาลจริงของพื้นที่
- [ ] มีการประมาณคร่าวๆ ว่าพอกินเองหรือไม่ และเหลือขายได้ประมาณไหน โดยไม่ยัดเยียดตัวเลขที่แม่นยำเกินจริง
- [ ] มีข้อเตือนความเสี่ยงและทางเลือกสำรองอย่างน้อย 1 จุดในแผน
- [ ] **ห้ามระบุราคาตลาดที่แน่นอน ปริมาณสารเคมี/ยาสัตว์ หรือตัวเลขกฎระเบียบที่เจาะจงขึ้นมาเอง** หากจำเป็นให้ระบุว่าต้องสอบถามเกษตรอำเภอหรือหน่วยงานท้องถิ่นในพื้นที่แทน
- [ ] เนื้อหาสั้น กระชับ พอดีอ่านจบในไม่กี่นาที เหมาะกับการพิมพ์หรือส่งต่อในครัวเรือน
