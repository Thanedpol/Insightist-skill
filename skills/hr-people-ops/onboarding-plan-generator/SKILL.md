# Onboarding Plan Generator

Skill นี้ช่วย HR, หัวหน้าทีม หรือ Manager ที่กำลังจะรับพนักงานใหม่เข้าทีม สร้างแผน Onboarding ที่มีโครงสร้างชัดเจนตามกรอบเวลา 30-60-90 วัน ทำให้พนักงานใหม่เข้าใจบทบาทของตัวเองได้เร็วขึ้น รู้สึกได้รับการต้อนรับอย่างเป็นระบบ และช่วยลดความเสี่ยงที่พนักงานใหม่จะลาออกในช่วงทดลองงานเพราะไม่มีทิศทางที่ชัดเจน

## เมื่อไหร่ควรใช้ skill นี้

- มีพนักงานใหม่กำลังจะเข้าทำงานในตำแหน่งที่ระบุ และยังไม่มีแผน onboarding ที่เป็นระบบ
- หัวหน้าทีมต้องการกรอบเวลาที่ชัดเจนว่าพนักงานใหม่ควรทำอะไรใน 30, 60, 90 วันแรก
- ต้องการปรับปรุงแผน onboarding เดิมที่มีอยู่ให้ครอบคลุมและวัดผลได้ดีขึ้น
- ต้องการ onboarding plan ที่ต่างกันตามตำแหน่งงาน (เช่น Sales ต่างจาก Engineer)
- HR ต้องการ template กลางที่ปรับใช้ได้กับหลายตำแหน่งในองค์กร
- ต้องการวางแผนเพื่อลดอัตราการลาออกของพนักงานใหม่ในช่วงทดลองงาน (early attrition)

## ขั้นตอนการทำงาน

1. **รวบรวมข้อมูลตำแหน่งและทีม** — สอบถามหรือสรุปจากข้อมูลที่ผู้ใช้ให้มา: ชื่อตำแหน่ง, ทีม/แผนก, หัวหน้างานโดยตรง, เป้าหมายหลักของตำแหน่งนี้ในการทำงาน 90 วันแรก และเครื่องมือ/ระบบที่ต้องเรียนรู้
2. **กำหนดเป้าหมายภาพรวมของแต่ละช่วง (Phase Goal)** — แบ่งเป็น 3 ช่วงตามหลักการมาตรฐาน:
   - **30 วันแรก (Learn):** เรียนรู้ระบบ วัฒนธรรมองค์กร กระบวนการทำงาน และทำความรู้จักทีม
   - **60 วัน (Contribute):** เริ่มลงมือทำงานจริง รับผิดชอบงานย่อยได้ด้วยตัวเอง มีส่วนร่วมในโปรเจกต์
   - **90 วัน (Own):** ทำงานได้อย่างอิสระ รับผิดชอบผลลัพธ์เต็มรูปแบบ และเริ่มเสนอไอเดียปรับปรุงงาน
3. **ออกแบบกิจกรรมและ Task ในแต่ละช่วง** — ระบุกิจกรรมที่จับต้องได้ในแต่ละสัปดาห์หรือแต่ละช่วง เช่น การอบรม, การประชุม 1:1 กับหัวหน้างาน, การมอบหมายงานทดลอง (shadow task), หรือโปรเจกต์แรกที่ควรรับผิดชอบ
4. **กำหนดตัวชี้วัดความสำเร็จ (Success Metrics) ต่อช่วง** — ระบุสิ่งที่ใช้วัดว่าพนักงานใหม่ "ผ่าน" ช่วงนั้นแล้ว เช่น เข้าใจ workflow หลักได้ครบ, ส่งงานชิ้นแรกได้ตรงเวลา, ได้รับ feedback เชิงบวกจากทีม
5. **ระบุบทบาทผู้สนับสนุน (Support Roles)** — ระบุว่าใครมีบทบาทช่วยเหลือพนักงานใหม่ในแต่ละช่วง เช่น Hiring Manager, Buddy/Mentor, ฝ่าย HR เพื่อให้พนักงานใหม่รู้ว่าจะถามใครเมื่อติดปัญหา
6. **กำหนดจุด Check-in ที่ชัดเจน** — วางกำหนดการประชุม 1:1 หรือ feedback session ในแต่ละช่วง (เช่น สัปดาห์ที่ 1, วันที่ 30, วันที่ 60, วันที่ 90) เพื่อประเมินความคืบหน้าและปรับแผนตามความจำเป็น
7. **ประกอบร่างเป็นแผน Onboarding ฉบับสมบูรณ์** ตามโครงสร้าง Output ด้านล่าง
8. **แจ้งเตือนเรื่องกฎหมายแรงงานและช่วงทดลองงาน** — ปิดท้ายด้วยข้อความเตือนเสมอว่าระยะเวลาทดลองงาน สิทธิ์การบอกเลิกจ้างในช่วงทดลองงาน และข้อกำหนดอื่นๆ เกี่ยวกับพนักงานใหม่แตกต่างกันไปตามกฎหมายแรงงานของแต่ละประเทศ ให้ผู้ใช้ตรวจสอบกับฝ่ายกฎหมายหรือ HR ท้องถิ่นก่อนนำไปใช้จริง

## ตัวอย่าง

**Input ที่ผู้ใช้ให้มา:**
> "ต้องการแผน onboarding สำหรับตำแหน่ง Content Marketing Specialist ทีม Marketing เริ่มงานสัปดาห์หน้า"

**Output คร่าวๆ ที่ควรได้:**
แผน Onboarding เต็มรูปแบบตามโครงสร้างด้านบน โดย Phase 1 เน้นการเรียนรู้ Brand Guideline, เครื่องมือที่ทีมใช้ (เช่น Canva, Content Calendar), และทำความรู้จักทีม Marketing/Sales; Phase 2 เริ่มให้ผลิตคอนเทนต์จริงภายใต้การตรวจสอบของหัวหน้าทีม; Phase 3 ให้รับผิดชอบแคมเปญคอนเทนต์อย่างน้อย 1 แคมเปญด้วยตัวเอง พร้อมตัวชี้วัดความสำเร็จและจุด Check-in ในแต่ละช่วงตามโครงสร้าง

## เกณฑ์คุณภาพ

- [ ] แบ่งช่วงเวลา 30-60-90 วันชัดเจน แต่ละช่วงมีเป้าหมายที่แตกต่างกันตามระดับความรับผิดชอบที่เพิ่มขึ้น
- [ ] กิจกรรม/Task เจาะจงกับตำแหน่งงานและทีมจริง ไม่ใช่ template ทั่วไปที่ใช้ได้กับทุกตำแหน่ง
- [ ] ทุกช่วงมีตัวชี้วัดความสำเร็จที่วัดผลได้ ไม่ใช่คำกว้างๆ เช่น "ทำงานได้ดีขึ้น"
- [ ] ระบุบทบาทผู้สนับสนุน (หัวหน้างาน, Buddy, HR) ชัดเจนในแต่ละกิจกรรม
- [ ] มีจุด Check-in/1:1 กำหนดไว้ล่วงหน้าในทุกช่วง
- [ ] มีหมายเหตุเตือนเรื่องกฎหมายแรงงานและช่วงทดลองงานทุกครั้งที่ส่ง Output
