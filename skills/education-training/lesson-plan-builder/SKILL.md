# Lesson Plan Builder

Skill นี้ช่วยครู วิทยากร ฝ่าย L&D และผู้ออกแบบหลักสูตร สร้างแผนการสอนที่พร้อมใช้งานจริงจากแค่ "หัวข้อ" และ "กลุ่มผู้เรียน" ที่ผู้ใช้บอกมา โดยแปลงหัวข้อกว้างๆ ให้กลายเป็นแผนที่มี learning objective ชัดเจน กิจกรรมที่เหมาะกับเวลาและระดับผู้เรียน และวิธีวัดผลที่จับต้องได้ ไม่ใช่แค่ list หัวข้อเนื้อหาลอยๆ

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้ขอ "แผนการสอน" หรือ "lesson plan" สำหรับวิชา คอร์ส หรือ workshop ใดๆ
- ผู้ใช้บอกหัวข้อ + กลุ่มผู้เรียน (เช่น เด็ก ป.4, พนักงานใหม่, ผู้บริหารระดับกลาง) แล้วขอให้ช่วยออกแบบการสอน
- ผู้ใช้ต้องการแปลง course outline หรือหัวข้อในหลักสูตรให้เป็นแผนสอนรายครั้ง/รายคาบ
- ผู้ใช้ขอ "กิจกรรมการเรียนรู้" หรือ "learning activity" ประกอบเนื้อหาที่มีอยู่แล้ว
- ผู้ใช้เป็นครู วิทยากรฝึกอบรม หรือ instructional designer ที่ต้องส่งแผนสอนให้ผู้บริหาร/โรงเรียนอนุมัติ
- ผู้ใช้พูดว่า "จะสอนเรื่องนี้ยังไงดี", "ช่วยวาง session นี้หน่อย", "ออกแบบ workshop เรื่อง..."

## ขั้นตอนการทำงาน

1. **เก็บข้อมูลตั้งต้น** — สอบถามหรืออนุมานจากข้อความผู้ใช้ให้ได้อย่างน้อย 4 อย่าง: (1) หัวข้อ/เนื้อหาหลัก (2) กลุ่มผู้เรียน (อายุ ระดับความรู้ บริบท เช่น นักเรียนมัธยม, พนักงานฝ่ายขาย) (3) ระยะเวลาที่มี (เช่น 1 ชั่วโมง, ครึ่งวัน, 3 คาบ) (4) เป้าหมายปลายทาง (สิ่งที่อยากให้ผู้เรียนทำได้หลังจบ) — ถ้าข้อมูลไม่ครบ ให้สมมติฐานที่สมเหตุสมผลและระบุไว้ชัดเจนว่าเป็นสมมติฐาน แทนที่จะหยุดถามซ้ำ
2. **ตั้ง Learning Objective** — เขียน objective 2-4 ข้อ โดยใช้หลัก Bloom's Taxonomy เลือก action verb ที่วัดผลได้ (เช่น อธิบาย, เปรียบเทียบ, ประยุกต์ใช้, วิเคราะห์, ออกแบบ) หลีกเลี่ยงคำกว้างๆ ที่วัดไม่ได้ เช่น "เข้าใจ" หรือ "รู้จัก" เพียงลำพัง — ให้ต่อท้ายด้วยเงื่อนไขว่าเข้าใจ/รู้จักอะไรและแสดงออกอย่างไร
3. **แบ่งโครงสร้างบทเรียนตามเวลา** — แบ่งเป็น 3 ช่วงหลักเสมอ: เปิด (Warm-up/Hook) — เนื้อหาหลัก (Instruction + Practice) — ปิด (Wrap-up/Assessment) จัดสัดส่วนเวลาให้เหมาะกับกลุ่มผู้เรียน (เด็กเล็กต้องมีกิจกรรมสั้นและสลับบ่อย ผู้ใหญ่ในองค์กรเน้น case/practice)
4. **ออกแบบกิจกรรมการเรียนรู้** — สำหรับแต่ละช่วง ระบุกิจกรรมที่เป็นรูปธรรม (ไม่ใช่แค่ "บรรยาย") เช่น discussion, role-play, group work, case study, quiz สั้น, hands-on practice พร้อมระบุว่าใช้เวลาเท่าไร และ ผู้สอนต้องเตรียมอะไร
5. **กำหนดวิธีประเมินผล** — ระบุว่าจะรู้ได้อย่างไรว่าผู้เรียนบรรลุ objective เช่น แบบฝึกหัดท้ายคาบ, exit ticket, การสังเกตพฤติกรรมระหว่างกิจกรรม, quiz สั้น — ให้เชื่อมโยงกับ objective ข้อใดข้อหนึ่งเสมอ อย่าใส่ลอยๆ
6. **ระบุสื่อ/อุปกรณ์ที่ต้องเตรียม** — list สื่อการสอน อุปกรณ์ หรือเอกสารประกอบที่จำเป็น เพื่อให้ผู้สอนเตรียมตัวล่วงหน้าได้
7. **ประกอบร่างเป็นแผนฉบับสมบูรณ์** ตามโครงสร้าง Output ด้านล่าง แล้วตรวจสอบด้วยเกณฑ์คุณภาพก่อนส่งมอบ

## โครงสร้าง Output

```
# แผนการสอน: [ชื่อหัวข้อ]

**กลุ่มผู้เรียน:** [ระบุ]
**ระยะเวลา:** [ระบุ]
**จำนวนผู้เรียน (ถ้าทราบ):** [ระบุ หรือ "ไม่ระบุ"]

## Learning Objectives
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ:
1. [Objective 1 — ใช้ action verb ที่วัดผลได้]
2. [Objective 2]
3. [Objective 3]

## โครงสร้างบทเรียน

### 1. เปิดบทเรียน ([X] นาที)
- กิจกรรม: [รายละเอียด]
- วัตถุประสงค์ของช่วงนี้: [เชื่อมโยงความสนใจ/ปูพื้นสู่เนื้อหาหลัก]

### 2. เนื้อหาหลัก ([X] นาที)
- หัวข้อย่อยที่ 1: [เนื้อหา] — กิจกรรม: [รายละเอียด] ([X] นาที)
- หัวข้อย่อยที่ 2: [เนื้อหา] — กิจกรรม: [รายละเอียด] ([X] นาที)
- (เพิ่มตามความเหมาะสม)

### 3. ปิดบทเรียน / สรุป ([X] นาที)
- กิจกรรม: [รายละเอียด]
- การประเมินผล: [วิธีวัดว่าบรรลุ objective]

## สื่อ/อุปกรณ์ที่ต้องเตรียม
- [รายการ]

## หมายเหตุสำหรับผู้สอน
- [ข้อควรระวัง จุดที่ผู้เรียนมักสับสน หรือแนวทางปรับสำหรับกลุ่มที่เร็ว/ช้ากว่าคาด]
```

## การปรับให้เหมาะกับกลุ่มผู้เรียนต่างกัน

- **เด็กเล็ก/ประถม** — กิจกรรมต้องสั้น (5-10 นาทีต่อกิจกรรม) สลับรูปแบบบ่อย ใช้ภาพและการเคลื่อนไหวเป็นหลัก ลด lecture ให้เหลือน้อยที่สุด
- **วัยรุ่น/มัธยม** — เชื่อมโยงกับชีวิตจริงหรือสิ่งที่เขาสนใจ เปิดพื้นที่ให้ถกเถียง/แสดงความเห็น ใส่การแข่งขันหรือเกมเพื่อกระตุ้นความสนใจได้
- **ผู้ใหญ่ในองค์กร (พนักงาน/ผู้บริหาร)** — ใช้หลัก Adult Learning: เริ่มจากปัญหาหรือสถานการณ์จริงในงานก่อนเสมอ เน้น case study และ practice มากกว่า theory เคารพเวลาและประสบการณ์เดิมของผู้เรียน หลีกเลี่ยงน้ำเสียงแบบสอนเด็ก
- **กลุ่มผสมระดับความรู้** — เตรียมกิจกรรมสำรอง 2 ระดับ (ง่าย/ยาก) หรือออกแบบงานที่ปรับความยากได้ในตัว เพื่อไม่ให้คนที่รู้อยู่แล้วเบื่อ หรือคนที่ยังไม่รู้ตามไม่ทัน

## ตัวอย่าง

**Input:** "ช่วยทำแผนการสอนเรื่อง 'การตั้งเป้าหมาย SMART' ให้พนักงานใหม่ ใช้เวลา 1 ชั่วโมง"

**Output (คร่าวๆ):**
- Objective: อธิบายองค์ประกอบของ SMART Goal ได้ครบ 5 ข้อ / เขียนเป้าหมายงานของตนเองในรูปแบบ SMART ได้อย่างน้อย 1 ข้อ
- เปิด (10 นาที): ให้พนักงานเขียนเป้าหมายเดิมของตนเอง 1 ข้อ แล้วถามว่าเป้าหมายนั้น "วัดได้" หรือไม่
- เนื้อหาหลัก (35 นาที): อธิบายกรอบ SMART ทีละตัวอักษรพร้อมตัวอย่างจากงานจริง จากนั้นให้จับคู่ช่วยกันแปลงเป้าหมายเดิมของตนเองให้เป็น SMART
- ปิด (15 นาที): แต่ละคนนำเสนอเป้าหมาย SMART ของตนเอง 1 ประโยค + ผู้สอนให้ feedback สั้นๆ เป็น exit assessment

## ข้อควรระวัง

- อย่าใส่กิจกรรมแน่นเกินเวลาที่มีจริง ให้เผื่อเวลา buffer อย่างน้อย 5-10% ของเวลาทั้งหมดสำหรับคำถามและความล่าช้า
- อย่าเขียน objective มากเกิน 4 ข้อในบทเรียนสั้น (ต่ำกว่า 2 ชั่วโมง) เพราะจะสอนได้ไม่ลึกพอ
- ถ้าผู้ใช้ให้เนื้อหาที่มีอยู่แล้ว (เช่น สไลด์ หรือเอกสาร) ให้ยึดเนื้อหานั้นเป็นหลักในการออกแบบกิจกรรม ไม่สร้างเนื้อหาใหม่ที่ขัดแย้งกัน
- ระบุระยะเวลาเป็นตัวเลขเสมอ (นาที) ไม่ใช้คำกว้างๆ เช่น "สักพัก" หรือ "นานพอสมควร"

## เกณฑ์คุณภาพ

- [ ] Learning objective ทุกข้อใช้ action verb ที่วัดผลได้ ไม่ใช้คำกว้างเช่น "เข้าใจ" ลอยๆ
- [ ] สัดส่วนเวลาในแต่ละช่วงรวมกันตรงกับระยะเวลาที่ผู้ใช้ระบุ
- [ ] มีกิจกรรมที่ผู้เรียนลงมือทำ ไม่ใช่แค่บรรยายฝ่ายเดียวตลอดคาบ
- [ ] มีวิธีประเมินผลที่เชื่อมโยงกลับไปยัง objective อย่างน้อย 1 ข้อ
- [ ] กิจกรรมและภาษาที่ใช้เหมาะสมกับกลุ่มผู้เรียนที่ระบุ (อายุ/ระดับ/บริบทงาน)
- [ ] มีรายการสื่อ/อุปกรณ์ที่ผู้สอนต้องเตรียมล่วงหน้าอย่างชัดเจน
