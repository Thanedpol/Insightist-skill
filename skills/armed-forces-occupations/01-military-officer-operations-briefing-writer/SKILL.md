# Military Officer Operations-Briefing Writer

Skill นี้ช่วยนายทหารสัญญาบัตร (เช่น นายพล นายพัน นายร้อย ในกองทัพบก กองทัพเรือ และกองทัพอากาศ) จัดทำเอกสารบรรยายสรุปงานประจำวันและรายงานสถานะหน่วยในรูปแบบมาตรฐาน เพื่อใช้สื่อสารข้อมูลเชิงบริหารจัดการ เช่น จำนวนกำลังพล ตารางนัดหมาย และสถานะความพร้อมของอุปกรณ์ ให้ผู้บังคับบัญชาหรือหน่วยเหนือรับทราบได้อย่างเป็นระบบ ครบถ้วน และอ่านง่าย

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้เป็นนายทหารสัญญาบัตรระดับนายพล นายพัน หรือนายร้อย ที่ต้องการแบบฟอร์มบันทึกข้อความบรรยายสรุปประจำวัน/ประจำสัปดาห์
- ต้องการจัดทำรายงานสถานะหน่วย (unit status report) เช่น จำนวนกำลังพลปฏิบัติหน้าที่ ลากิจ ลาป่วย และตารางนัดหมายของหน่วย
- ต้องการแบบฟอร์มรายงานความพร้อมของยุทโธปกรณ์ในเชิงธุรการ (เช่น จำนวนเครื่องมือที่ใช้งานได้/ส่งซ่อม) โดยไม่ลงรายละเอียดเชิงเทคนิคหรือขีดความสามารถ
- ต้องการเตรียมวาระการประชุมหรือสรุปนัดหมายสำหรับการประชุมหน่วยประจำสัปดาห์
- **ข้อควรทราบ:** skill นี้จำกัดเฉพาะงานเอกสารธุรการและการบริหารจัดการหน่วยทั่วไปเท่านั้น (ตารางเวร จำนวนกำลังพล รูปแบบรายงานสถานะ) ไม่ใช่การวางแผนเชิงยุทธการ ไม่เกี่ยวข้องกับข้อมูลลับ หรือข้อมูลความมั่นคงที่ละเอียดอ่อนใดๆ ทั้งสิ้น

## ขั้นตอนการทำงาน

### 1. รวบรวมข้อมูลพื้นฐานของหน่วย
สอบถามหรือรับข้อมูล: ชื่อหน่วยงาน (แบบทั่วไป ไม่ต้องระบุรหัสหน่วยจริง), ช่วงเวลาที่รายงาน (วัน/สัปดาห์), ผู้รับรายงาน (ผู้บังคับบัญชา/หน่วยเหนือ), และผู้จัดทำ

### 2. จัดโครงสร้างหัวบันทึกข้อความ (Memo Header)
ระบุรูปแบบมาตรฐาน: เรื่อง, เรียน, อ้างถึง (ถ้ามี), วันที่, ชั้นความเร็ว (ปกติ/ด่วน) — ใช้รูปแบบธุรการทั่วไป ไม่ใช้ชั้นความลับ

### 3. สรุปสถานะกำลังพล
จัดทำตารางสรุปจำนวนกำลังพลตามหมวดหมู่: ปฏิบัติหน้าที่ปกติ, ลาพักร้อน/ลากิจ/ลาป่วย, อบรม/ราชการนอกหน่วย, รวมยอดทั้งหมด — เป็นตัวเลขสรุปเชิงบริหารเท่านั้น

### 4. สรุปตารางนัดหมายและกิจกรรมประจำวัน/สัปดาห์
ระบุนัดหมายเชิงธุรการ เช่น การประชุม การตรวจเยี่ยม การฝึกอบรมตามปกติ พร้อมเวลาและสถานที่แบบทั่วไป

### 5. รายงานสถานะความพร้อมของทรัพยากร (เชิงธุรการ)
สรุปจำนวนยานพาหนะ/อุปกรณ์สำนักงาน/สิ่งอำนวยความสะดวกที่ใช้งานได้ปกติ กับที่อยู่ระหว่างซ่อมบำรุงหรือขอเบิก — เป็นตัวเลขสรุประดับบริหารจัดการ ไม่ลงรายละเอียดขีดความสามารถหรือตำแหน่งที่ตั้งเชิงยุทธการ

### 6. สรุปประเด็นเสนอผู้บังคับบัญชา
ระบุประเด็นที่ต้องการการอนุมัติหรือการตัดสินใจเชิงบริหาร เช่น การจัดสรรงบประมาณ การอนุมัติลา หรือการจัดกำลังพลไปราชการ

### 7. ตรวจทานความครบถ้วนและรูปแบบ
ตรวจสอบว่าเอกสารมีหัวข้อครบตามแบบฟอร์ม ตัวเลขสอดคล้องกัน และไม่มีเนื้อหาที่เกินขอบเขตงานธุรการ

## โครงสร้าง Output

```
บันทึกข้อความ
ส่วนราชการ: [ชื่อหน่วยแบบทั่วไป]
ที่: [เลขที่หนังสือ]                          วันที่: [วัน/เดือน/ปี]
เรื่อง: บรรยายสรุปสถานะหน่วยประจำ[วัน/สัปดาห์]
เรียน: [ผู้บังคับบัญชา/ตำแหน่ง]

1. สถานะกำลังพล
   - ปฏิบัติหน้าที่ปกติ: [จำนวน] นาย
   - ลากิจ/ลาป่วย/ลาพักร้อน: [จำนวน] นาย
   - อบรม/ราชการนอกหน่วย: [จำนวน] นาย
   - รวมยอดกำลังพลทั้งหมด: [จำนวน] นาย

2. ตารางนัดหมาย/กิจกรรมประจำ[วัน/สัปดาห์]
   [เวลา] - [กิจกรรม] - [สถานที่]

3. สถานะความพร้อมทรัพยากร (เชิงธุรการ)
   - ใช้งานได้ปกติ: [จำนวน/รายการ]
   - อยู่ระหว่างซ่อมบำรุง/ขอเบิก: [จำนวน/รายการ]

4. ประเด็นเสนอเพื่อพิจารณา/อนุมัติ
   - [ประเด็นที่ 1]
   - [ประเด็นที่ 2]

ลงชื่อ: [ยศ ชื่อ นามสกุล ผู้จัดทำ]
ตำแหน่ง: [ตำแหน่ง]
```

## ตัวอย่าง

**Input:** ผู้ใช้เป็นนายพันผู้บังคับกองพันสมมติ ต้องการรายงานสถานะหน่วยประจำสัปดาห์ให้ผู้บังคับการกรม กำลังพลรวม 320 นาย ปฏิบัติหน้าที่ปกติ 290 นาย ลา 20 นาย อบรมนอกหน่วย 10 นาย มีนัดประชุมประจำสัปดาห์วันพุธ 09:00 น.

**Output (ตัวอย่างบางส่วน):**
```
1. สถานะกำลังพล
   - ปฏิบัติหน้าที่ปกติ: 290 นาย
   - ลากิจ/ลาป่วย/ลาพักร้อน: 20 นาย
   - อบรม/ราชการนอกหน่วย: 10 นาย
   - รวมยอดกำลังพลทั้งหมด: 320 นาย

2. ตารางนัดหมาย
   วันพุธ 09:00 น. - ประชุมประจำสัปดาห์ - ห้องประชุมกองพัน
```

## เกณฑ์คุณภาพ

- [ ] มีหัวบันทึกข้อความครบตามรูปแบบธุรการมาตรฐาน (เรื่อง เรียน วันที่)
- [ ] ตัวเลขกำลังพลรวมกันได้ครบ ไม่มีข้อมูลขาดหรือเกิน
- [ ] ตารางนัดหมายระบุเวลาและสถานที่ชัดเจน อ่านแล้วนำไปใช้ได้ทันที
- [ ] ใช้ชื่อหน่วยและสถานที่แบบทั่วไป ไม่ระบุรหัสหน่วยจริงหรือข้อมูลระบุตัวตนเฉพาะเจาะจง
- [ ] ต้องไม่มีเนื้อหาเชิงยุทธวิธี ข้อมูลลับ หรือข้อมูลความมั่นคงที่ละเอียดอ่อน — จำกัดเฉพาะงานเอกสารธุรการ/บริหารจัดการกำลังพลทั่วไปเท่านั้น
- [ ] ภาษาที่ใช้เป็นทางการ กระชับ เหมาะกับการรายงานต่อผู้บังคับบัญชา
