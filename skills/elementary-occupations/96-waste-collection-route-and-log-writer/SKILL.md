# Waste Collection Route and Log Writer

Skill นี้ช่วยพนักงานเก็บขยะและคนงานพื้นฐานอื่นๆ (ISCO-08 กลุ่ม 96 — Skill Level 1) เขียนเช็คลิสต์เส้นทางที่ต้องไปเก็บขยะหรือทำงานประจำวัน พร้อมสมุดบันทึกกิจกรรมง่ายๆ ว่าไปจุดไหน ทำอะไร เจอปัญหาอะไรบ้าง ช่วยไม่ให้พลาดจุดที่ต้องไป และมีหลักฐานงานที่ทำแล้วในแต่ละวัน

## เมื่อไหร่ควรใช้ skill นี้

- พนักงานเก็บขยะต้องการเส้นทางเก็บขยะประจำวันที่ไม่ตกหล่นจุดไหน
- คนคัดแยกขยะ/ซาเล้งต้องการบันทึกจุดที่ไปเก็บและปริมาณ/ประเภทขยะที่ได้แต่ละวัน
- คนกวาดถนนต้องการตารางโซนถนนที่ต้องกวาดตามช่วงเวลา
- พนักงานส่งเอกสารและส่งของต้องการเส้นทางส่งของตามลำดับจุดที่ใกล้-ไกล
- พนักงานอ่านมาตรวัดต้องการเช็คลิสต์บ้าน/มิเตอร์ที่ต้องอ่านค่าให้ครบทุกจุด
- คนเฝ้าประตูหรือคนเติมสินค้าบนชั้นวางต้องการบันทึกกิจกรรมประจำวันแบบสั้นๆ

## ขั้นตอนการทำงาน

### 1. รวบรวมจุดหรือพื้นที่ที่ต้องไปทั้งหมด
สอบถามหรือรวบรวมรายชื่อถนน/ซอย/บ้านเลขที่/จุดวางถังขยะ/จุดส่งของทั้งหมดที่ต้องไปในวันนั้น

### 2. จัดลำดับเส้นทางให้ไม่ย้อนกลับ
เรียงจุดตามลำดับที่เดินทางสะดวกที่สุด ไม่วนย้อนไปมา เริ่มจากจุดใกล้ที่จอดรถ/จุดเริ่มต้นไปยังจุดไกลสุด แล้ววนกลับ

### 3. กำหนดเวลาโดยประมาณต่อจุดหรือต่อโซน
ระบุเวลาที่คาดว่าจะถึงแต่ละจุด/โซน เพื่อให้วางแผนงานทั้งวันได้ และรู้ว่าช้ากว่ากำหนดหรือไม่

### 4. ระบุสิ่งที่ต้องทำหรือสังเกตที่แต่ละจุด
บอกให้ชัดว่าถึงจุดนั้นแล้วต้องทำอะไร เช่น เก็บถังขยะและนำกลับมาวางที่เดิม, อ่านค่ามาตรวัดและจดตัวเลข, ส่งของแล้วให้ผู้รับเซ็นรับ

### 5. ทำช่องบันทึกปัญหาหรือสิ่งผิดปกติระหว่างทาง
เตรียมช่องว่างให้จดสิ่งผิดปกติ เช่น ถังขยะเต็มล้น มาตรวัดอ่านค่ายาก บ้านที่ไม่มีคนรับของ เพื่อรายงานหัวหน้างานภายหลัง

### 6. ทำสมุดบันทึกกิจกรรมสรุปท้ายวัน
สรุปว่าวันนี้ทำครบกี่จุดจากทั้งหมด ใช้เวลารวมเท่าไหร่ มีจุดไหนทำไม่ครบและต้องตามทำวันถัดไป

### 7. สรุปเป็นเอกสารพกติดตัวหรือติดรถ
รวมเส้นทางและช่องบันทึกเป็นแผ่นเดียว พับพกกระเป๋าหรือติดในรถเก็บขยะ/รถส่งของได้

## โครงสร้าง Output

```
=== เส้นทาง/บันทึกงานประจำวัน [ชื่อทีม/สาย] ===
วันที่: [ระบุ]  ผู้ปฏิบัติงาน: [ระบุ]  เวลาเริ่ม: [ระบุ]

1) ลำดับเส้นทาง
   ลำดับ | จุด/ถนน/ที่อยู่ | เวลาโดยประมาณ | สิ่งที่ต้องทำ | ทำแล้ว (กา)
   1 | [จุด] | [เวลา] | [งาน] | [ ]
   2 | [จุด] | [เวลา] | [งาน] | [ ]

2) บันทึกปัญหา/สิ่งผิดปกติระหว่างทาง
   - [จุดที่พบ]: [ปัญหาที่เจอ]

3) สรุปท้ายวัน
   ทำครบ [X] จาก [Y] จุด | เวลารวมที่ใช้: [ระบุ]
   จุดที่ยังไม่เสร็จ ต้องตามวันถัดไป: [ระบุ]
```

## ตัวอย่าง

**Input:** พนักงานเก็บขยะสายหนึ่งต้องเก็บ 5 ซอยในตำบล เริ่มงาน 05:00 น. ซอย 3 มักมีถังขยะล้นทุกครั้ง

**Output (คร่าวๆ):**
- เส้นทาง: 1) ซอย 1 เวลา 05:00 เก็บถังขยะหน้าบ้านเลขคู่ [ ], 2) ซอย 2 เวลา 05:15 [ ], 3) ซอย 3 เวลา 05:30 เก็บถังขยะและตรวจถังที่มักล้น [ ], 4) ซอย 4 เวลา 05:50 [ ], 5) ซอย 5 เวลา 06:05 [ ]
- ปัญหาที่พบ: ซอย 3 ถังขยะล้นเกินความจุอีกครั้ง ควรแจ้งหัวหน้างานให้เพิ่มถังหรือรอบเก็บ
- สรุปท้ายวัน: ทำครบ 5 จาก 5 จุด เวลารวม 1 ชั่วโมง 20 นาที ไม่มีจุดค้าง

## เกณฑ์คุณภาพ

- [ ] มีลำดับเส้นทางที่ไม่ย้อนกลับไปมา ประหยัดเวลาเดินทาง
- [ ] ระบุสิ่งที่ต้องทำที่แต่ละจุดชัดเจน ไม่ใช่แค่ชื่อสถานที่ลอยๆ
- [ ] มีช่องกาเสร็จ/ยังไม่เสร็จให้ใช้งานหน้างานได้จริง
- [ ] มีช่องบันทึกปัญหา/สิ่งผิดปกติแยกจากลำดับงานปกติ
- [ ] มีสรุปท้ายวันบอกจำนวนจุดที่ทำครบและจุดที่ต้องตามงานต่อ
- [ ] ภาษาที่ใช้สั้น กระชับ อ่านระหว่างเดินงานได้ทันทีโดยไม่ต้องหยุดคิด
