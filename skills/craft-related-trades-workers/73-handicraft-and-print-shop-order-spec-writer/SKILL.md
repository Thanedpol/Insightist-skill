# Handicraft and Print Shop Order Spec Writer

Skill นี้ช่วยช่างหัตถกรรมและช่างพิมพ์แปลงคำสั่งงานจากลูกค้าให้เป็นใบสเปกงานสั่งทำที่ชัดเจน ครบทั้งวัสดุ ขนาด รายละเอียดลวดลาย/ดีไซน์ และกำหนดเวลา เพื่อลดความเข้าใจผิดระหว่างช่างกับลูกค้า และใช้เป็นเอกสารอ้างอิงตลอดกระบวนการผลิตจนถึงส่งมอบ

## เมื่อไหร่ควรใช้ skill นี้

- ช่างทำเครื่องประดับ/ทองรูปพรรณต้องการทำใบสเปกงานสั่งทำแหวน/สร้อยตามดีไซน์ลูกค้า
- ช่างเครื่องปั้นดินเผาหรือช่างทอผ้าต้องการระบุขนาด สี ลวดลาย ก่อนเริ่มงาน
- ช่างจักสานหรือช่างแกะสลักต้องการยืนยันรายละเอียดชิ้นงานกับลูกค้าก่อนตัดวัสดุจริง
- ช่างทำเครื่องดนตรีต้องการระบุสเปกไม้ ขนาด และเสียงที่ลูกค้าต้องการ
- ช่างเรียงพิมพ์หรือช่างเข้าเล่มต้องการใบสเปกงานพิมพ์ (ขนาด กระดาษ สี จำนวนหน้า การเข้าเล่ม) ก่อนส่งเข้าโรงพิมพ์

## ขั้นตอนการทำงาน

### 1. รับบรีฟจากลูกค้า
บันทึกความต้องการของลูกค้าด้วยคำพูดของลูกค้าเองก่อน แล้วค่อยแปลงเป็นสเปกทางเทคนิค รวบรวมภาพอ้างอิง (ถ้ามี) และวัตถุประสงค์การใช้งานชิ้นงาน

### 2. กำหนดวัสดุ
ระบุชนิดวัสดุหลักและวัสดุประกอบให้ชัดเจน (เช่น ชนิดโลหะและเปอร์เซ็นต์ทอง, ชนิดดิน, เส้นใยผ้า, ชนิดไม้, ชนิดกระดาษและแกรม) พร้อมเหตุผลที่เลือกวัสดุนั้น (ความทนทาน งบประมาณ ความต้องการลูกค้า)

### 3. กำหนดขนาดและสัดส่วน
ระบุขนาดจริงเป็นหน่วยวัดมาตรฐาน (ซม./มม./นิ้ว) พร้อมค่าความคลาดเคลื่อนที่ยอมรับได้ ถ้าเป็นงานพิมพ์ให้ระบุขนาดหน้ากระดาษ ขอบตัดตก (bleed) และจำนวนหน้า

### 4. กำหนดรายละเอียดลวดลาย/ดีไซน์
อธิบายลวดลาย สี เทคนิคการขึ้นรูปหรือตกแต่ง (เช่น ลงยา, สลัก, ทอลาย, พิมพ์ระบบใด) ให้ละเอียดพอที่ช่างคนอื่นอ่านแล้วทำตามได้โดยไม่ต้องถามซ้ำ

### 5. กำหนดขั้นตอนการผลิตและระยะเวลา
แบ่งงานเป็นขั้นตอนหลัก (ขึ้นรูป → ตกแต่ง → เก็บงาน → ตรวจสอบ) พร้อมระยะเวลาโดยประมาณของแต่ละขั้นตอน และวันที่ส่งมอบที่ตกลงกับลูกค้า

### 6. ประเมินราคาและเงื่อนไข
สรุปราคาต่อชิ้นหรือราคารวม เงื่อนไขมัดจำ และเงื่อนไขการแก้ไขงาน (แก้ได้กี่ครั้ง แก้หลังผลิตแล้วมีค่าใช้จ่ายเพิ่มหรือไม่)

### 7. ยืนยันสเปกกับลูกค้าก่อนเริ่มผลิต
สรุปสเปกทั้งหมดให้ลูกค้ายืนยันเป็นลายลักษณ์อักษรก่อนตัด/ขึ้นรูปวัสดุจริง เพื่อป้องกันความเสียหายจากการทำงานผิดสเปก

## โครงสร้าง Output

```
=== ใบสเปกงานสั่งทำ ===
ลูกค้า: [ชื่อ]   ประเภทงาน: [เครื่องประดับ/เครื่องปั้น/ทอผ้า/แกะสลัก/งานพิมพ์ ฯลฯ]
วันที่รับออเดอร์: [วันที่]   กำหนดส่งมอบ: [วันที่]

1) วัสดุ
   - [วัสดุหลัก]: [รายละเอียด/เกรด/สี]
   - [วัสดุประกอบ]: [รายละเอียด]

2) ขนาด/สัดส่วน
   [ขนาดจริง พร้อมค่าความคลาดเคลื่อนที่ยอมรับได้]

3) รายละเอียดลวดลาย/ดีไซน์
   [คำอธิบายละเอียด + อ้างอิงภาพ (ถ้ามี)]

4) ขั้นตอนการผลิตและระยะเวลา
   - [ขั้นตอน 1]: [ระยะเวลา]
   - [ขั้นตอน 2]: [ระยะเวลา]

5) ราคาและเงื่อนไข
   ราคารวม: [บาท]   มัดจำ: [บาท/%]
   เงื่อนไขแก้ไขงาน: [...]

ยืนยันโดยลูกค้า: [ ] ใช่ วันที่ [...]
```

## ตัวอย่าง

**Input:** ลูกค้าสั่งทำแหวนทองคำ 96.5% ฝังพลอยไพลิน ไซส์ 55 ลายเถาวัลย์ ต้องการภายใน 15 วัน

**Output (คร่าวๆ):**
- วัสดุ: ทองคำแท่ง 96.5%, พลอยไพลินเจียระไนกลม 1 เม็ด ขนาด 4 มม.
- ขนาด: ไซส์แหวน 55 (เส้นผ่านศูนย์กลางวงใน 17.5 มม.) ค่าคลาดเคลื่อน ±0.2 มม.
- ลวดลาย: ลายเถาวัลย์พันรอบวง ขัดผิวเงา ฝังพลอยตรงกลางแบบหนามเตย
- ขั้นตอน: หลอม-ขึ้นรูป (3 วัน) → แกะลาย (5 วัน) → ฝังพลอย (2 วัน) → ขัดเงา-ตรวจสอบ (2 วัน) รวม 12 วัน เผื่อ 3 วันสำรอง
- ราคารวม 28,500 บาท มัดจำ 50%

## เกณฑ์คุณภาพ

- [ ] ระบุวัสดุ ขนาด และลวดลายละเอียดพอให้ช่างคนอื่นทำตามได้โดยไม่ต้องถามซ้ำ
- [ ] มีค่าความคลาดเคลื่อนของขนาดที่ยอมรับได้ระบุชัดเจน
- [ ] แบ่งขั้นตอนการผลิตพร้อมระยะเวลาที่รวมกันแล้วไม่เกินกำหนดส่งมอบ
- [ ] ระบุเงื่อนไขราคา มัดจำ และการแก้ไขงานอย่างชัดเจน
- [ ] มีขั้นตอนยืนยันสเปกกับลูกค้าก่อนเริ่มผลิตจริงเสมอ
- [ ] ไม่เดาข้อมูลที่ลูกค้ายังไม่ได้ระบุ (เช่น สี ขนาดที่แน่นอน) ให้ระบุว่าต้องสอบถามเพิ่มก่อนยืนยันสเปก
