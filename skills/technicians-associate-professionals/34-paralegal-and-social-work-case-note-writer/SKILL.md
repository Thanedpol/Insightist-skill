# Paralegal and Social Work Case Note Writer

Skill นี้ช่วยจัดทำบันทึกคดีและบันทึกกรณีสำหรับงานสายกฎหมาย สังคม วัฒนธรรม และที่เกี่ยวข้อง ให้เป็นระบบ อ่านง่าย และใช้ติดตามความคืบหน้าได้จริง **skill นี้ไม่ใช่การให้คำแนะนำทางกฎหมาย และห้ามกุหมายเลขมาตรากฎหมายหรือข้อกฎหมายที่ไม่แน่ใจโดยเด็ดขาด** หากต้องอ้างอิงมาตราหรือระเบียบใด ให้ระบุเฉพาะที่ผู้ใช้ให้ข้อมูลมา หรือทำเครื่องหมายให้ทนายความ/ผู้เชี่ยวชาญตรวจสอบก่อนใช้จริง

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ช่วยทนายความต้องการจดบันทึกความคืบหน้าคดี การนัดหมาย และเอกสารที่เกี่ยวข้อง เพื่อส่งต่อให้ทนายความ
- นักสังคมสงเคราะห์ระดับปฏิบัติการต้องการบันทึกการเยี่ยมบ้านหรือการติดตามเคสผู้รับบริการ
- เจ้าหน้าที่พัฒนาสังคมต้องการสรุปสถานะความช่วยเหลือของกรณีใดกรณีหนึ่งให้หัวหน้างานอ่าน
- เจ้าหน้าที่ราชทัณฑ์ต้องการบันทึกข้อมูลติดตามผู้ต้องขังตามระเบียบงานประจำ
- โค้ชหรือผู้จัดการนักกีฬาอาชีพต้องการบันทึกกรณีที่เกี่ยวข้องกับสัญญาหรือข้อพิพาทเพื่อส่งต่อฝ่ายกฎหมาย

## เมื่อไหร่ควรระวังการจัดหมวดอาชีพ

ตาม ISCO-08 "เชฟ" (chef) จัดอยู่ในกลุ่ม 34 (เทคนิคด้านกฎหมาย สังคม วัฒนธรรม และที่เกี่ยวข้อง) ในขณะที่ "พ่อครัวทั่วไป" (cook) จัดอยู่ในกลุ่ม 5 (พนักงานบริการ) เป็นจุดที่มักเข้าใจผิดเวลาจัดกลุ่มอาชีพ — หากผู้ใช้ต้องการเขียนบันทึกงานของเชฟในฐานะผู้เชี่ยวชาญด้านอาหาร (ไม่ใช่บันทึกคดี/เคส) skill นี้อาจไม่ใช่ตัวที่เหมาะสมที่สุด ควรสอบถามผู้ใช้ให้ชัดก่อนว่าต้องการเอกสารประเภทใด

## ขั้นตอนการทำงาน

### 1. ระบุประเภทบันทึกและขอบเขตงาน
แยกให้ชัดว่าเป็นบันทึกคดีทางกฎหมาย (paralegal case note) หรือบันทึกกรณีทางสังคมสงเคราะห์ (social work case note) เพราะโครงสร้างข้อมูลที่ต้องเก็บต่างกัน

### 2. รวบรวมข้อมูลพื้นฐานของเคส/คดี
ระบุ: หมายเลขคดี/เคส (ถ้ามี), วันที่เปิดเคส, ผู้รับผิดชอบ, คู่กรณีหรือผู้รับบริการ, สถานะปัจจุบัน

### 3. บันทึกลำดับเหตุการณ์ (timeline of events)
เรียงเหตุการณ์ตามวันที่เกิดขึ้นจริง ระบุแหล่งข้อมูลของแต่ละเหตุการณ์ (เช่น จากการสัมภาษณ์, เอกสารที่ได้รับ, การนัดหมาย) เพื่อให้ตรวจสอบย้อนกลับได้

### 4. บันทึกการดำเนินการที่ทำไปแล้ว (actions taken)
ระบุสิ่งที่ผู้ช่วยทนายความหรือนักสังคมสงเคราะห์ได้ทำไปแล้วในแต่ละครั้ง เช่น ติดต่อหน่วยงาน ส่งเอกสาร นัดหมาย เยี่ยมบ้าน

### 5. ระบุประเด็นที่ต้องติดตามต่อ (follow-up items)
แยกงานที่ยังค้างอยู่ ผู้รับผิดชอบต่อไป และกำหนดเวลาที่ควรติดตาม

### 6. ทำเครื่องหมายจุดที่ต้องให้ผู้เชี่ยวชาญตรวจสอบ
หากมีการอ้างอิงข้อกฎหมาย มาตรา หรือระเบียบใดที่ไม่ได้มาจากข้อมูลที่ผู้ใช้ให้ไว้ชัดเจน ให้ใส่ "[ต้องให้ทนายความ/ผู้เชี่ยวชาญตรวจสอบยืนยัน]" แทนการเดา

### 7. สรุปสถานะเคสโดยรวม
สรุปว่าเคสนี้อยู่ในขั้นตอนใด ต้องทำอะไรต่อ และมีความเร่งด่วนระดับใด

## โครงสร้าง Output

```
=== บันทึกคดี/เคส (Case Note) ===
ประเภทบันทึก: [กฎหมาย / สังคมสงเคราะห์]
หมายเลขเคส/คดี: [ถ้ามี]
วันที่บันทึก: [วัน/เดือน/ปี]
ผู้บันทึก: [ชื่อ-ตำแหน่ง]
ผู้รับบริการ/คู่กรณี: [...]

1) สถานะปัจจุบัน
   [สรุปสั้นๆ]

2) ลำดับเหตุการณ์ (Timeline)
   - [วันที่]: [เหตุการณ์] (แหล่งข้อมูล: [...])

3) การดำเนินการที่ทำไปแล้ว
   - [วันที่]: [การดำเนินการ] โดย [ผู้รับผิดชอบ]

4) ประเด็นที่ต้องติดตามต่อ
   - [รายการ] | ผู้รับผิดชอบ: [...] | กำหนดติดตาม: [...]

5) จุดที่ต้องให้ผู้เชี่ยวชาญตรวจสอบยืนยัน
   - [...]

หมายเหตุ: บันทึกนี้ไม่ใช่คำแนะนำทางกฎหมาย
```

## ตัวอย่าง

**Input:** นักสังคมสงเคราะห์ลงพื้นที่เยี่ยมบ้านผู้สูงอายุรายหนึ่งตามที่ได้รับแจ้งจากอาสาสมัครในชุมชน พบว่าอาศัยอยู่คนเดียว ลูกหลานไปทำงานต่างจังหวัด ต้องการความช่วยเหลือด้านการเดินทางไปโรงพยาบาล

**Output (คร่าวๆ):**
- สถานะปัจจุบัน: เปิดเคสใหม่ ระหว่างประเมินความต้องการความช่วยเหลือ
- ลำดับเหตุการณ์: [วันที่เยี่ยมบ้าน] ได้รับแจ้งจากอาสาสมัครชุมชน และลงพื้นที่เยี่ยมบ้านจริง
- การดำเนินการที่ทำไปแล้ว: เยี่ยมบ้านและสัมภาษณ์ผู้สูงอายุเบื้องต้น
- ประเด็นที่ต้องติดตามต่อ: ประสานหน่วยงานด้านการเดินทาง/รถรับส่งผู้สูงอายุ ผู้รับผิดชอบ: นักสังคมสงเคราะห์ผู้ดูแลเคส กำหนดติดตาม: ภายในสัปดาห์หน้า
- จุดที่ต้องให้ผู้เชี่ยวชาญตรวจสอบยืนยัน: [ต้องให้หัวหน้างานตรวจสอบสิทธิ์การรับความช่วยเหลือตามระเบียบหน่วยงานจริง]

## เกณฑ์คุณภาพ

- [ ] ระบุประเภทบันทึก (กฎหมาย/สังคมสงเคราะห์) และข้อมูลพื้นฐานของเคสครบถ้วน
- [ ] ลำดับเหตุการณ์เรียงตามเวลาจริงและระบุแหล่งที่มาของข้อมูลแต่ละจุด
- [ ] ไม่กุหมายเลขมาตรากฎหมาย ระเบียบ หรือข้อเท็จจริงใดที่ไม่ได้รับข้อมูลมา
- [ ] ไม่ให้คำแนะนำทางกฎหมายโดยตรง เน้นบันทึกข้อเท็จจริงและส่งต่อให้ผู้เชี่ยวชาญตัดสินใจ
- [ ] มีรายการติดตามต่อ (follow-up) ที่ระบุผู้รับผิดชอบและกำหนดเวลาชัดเจน
- [ ] แยกแยะการจัดหมวดอาชีพที่มักสับสน (เชฟอยู่กลุ่ม 34 ส่วนพ่อครัวทั่วไปอยู่กลุ่ม 5) เมื่อเกี่ยวข้องกับบริบทงาน
