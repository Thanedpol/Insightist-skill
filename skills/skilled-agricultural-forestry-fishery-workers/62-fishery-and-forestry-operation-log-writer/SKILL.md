# Fishery and Forestry Operation Log Writer

Skill นี้ช่วยผู้ทำป่าไม้ ประมง และล่าสัตว์เพื่อการค้า (ISCO-08 กลุ่ม 62) เขียนบันทึกการปฏิบัติงานประจำวันให้เป็นระบบ ครอบคลุมปริมาณจับ/เก็บเกี่ยว การบำรุงรักษาอุปกรณ์ และสภาพแวดล้อมขณะทำงาน พร้อมสรุปผลผลิตแบบง่ายที่นำไปเทียบย้อนหลังได้ทุกสัปดาห์/เดือน เพื่อช่วยวางแผนรอบการทำงานถัดไปและประเมินความคุ้มค่าของแต่ละเที่ยว กลุ่มอาชีพเกษตร ป่าไม้ และประมง (ISCO-08 กลุ่มใหญ่ที่ 6) เป็นกลุ่มอาชีพที่ใหญ่ที่สุดของประเทศไทย คิดเป็น 27.40% ของกำลังแรงงานทั้งหมด (ข้อมูลสำนักงานสถิติแห่งชาติ)

## เมื่อไหร่ควรใช้ skill นี้

- คนทำป่าไม้ ต้องการบันทึกปริมาณไม้ที่ตัด/ขนย้ายในแต่ละวัน
- ผู้เพาะเลี้ยงสัตว์น้ำ (กุ้ง/ปลานิล/ปลากะพง) ต้องการบันทึกการให้อาหาร คุณภาพน้ำ และปริมาณจับขาย
- ชาวประมงชายฝั่งหรือชาวประมงน้ำลึก ต้องการบันทึกปริมาณจับปลาต่อเที่ยวเรือ พร้อมสภาพอากาศ/น้ำขึ้นน้ำลง
- นักล่าสัตว์/ดักสัตว์เพื่อการค้า ต้องการบันทึกจำนวนที่จับได้และพื้นที่ที่ใช้
- ต้องการสรุปยอดผลผลิตรายสัปดาห์/รายเดือนเพื่อดูแนวโน้มว่าเที่ยวไหนคุ้มค่าที่สุด

## ขั้นตอนการทำงาน

### 1. กำหนดหน่วยและรูปแบบบันทึกให้เหมาะกับประเภทงาน
สอบถามว่าเป็นงานประมงชายฝั่ง/น้ำลึก, เพาะเลี้ยงสัตว์น้ำ, หรือป่าไม้/ล่าสัตว์ เพื่อเลือกหน่วยที่ใช้บันทึก (กิโลกรัม/ตัว/ลูกบาศก์เมตร) และความถี่การบันทึก (ต่อเที่ยว/ต่อวัน/ต่อรอบ)

### 2. บันทึกข้อมูลก่อนออกปฏิบัติงาน
จดวันที่ เวลาออก จุดที่ปฏิบัติงาน (พิกัดคร่าวๆ หรือชื่อพื้นที่) สภาพอากาศ และถ้าเป็นงานประมงให้บันทึกสภาพน้ำขึ้นน้ำลงและระดับน้ำด้วย

### 3. บันทึกปริมาณจับ/เก็บเกี่ยวระหว่างวัน
แยกตามชนิด/ขนาด/เกรด เช่น ปลานิลเกรด A/B, กุ้งขาวขนาดต่างๆ, ไม้แปรรูปตามชนิดไม้ แล้วรวมยอดเมื่อสิ้นวัน/สิ้นเที่ยว

### 4. บันทึกการบำรุงรักษาอุปกรณ์
จดสภาพเรือ/เครื่องยนต์/อวน/กรงเลี้ยง/เครื่องมือทำไม้ ว่ามีจุดชำรุดหรือต้องซ่อมบำรุงเมื่อไหร่ เพื่อวางแผนซ่อมก่อนเกิดปัญหาหนัก

### 5. สรุปต้นทุนเที่ยว/วันนั้นแบบคร่าวๆ
รวมค่าน้ำมัน ค่าแรงลูกเรือ/ลูกจ้าง ค่าอาหารสัตว์ (ถ้ามี) เทียบกับปริมาณ/มูลค่าที่จับได้ เพื่อประเมินความคุ้มค่าเบื้องต้น (ไม่ต้องระบุราคาตลาดที่แน่นอน ให้เว้นช่องกรอกราคาจริง ณ วันขาย)

### 6. รวมข้อมูลเป็นสรุปผลผลิตรายสัปดาห์/รายเดือน
นำบันทึกรายวันมารวมเป็นตาราง เทียบแนวโน้มว่าช่วงไหนได้ผลผลิตดี/ไม่ดี และปัจจัยแวดล้อม (ฤดูกาล น้ำขึ้นน้ำลง) ที่อาจเกี่ยวข้อง

### 7. ตั้งข้อสังเกตเพื่อวางแผนรอบถัดไป
ระบุจุดที่ควรปรับปรุง เช่น เปลี่ยนพื้นที่จับ ปรับตารางให้อาหาร หรือช่วงเวลาที่ควรหยุดพักฟื้นแหล่งทรัพยากร

## โครงสร้าง Output

```
=== บันทึกการปฏิบัติงาน [ประมง/ป่าไม้] ===
วันที่: [ระบุ]  พื้นที่/เส้นทาง: [ระบุ]
สภาพอากาศ: [ระบุ]   น้ำขึ้น-น้ำลง (ถ้ามี): [ระบุ]

1) ปริมาณจับ/เก็บเกี่ยว
   [ชนิด/เกรด] [ปริมาณ] [หน่วย]
   รวมทั้งหมด: [ระบุ]

2) สภาพอุปกรณ์
   - [รายการอุปกรณ์]: [สภาพ/ต้องซ่อมหรือไม่]

3) ต้นทุนเที่ยว/วันนี้ (โดยประมาณ)
   ค่าน้ำมัน/เชื้อเพลิง: [...]
   ค่าแรง: [...]
   อื่นๆ: [...]
   รายได้ (กรอกภายหลังเมื่อขายจริง): [...]

4) สรุปผลผลิตสัปดาห์/เดือน (เมื่อมีข้อมูลสะสม)
   [วันที่] [ปริมาณรวม] [แนวโน้ม ↑/↓/→]

5) ข้อสังเกตสำหรับรอบถัดไป
   - [...]
```

## ตัวอย่าง

**Input:** ชาวประมงชายฝั่งจังหวัดระยอง ออกเรือทุกวัน อยากได้แบบฟอร์มบันทึกปริมาณปลาหมึกและกุ้งที่จับได้ พร้อมสรุปรายสัปดาห์

**Output (คร่าวๆ):**
- บันทึกวันที่ 12 ก.ย. 2569: ออกเรือ 05.00 น. น้ำลง สภาพอากาศแจ่มใส คลื่นลมสงบ ปลาหมึก 18 กก. กุ้งแชบ๊วย 7 กก. รวม 25 กก.
- สภาพอุปกรณ์: อวนมีจุดขาดเล็กน้อยด้านซ้าย ต้องซ่อมก่อนออกเรือรอบหน้า
- ต้นทุนเที่ยว: น้ำมัน 400 บาท ค่าแรงลูกเรือ 300 บาท รวม 700 บาท (รายได้กรอกเมื่อขายที่แพปลา)
- สรุปสัปดาห์: เฉลี่ยจับได้ 22 กก./วัน วันที่น้ำลงตอนเช้าได้ผลผลิตสูงกว่าวันน้ำขึ้นตอนเช้าอย่างชัดเจน ควรวางแผนออกเรือตามรอบน้ำลงเป็นหลัก

## เกณฑ์คุณภาพ

- [ ] บันทึกครบทั้งปริมาณจับ/เก็บเกี่ยว สภาพอุปกรณ์ และสภาพแวดล้อม (อากาศ/น้ำขึ้นน้ำลง) ในทุกรายการ
- [ ] แยกปริมาณตามชนิด/เกรดชัดเจน และมียอดรวมท้ายวัน/เที่ยว
- [ ] มีสรุปผลผลิตแบบเทียบแนวโน้มเมื่อมีข้อมูลสะสมหลายวัน/สัปดาห์
- [ ] ต้นทุนที่ระบุเป็นเพียงประมาณการ ไม่ยัดเยียดราคาตลาด/ราคาขายที่แน่นอนโดยไม่มีข้อมูลจริง
- [ ] **ห้ามระบุปริมาณจับที่เกินโควตากฎหมายหรือให้คำแนะนำเลี่ยงกฎระเบียบประมง/ป่าไม้** หากไม่แน่ใจเรื่องกฎระเบียบหรือฤดูปิดอ่าว ให้แนะนำตรวจสอบกับกรมประมง/กรมป่าไม้หรือหน่วยงานท้องถิ่นเสมอ
- [ ] ภาษาที่ใช้กระชับ ใช้งานได้จริงหน้างานแม้พื้นที่ไม่มีสัญญาณอินเทอร์เน็ต
