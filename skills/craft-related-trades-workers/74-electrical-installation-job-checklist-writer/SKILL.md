# Electrical Installation Job Checklist Writer

Skill นี้ช่วยช่างไฟฟ้าและอิเล็กทรอนิกส์จัดทำเช็กลิสต์ความปลอดภัยก่อน-หลังติดตั้งงานไฟฟ้า และรายงานสรุปงานที่เสร็จสิ้น เพื่อให้มีเอกสารบันทึกที่ตรวจสอบย้อนกลับได้และสื่อสารกับลูกค้าได้ชัดเจน

**คำเตือนสำคัญ:** เอกสารที่ผลิตจาก skill นี้เป็นเพียงเครื่องมือช่วยจดบันทึกและจัดระเบียบงาน **ไม่ใช่การรับรองความปลอดภัยทางไฟฟ้าและไม่ทดแทนดุลยพินิจของช่างไฟฟ้าที่มีใบอนุญาตหรือวิศวกรไฟฟ้า** คำถามใดๆ เกี่ยวกับความสอดคล้องกับมาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย (เช่น มาตรฐานของวิศวกรรมสถานแห่งประเทศไทยฯ (วสท.), ข้อกำหนดของการไฟฟ้าส่วนภูมิภาค (กฟภ.) หรือการไฟฟ้านครหลวง (กฟน.) ที่เกี่ยวข้อง) ต้องตรวจสอบกับมาตรฐานทางการหรือผู้เชี่ยวชาญที่มีใบอนุญาตโดยตรง **ห้ามเดาหรือสรุปว่างานใดผ่านมาตรฐานโดยไม่มีการตรวจสอบจริง**

## เมื่อไหร่ควรใช้ skill นี้

- ช่างไฟฟ้าอาคารต้องการเช็กลิสต์ตรวจก่อนจ่ายไฟให้วงจรใหม่
- ช่างติดตั้งสายไฟต้องการบันทึกขั้นตอนตรวจสอบก่อน-หลังเดินสาย
- ช่างซ่อมอุปกรณ์ไฟฟ้าหรือช่างอิเล็กทรอนิกส์ต้องการรายงานผลซ่อมพร้อมจุดที่ตรวจแล้วปลอดภัย
- ช่างติดตั้งเคเบิล/ไฟเบอร์หรือช่างติดตั้งระบบโทรคมนาคมต้องการรายงานส่งมอบงานให้ลูกค้าหรือผู้รับเหมาหลัก
- หัวหน้าทีมช่างไฟฟ้าต้องการมาตรฐานเช็กลิสต์กลางให้ทีมใช้ก่อนปิดงานทุกครั้ง

## ขั้นตอนการทำงาน

### 1. บันทึกขอบเขตงานและจุดติดตั้ง
ระบุประเภทงาน (ติดตั้งใหม่/ซ่อม/เพิ่มวงจร/เดินสาย/ติดตั้งเคเบิล) ตำแหน่งที่ติดตั้ง จำนวนจุด และแบบ/แปลนที่ใช้อ้างอิง (ถ้ามี)

### 2. เช็กลิสต์ก่อนเริ่มงาน (Pre-installation)
ระบุจุดตรวจก่อนลงมือ เช่น ตัดไฟและล็อกจุดตัดไฟ (lockout) ก่อนสัมผัสวงจร, ตรวจสอบว่าไม่มีไฟด้วยเครื่องมือวัดก่อนแตะสาย, ตรวจสภาพอุปกรณ์ป้องกันส่วนบุคคล (ถุงมือกันไฟฟ้า, รองเท้าฉนวน), เตรียมอุปกรณ์ดับเพลิงที่เหมาะกับไฟฟ้าลัดวงจรไว้ใกล้มือ

### 3. เช็กลิสต์ระหว่างติดตั้ง
บันทึกจุดตรวจระหว่างทำงาน เช่น ขนาดสายไฟและเบรกเกอร์ตรงตามที่ออกแบบไว้หรือไม่, จุดต่อสายแน่นหนาไม่มีจุดหลวม, มีการเดินสายดินตามจุดที่กำหนด, ไม่มีสายไฟพาดผ่านจุดเสี่ยงความร้อนหรือความชื้น

### 4. เช็กลิสต์หลังติดตั้ง (Post-installation)
ก่อนจ่ายไฟจริง ให้ตรวจ: วัดค่าความต้านทานฉนวนหรือกระแสรั่วไหลด้วยเครื่องมือที่เหมาะสม, ทดสอบเบรกเกอร์กันไฟดูด (RCD/ELCB) ว่าทำงานจริง, ทดสอบระบบสายดินให้ต่อเนื่องครบวงจร, ทดลองใช้งานอุปกรณ์ปลายทางทุกจุดก่อนส่งมอบ

### 5. บันทึกผลตรวจและระบุจุดที่ต้องติดตาม
สรุปผลการตรวจแต่ละจุด (ผ่าน/ไม่ผ่าน/ต้องแก้ไข) พร้อมสิ่งที่แก้ไขไปแล้วและสิ่งที่ยังต้องติดตาม อย่าสรุปว่างานทั้งหมด "ปลอดภัย 100%" ให้ระบุเฉพาะสิ่งที่ตรวจสอบแล้วจริงเท่านั้น

### 6. เขียนรายงานสรุปงานที่เสร็จสิ้น
สรุปขอบเขตงานที่ทำจริง วัสดุ/อุปกรณ์ที่ใช้ วันที่ส่งมอบ ผู้ตรวจรับงาน และคำแนะนำการใช้งาน/บำรุงรักษาต่อเนื่อง

### 7. ระบุข้อจำกัดของเอกสารให้ชัดเจนทุกครั้ง
ปิดท้ายเอกสารด้วยข้อความย้ำว่านี่คือบันทึกงานเพื่อการจัดการภายใน ไม่ใช่ใบรับรองมาตรฐานความปลอดภัยทางไฟฟ้า และหากมีข้อสงสัยเรื่องมาตรฐานให้ปรึกษาช่างไฟฟ้าที่มีใบอนุญาตหรือหน่วยงานที่เกี่ยวข้องโดยตรง

## โครงสร้าง Output

```
=== เช็กลิสต์และรายงานงานติดตั้ง/ซ่อมไฟฟ้า ===
ลูกค้า/สถานที่: [...]   ประเภทงาน: [...]   วันที่ดำเนินการ: [...]
ผู้ปฏิบัติงาน: [ชื่อช่าง]

1) เช็กลิสต์ก่อนเริ่มงาน
   - [ ] ตัดไฟและล็อกจุดตัดไฟก่อนเริ่มงาน
   - [ ] ตรวจสอบไม่มีไฟด้วยเครื่องมือวัดก่อนสัมผัสวงจร
   - [ ] ตรวจอุปกรณ์ป้องกันส่วนบุคคลพร้อมใช้งาน

2) เช็กลิสต์ระหว่างติดตั้ง
   - [ ] ขนาดสาย/เบรกเกอร์ตรงตามแบบ
   - [ ] จุดต่อสายแน่นหนา มีสายดินครบ

3) เช็กลิสต์หลังติดตั้ง
   - [ ] วัดค่าความต้านทานฉนวน/กระแสรั่วไหล: [ผลตรวจ]
   - [ ] ทดสอบเบรกเกอร์กันไฟดูด (RCD/ELCB): [ผ่าน/ไม่ผ่าน]
   - [ ] ทดสอบสายดินต่อเนื่อง: [ผลตรวจ]
   - [ ] ทดลองใช้งานอุปกรณ์ปลายทาง: [ผลตรวจ]

4) สรุปงานที่เสร็จสิ้น
   ขอบเขตที่ทำจริง: [...]
   จุดที่ต้องติดตามต่อ: [...]

หมายเหตุ: เอกสารนี้เป็นบันทึกช่วยจัดการงานภายในเท่านั้น ไม่ใช่ใบรับรองมาตรฐานความปลอดภัยทางไฟฟ้า
กรณีมีข้อสงสัยเรื่องความสอดคล้องกับมาตรฐาน วสท./กฟภ./กฟน. หรือกฎหมายที่เกี่ยวข้อง
ให้ตรวจสอบกับช่างไฟฟ้าที่มีใบอนุญาตหรือหน่วยงานทางการโดยตรง ไม่ใช้เอกสารนี้แทนการตรวจสอบดังกล่าว
```

## ตัวอย่าง

**Input:** ช่างไฟฟ้าอาคารติดตั้งวงจรไฟใหม่ให้ห้องครัวคอนโด 1 จุด พร้อมเบรกเกอร์กันไฟดูด

**Output (คร่าวๆ):**
- ก่อนเริ่มงาน: [x] ตัดไฟที่ตู้เมนก่อนเริ่ม, [x] ตรวจไม่มีไฟด้วยไขควงวัดไฟก่อนแตะสาย
- ระหว่างติดตั้ง: [x] ใช้สาย 2.5 ตร.มม. ตามแบบ, [x] เดินสายดินไปจุดปลั๊กครบ
- หลังติดตั้ง: ทดสอบปุ่มทดสอบ (Test) บนเบรกเกอร์กันไฟดูด — ตัดไฟทำงานปกติ; ทดลองเสียบเครื่องใช้ไฟฟ้าที่ปลั๊กใหม่ — ทำงานปกติ
- จุดที่ต้องติดตาม: แนะนำให้ลูกค้ากดปุ่มทดสอบเบรกเกอร์กันไฟดูดทุกเดือนตามคำแนะนำผู้ผลิต
- หมายเหตุปิดท้าย: ย้ำว่าเอกสารนี้ไม่ใช่ใบรับรองมาตรฐาน หากต้องการใบรับรองอย่างเป็นทางการให้ติดต่อช่างไฟฟ้าที่มีใบอนุญาตหรือหน่วยงานที่เกี่ยวข้อง

## เกณฑ์คุณภาพ

- [ ] มีเช็กลิสต์ครบทั้งสามช่วง (ก่อน-ระหว่าง-หลังติดตั้ง) ไม่ข้ามขั้นตอนความปลอดภัยพื้นฐาน
- [ ] บันทึกผลตรวจตามที่ตรวจจริงเท่านั้น ไม่สรุปว่า "ปลอดภัย" หรือ "ผ่านมาตรฐาน" โดยไม่มีผลตรวจรองรับ
- [ ] **ไม่เดาหรือยืนยันความสอดคล้องกับมาตรฐาน วสท./กฟภ./กฟน. หรือกฎหมายไฟฟ้าใดๆ** ให้ระบุเสมอว่าต้องตรวจสอบกับผู้มีใบอนุญาตหรือหน่วยงานทางการ
- [ ] มีข้อความปฏิเสธความรับผิด (disclaimer) ว่าเอกสารนี้ไม่ทดแทนดุลยพินิจช่างไฟฟ้าที่มีใบอนุญาต ปรากฏอยู่ทุกครั้ง
- [ ] ระบุจุดที่ต้องติดตามต่อหรือยังไม่ได้ตรวจอย่างตรงไปตรงมา ไม่ปิดบังข้อบกพร่อง
- [ ] รายงานสรุปงานระบุขอบเขตงานจริง วันที่ และผู้ปฏิบัติงานชัดเจน ตรวจสอบย้อนกลับได้
