# Inventory Reorder Planner

Skill นี้ช่วยฝ่ายจัดซื้อ ฝ่ายคลังสินค้า และเจ้าของธุรกิจ SME คำนวณว่า "ควรสั่งซื้อสินค้าซ้ำเมื่อไหร่" และ "ควรสั่งซื้อครั้งละเท่าไหร่" โดยใช้ข้อมูลจริงที่มีอยู่แล้ว — ยอดขายเฉลี่ยต่อวัน สต็อกคงเหลือ และระยะเวลารอสินค้า (lead time) — แทนการเดาสุ่มหรือสั่งตามความเคยชิน ช่วยลดทั้งปัญหาสต็อกขาด (stockout) และสต็อกจมทุน (overstock) ในเวลาเดียวกัน

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้มีข้อมูลยอดขาย/การเบิกใช้สินค้าย้อนหลัง แล้วอยากรู้ว่าควรสั่งซื้อซ้ำตอนสต็อกเหลือเท่าไหร่
- ผู้ใช้กังวลว่าสินค้าจะขาดสต็อกก่อนของใหม่มาถึง (โดยเฉพาะสินค้าขายดีหรือ lead time นาน)
- ผู้ใช้อยากลดต้นทุนจมในสต็อก แต่ก็ไม่อยากสั่งของบ่อยเกินไปจนเสียค่าขนส่ง/ค่าดำเนินการ
- ผู้ใช้ต้องการตั้งกฎอัตโนมัติให้ทีมจัดซื้อ เช่น "พอสต็อกเหลือ X ชิ้น ให้สั่งซื้อ Y ชิ้นทันที"
- ผู้ใช้มีสินค้าหลาย SKU และอยากได้ตารางสรุปว่าตัวไหนควรสั่งก่อน-หลัง
- ผู้ใช้ถามคำถามประมาณ "ของจะหมดวันไหน", "สั่งตอนนี้ทันไหม", "เผื่อสต็อกเท่าไหร่ถึงจะปลอดภัย"

## ขั้นตอนการทำงาน

### 1. เก็บข้อมูลนำเข้าที่จำเป็น
ถามหรือดึงข้อมูลต่อไปนี้จากผู้ใช้ (ต่อ 1 SKU):
- **ยอดขาย/การเบิกใช้เฉลี่ยต่อวัน** (Average Daily Usage — ADU) คำนวณจากยอดขายย้อนหลังอย่างน้อย 30-90 วัน หากมีเฉพาะยอดรายเดือน ให้หารด้วยจำนวนวันทำการ
- **สต็อกคงเหลือปัจจุบัน** (Current Stock on Hand)
- **Lead Time** — จำนวนวันตั้งแต่สั่งซื้อจนของมาถึงคลัง (หน่วยเป็นวัน)
- **ความผันผวนของยอดขาย** — ถ้ามีข้อมูลละเอียด ใช้ส่วนเบี่ยงเบนมาตรฐาน (SD) ของยอดขายรายวัน ถ้าไม่มีให้ประมาณจากค่าสูงสุด-ต่ำสุด
- **ระดับการบริการที่ต้องการ** (Service Level) — ค่ามาตรฐานที่ใช้บ่อย 90% (Z=1.28), 95% (Z=1.65), 99% (Z=2.33) ถ้าผู้ใช้ไม่ระบุ ให้ใช้ 95% เป็นค่าเริ่มต้น
- (ถ้ามี) ต้นทุนต่อครั้งของการสั่งซื้อ (Ordering Cost) และต้นทุนการถือครองสต็อกต่อหน่วยต่อปี (Holding Cost) — ใช้สำหรับคำนวณ EOQ

หากข้อมูลไม่ครบ ให้ตั้งสมมติฐานอย่างมีเหตุผล (ระบุให้ชัดในรายงานว่า "สมมติฐาน") แทนการหยุดรอ

### 2. คำนวณ Safety Stock (สต็อกกันชน)
สูตรมาตรฐาน (แบบมี lead time คงที่ ผันผวนเฉพาะยอดขาย):

```
Safety Stock = Z × SD(ยอดขายรายวัน) × √(Lead Time)
```

ถ้าไม่มีค่า SD ให้ใช้สูตรประมาณแบบง่าย:

```
Safety Stock = (ยอดขายสูงสุดต่อวัน − ยอดขายเฉลี่ยต่อวัน) × Lead Time
```

### 3. คำนวณ Reorder Point (จุดสั่งซื้อซ้ำ)

```
Reorder Point (ROP) = (Average Daily Usage × Lead Time) + Safety Stock
```

ตีความ: เมื่อสต็อกคงเหลือลดลงมาถึงตัวเลขนี้ ต้องยิงคำสั่งซื้อทันที ไม่ใช่รอให้ของหมด

### 4. คำนวณปริมาณสั่งซื้อที่เหมาะสม (Order Quantity)
- ถ้ามีข้อมูลต้นทุนครบ ใช้สูตร EOQ (Economic Order Quantity):

```
EOQ = √( (2 × Demand ต่อปี × Ordering Cost) ÷ Holding Cost ต่อหน่วยต่อปี )
```

- ถ้าไม่มีข้อมูลต้นทุน ให้ใช้แนวทางปฏิบัติ: กำหนดรอบสั่งซื้อ (เช่น สั่งทุก 2 สัปดาห์ หรือ 30 วัน) แล้วคำนวณ

```
Order Quantity = (Average Daily Usage × จำนวนวันในรอบสั่งซื้อ) + Safety Stock − สต็อกคงเหลือ ณ วันที่สั่ง
```

### 5. ประเมินความเร่งด่วนปัจจุบัน
เปรียบเทียบสต็อกคงเหลือกับ ROP:
- ถ้า **สต็อกคงเหลือ ≤ ROP** → สถานะ "ต้องสั่งซื้อทันที"
- ถ้า **สต็อกคงเหลือ > ROP** → คำนวณ "จำนวนวันก่อนถึงจุดสั่งซื้อ" = (สต็อกคงเหลือ − ROP) ÷ Average Daily Usage

### 6. สรุปเป็นตารางและคำแนะนำเชิงปฏิบัติ
จัดเรียงสินค้าตามความเร่งด่วน (วันที่เหลือน้อยที่สุดขึ้นก่อน) พร้อมระบุ action ที่ชัดเจนต่อ SKU

## โครงสร้าง Output

```
# แผนสั่งซื้อสต็อก — [ชื่อร้าน/หมวดสินค้า]
วันที่วิเคราะห์: [DD/MM/YYYY]

## สรุปสำหรับผู้บริหาร

- Reorder Point = [สูตรพร้อมตัวเลขแทนค่า] = [ผลลัพธ์]
- Order Quantity แนะนำ = [สูตรพร้อมตัวเลขแทนค่า] = [ผลลัพธ์]

3. [ข้อควรระวัง เช่น ตรวจสอบ lead time ซ้ำกับซัพพลายเออร์ช่วงเทศกาล]
```

## ตัวอย่าง

**Input:** สินค้า "น้ำยาล้างจาน 800ml" ขายเฉลี่ย 12 ขวด/วัน สต็อกคงเหลือ 150 ขวด lead time ผู้จำหน่าย 7 วัน ยอดขายสูงสุดที่เคยเกิดขึ้นในหนึ่งวันคือ 20 ขวด ต้องการ service level 95% (Z=1.65) และไม่มีข้อมูลต้นทุนสำหรับ EOQ จึงตั้งรอบสั่งซื้อทุก 14 วัน

**Output คร่าวๆ ที่ควรได้:**
- Safety Stock ≈ (20 − 12) × 7 = 56 ขวด
- Reorder Point = (12 × 7) + 56 = 84 + 56 = **140 ขวด**
- สถานะ: สต็อกปัจจุบัน 150 ขวด มากกว่า ROP 140 ขวด → ยังไม่ต้องสั่งตอนนี้ แต่จะถึงจุดสั่งซื้อในอีก (150 − 140) ÷ 12 ≈ **0.8 วัน** → 🔴 ต้องเตรียมสั่งภายในวันพรุ่งนี้
- Order Quantity แนะนำสำหรับรอบ 14 วัน = (12 × 14) + 56 − 150 = 168 + 56 − 150 = **74 ขวด**
