# Street Vendor Daily Sales Log Writer

Skill นี้ช่วยผู้ขายและผู้ให้บริการตามถนน (ISCO-08 กลุ่ม 95 — Skill Level 1) เขียนสมุดบันทึกยอดขายประจำวันแบบง่ายที่สุด ไม่ต้องรู้บัญชี ใช้คำง่าย ตัวเลขน้อย เขียนตามได้ทันทีตอนขายของ ช่วยให้รู้ว่าวันนี้ขายได้เท่าไหร่ เงินหายไปไหนบ้าง และของอะไรใกล้หมดต้องซื้อเพิ่ม

## เมื่อไหร่ควรใช้ skill นี้

- คนขายของริมถนนต้องการจดว่าวันนี้ขายอะไรได้บ้าง ได้เงินเท่าไหร่
- คนขายอาหารข้างทางต้องการรู้ว่าวันไหนขายดี วันไหนของเหลือ
- คนขัดรองเท้าหรือคนล้างกระจกรถตามสี่แยกต้องการจดจำนวนลูกค้าและเงินที่ได้ต่อวัน
- คนวิ่งงานตามถนนต้องการจดรายรับจากงานที่รับมาแต่ละวัน
- พ่อค้าแม่ค้าที่ไม่เคยทำบัญชีมาก่อนต้องการเริ่มจดบันทึกง่ายๆ ให้ติดเป็นนิสัย

## ขั้นตอนการทำงาน

### 1. ถามว่าวันนี้ขายอะไรบ้าง
สอบถามรายการของที่ขายวันนี้ เช่น ก๋วยเตี๋ยว น้ำแข็งใส ของชำ ผลไม้ หรือบริการ (ขัดรองเท้า ล้างกระจก) แล้วตั้งชื่อรายการให้จำง่าย

### 2. จดจำนวนที่ขายได้และเงินที่ได้ต่อรายการ
ถามจำนวนชิ้น/ถ้วย/ครั้งที่ขายได้ และราคาต่อหน่วย คูณออกมาเป็นยอดขายต่อรายการ ใช้เลขกลมๆ ไม่ต้องละเอียดเป็นสตางค์

### 3. รวมยอดขายทั้งหมดของวัน
บวกยอดขายทุกรายการเป็นยอดรวมวันนี้ เขียนตัวเลขให้ใหญ่ชัดเจน อ่านง่าย

### 4. จดเงินที่จ่ายออกระหว่างวัน
ถามว่าวันนี้จ่ายอะไรไปบ้าง เช่น ซื้อของเพิ่ม ค่าน้ำแข็ง ค่าน้ำมันรถเข็น ค่าที่จอด แล้วรวมเป็นยอดจ่ายรวม

### 5. คำนวณเงินคงเหลือปลายวันแบบง่าย
เอายอดขายรวม ลบ ยอดจ่ายรวม ได้เป็นเงินที่เหลือให้เก็บหรือใช้ต่อพรุ่งนี้ อธิบายเป็นคำพูดง่ายๆ ว่า "วันนี้เหลือเงินเท่าไหร่"

### 6. เตือนของที่ใกล้หมดต้องซื้อเพิ่มพรุ่งนี้
ถามว่าของชิ้นไหนขายหมดเร็วหรือเหลือน้อย จดเป็นรายการเตือนซื้อเพิ่มไว้ล่วงหน้า

### 7. สรุปเป็นสมุดบันทึก 1 หน้าต่อวัน
รวมทุกส่วนเป็นแผ่นเดียว ตัวหนังสือใหญ่ อ่านง่าย เหมาะเขียนด้วยมือต่อในสมุดเล่มเล็กทุกวัน

## โครงสร้าง Output

```
=== บันทึกยอดขายวันที่ [ระบุ] ===

1) ขายอะไรได้บ้าง
   [ชื่อของ/บริการ] x [จำนวน] x [ราคาต่อหน่วย] = [ยอดขาย]
   รวมยอดขายวันนี้ = [ยอดรวม] บาท

2) จ่ายอะไรไปบ้าง
   [รายการที่จ่าย] = [จำนวนเงิน]
   รวมยอดจ่ายวันนี้ = [ยอดรวม] บาท

3) เงินเหลือวันนี้
   ยอดขาย [ยอดรวม] − ยอดจ่าย [ยอดรวม] = เหลือ [ยอดเงินคงเหลือ] บาท

4) ของที่ต้องซื้อเพิ่มพรุ่งนี้
   - [รายการที่ใกล้หมด]
```

## ตัวอย่าง

**Input:** แม่ค้าขายส้มตำริมถนนบอกว่าวันนี้ขายตำถาด 15 ถุง ถุงละ 40 บาท ไก่ย่าง 5 ตัว ตัวละ 100 บาท จ่ายค่าซื้อวัตถุดิบเพิ่ม 300 บาท ค่ารถเข็น 50 บาท มะละกอเหลือน้อยแล้ว

**Output (คร่าวๆ):**
- ขายได้: ส้มตำ 15 x 40 = 600 บาท, ไก่ย่าง 5 x 100 = 500 บาท → รวมยอดขาย 1,100 บาท
- จ่ายไป: ซื้อวัตถุดิบ 300 บาท, ค่ารถเข็น 50 บาท → รวมยอดจ่าย 350 บาท
- เงินเหลือวันนี้: 1,100 − 350 = 750 บาท
- ของที่ต้องซื้อเพิ่มพรุ่งนี้: มะละกอ

- [ ] ใช้คำง่ายๆ ไม่มีศัพท์บัญชี เขียนแล้วคนไม่เคยทำบัญชีอ่านเข้าใจทันที
- [ ] มีทั้งยอดขาย ยอดจ่าย และเงินคงเหลือครบทั้งสามส่วน
- [ ] มีรายการเตือนของที่ต้องซื้อเพิ่มพรุ่งนี้เสมอ ถ้าผู้ใช้ไม่ได้บอกให้ถามก่อนแทนการเดาเอง
- [ ] จัดหน้าให้สั้น กระชับ พอดีกับ 1 หน้าเขียนด้วยมือ
