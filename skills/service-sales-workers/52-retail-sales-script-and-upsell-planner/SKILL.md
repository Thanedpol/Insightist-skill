# Retail Sales Script & Upsell Planner

Skill นี้ช่วยเขียนสคริปต์การขายและคำถามกระตุ้นการขายเพิ่มสำหรับพนักงานขายหน้าร้านและกลุ่มงานขาย (ISCO-08 กลุ่มย่อย 52) ให้พูดเป็นธรรมชาติ ไม่กดดันลูกค้าจนรู้สึกอึดอัด และช่วยเพิ่มยอดขายเฉลี่ยต่อบิลได้จริง พร้อมแบบฟอร์มบันทึกยอดขายที่พนักงานกรอกเองได้ทุกวัน

## เมื่อไหร่ควรใช้ skill นี้

- ต้องการสคริปต์เปิดการขายสำหรับพนักงานขายหน้าร้านหรือพนักงานขายเคาน์เตอร์อาหาร
- ต้องการคำถามกระตุ้นการขายเพิ่ม (upsell) หรือขายพ่วง (cross-sell) ที่แคชเชียร์พูดได้ตอนคิดเงิน
- ต้องการสคริปต์โทรศัพท์สำหรับเทเลเซลส์หรือพนักงานขายตรงที่ต้องเปิดใจลูกค้าในไม่กี่วินาทีแรก
- ต้องการช่วยพ่อค้าแม่ค้าตลาด/แผงลอยหรือพนักงานปั๊มน้ำมันมีวิธีชวนซื้อที่เป็นธรรมชาติ
- ต้องการแบบฟอร์มบันทึกยอดขายประจำวันที่พนักงานขายกรอกเองได้ง่ายๆ

## ขั้นตอนการทำงาน

### 1. ระบุสินค้า/บริการและกลุ่มลูกค้าเป้าหมาย
สอบถามหรือระบุว่าขายอะไร ราคาช่วงไหน และลูกค้าส่วนใหญ่เป็นใคร เพื่อให้สคริปต์ที่เขียนใช้คำที่ตรงกับลูกค้าจริง

### 2. เขียนประโยคเปิดการขาย (opening line)
สร้างประโยคทักทายและเปิดบทสนทนาที่ไม่ฟังดูเหมือนกำลังขาย เน้นถามความต้องการก่อนเสนอสินค้า เช่น ถามหาโอกาสใช้งานแทนถามว่า "จะซื้ออะไร"

### 3. เขียนสคริปต์นำเสนอสินค้าหลัก
ระบุจุดขาย 2-3 ข้อของสินค้าที่ตรงกับความต้องการที่ลูกค้าบอก ใช้ภาษาพูดง่าย ไม่ใช้ศัพท์เทคนิคเกินจำเป็น

### 4. ออกแบบคำถาม/ประโยคขายเพิ่ม (upsell) และขายพ่วง (cross-sell)
- Upsell: เสนอรุ่น/ขนาดที่ดีกว่าในราคาที่สูงขึ้นเล็กน้อย เช่น "อีกแค่ [ส่วนต่างราคา] ได้รุ่นที่ [ประโยชน์เพิ่ม] ด้วยนะคะ"
- Cross-sell: เสนอสินค้าที่ใช้คู่กัน เช่น "ลูกค้าซื้อ [สินค้าหลัก] แล้ว มีคนซื้อ [สินค้าคู่กัน] เพิ่มด้วยบ่อยๆ ค่ะ"
- ทุกคำถามต้องมีทางออกให้ลูกค้าปฏิเสธได้อย่างสบายใจ ไม่ใช้คำพูดกดดัน

### 5. เขียนวิธีรับมือข้อโต้แย้งที่พบบ่อย (objection handling)
ระบุข้อโต้แย้งที่ลูกค้ามักพูด เช่น "แพงไป" "ขอดูก่อน" พร้อมแนวทางตอบสั้นๆ ที่ไม่เถียงกับลูกค้า

### 6. เขียนประโยคปิดการขาย
สร้างประโยคชวนตัดสินใจที่ไม่บังคับ เช่น เสนอทางเลือก 2 อย่างแทนคำถามปลายเปิด ("รับสีนี้หรือสีนี้ดีคะ" แทน "จะเอาไหมคะ")

### 7. ออกแบบแบบฟอร์มบันทึกยอดขายประจำวัน
สร้างแบบฟอร์มสั้นๆ ให้พนักงานกรอกยอดขาย จำนวนบิล และอัตราการขายเพิ่มสำเร็จ เพื่อติดตามผลและปรับสคริปต์ต่อไป

## โครงสร้าง Output

```
=== สคริปต์การขาย: [ชื่อสินค้า/ร้าน] ===

1) เปิดการขาย
   "[ประโยคเปิด]"

2) นำเสนอสินค้า
   จุดขาย: [จุดขาย 1] / [จุดขาย 2] / [จุดขาย 3]
   "[ประโยคนำเสนอ]"

3) ขายเพิ่ม/ขายพ่วง
   Upsell: "[ประโยคเสนอรุ่นที่ดีกว่า]"
   Cross-sell: "[ประโยคเสนอสินค้าคู่กัน]"

4) รับมือข้อโต้แย้ง
   ลูกค้าพูด: "[ข้อโต้แย้ง]" → ตอบ: "[คำตอบ]"

5) ปิดการขาย
   "[ประโยคปิด]"

=== แบบบันทึกยอดขายประจำวัน ===
วันที่: [วันที่] | พนักงาน: [ชื่อ]
| บิลที่ | ยอดขาย | มีขายเพิ่มไหม (มี/ไม่มี) | หมายเหตุ |
```

## ตัวอย่าง

**Input:** ร้านขายมือถือและอุปกรณ์เสริม ลูกค้าซื้อมือถือรุ่นกลาง

**Output (คร่าวๆ):**
```
1) เปิดการขาย
   "สวัสดีค่ะ วันนี้มองหามือถือไว้ใช้งานแบบไหนคะ ถ่ายรูปเยอะ เล่นเกม หรือใช้งานทั่วไปคะ"

3) ขายเพิ่ม/ขายพ่วง
   Upsell: "รุ่นนี้อีกแค่ 1,000 บาท ได้กล้องดีขึ้นและแบตอึดขึ้นค่ะ คุ้มกว่าถ้าใช้ยาว"
   Cross-sell: "ลูกค้าซื้อรุ่นนี้ส่วนใหญ่ซื้อฟิล์มกันรอยกับเคสกันกระแทกเพิ่มด้วยค่ะ วันนี้จัดโปรคู่กันได้"

4) รับมือข้อโต้แย้ง
   ลูกค้าพูด: "แพงไปหน่อย" → ตอบ: "เข้าใจค่ะ ถ้างบไม่ถึงมีรุ่นรองลงมาที่สเปกใกล้เคียงกันให้ดูเพิ่มได้นะคะ"
```

## เกณฑ์คุณภาพ

- [ ] สคริปต์ใช้ภาษาพูดธรรมชาติ ไม่ฟังดูท่องจำหรือกดดันลูกค้า
- [ ] มีทั้งขั้นตอนเปิดการขาย นำเสนอ ขายเพิ่ม รับมือข้อโต้แย้ง และปิดการขาย ครบ
- [ ] ข้อเสนอ upsell/cross-sell สมเหตุสมผลกับสินค้าจริง ไม่ใช่การยัดเยียด
- [ ] ไม่สร้างสรรพคุณสินค้าหรือส่วนลด/โปรโมชันที่ไม่มีข้อมูลยืนยันจากผู้ใช้
- [ ] มีแบบฟอร์มบันทึกยอดขายที่กรอกง่าย ใช้ได้จริงในหน้างาน
- [ ] ทุกประโยคเปิดทางให้ลูกค้าปฏิเสธได้โดยไม่รู้สึกอึดอัด
