# SWOT + Competitive Analysis

Skill นี้ช่วยประเมินสถานะเชิงกลยุทธ์ของธุรกิจ ผลิตภัณฑ์ หรือทีม โดยรวมสองเครื่องมือที่มักถูกใช้แยกกันแต่จริงๆ ควรมองคู่กัน คือ **SWOT** (มองเข้าไปในตัวเองและสภาพแวดล้อม) และ **Competitive Matrix** (มองเทียบกับคู่แข่งแบบเป็นรูปธรรม มีหัวข้อเปรียบเทียบชัดเจน) เหมาะกับผู้ที่กำลังวางแผนกลยุทธ์ เตรียม pitch นักลงทุน ทำแผนธุรกิจประจำปี หรือประเมินก่อนตัดสินใจเข้าตลาดใหม่

จุดสำคัญคือ SWOT ที่ดีต้อง "เจาะจงและพิสูจน์ได้" ไม่ใช่ลิสต์คำคุณศัพท์สวยหรู และ Competitive Matrix ต้องใช้เกณฑ์เปรียบเทียบที่ลูกค้าจริงให้ความสำคัญ ไม่ใช่เกณฑ์ที่บริษัทอยากเปรียบเทียบ

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้ต้องการประเมินสถานะธุรกิจ/ผลิตภัณฑ์ตัวเองอย่างรอบด้านก่อนตัดสินใจเชิงกลยุทธ์
- ผู้ใช้กำลังเตรียมเอกสารระดมทุนหรือแผนธุรกิจที่ต้องมีสไลด์ "ทำไมเราจะชนะคู่แข่ง"
- ผู้ใช้รู้จักคู่แข่งบางรายแต่ยังไม่เคยเทียบแบบเป็นระบบ
- ผู้ใช้ต้องการรู้จักคู่แข่งเพิ่มเติมในตลาดที่ยังไม่คุ้นเคย (ต้องค้นคว้าเพิ่ม)
- ทีมกำลังทบทวนกลยุทธ์ประจำไตรมาส/ประจำปี และต้องการมุมมองที่เป็นกลาง ไม่ลำเอียงเข้าข้างตัวเอง

## ขั้นตอนการทำงาน

### 1. เก็บข้อมูลตั้งต้น
ถามผู้ใช้ (หรือดึงจากบริบทที่ให้มาแล้ว):
- ธุรกิจ/ผลิตภัณฑ์ที่จะวิเคราะห์คืออะไร อยู่ในตลาด/อุตสาหกรรมไหน
- รู้จักคู่แข่งรายใดบ้าง (ชื่อ, ขนาด, จุดเด่นที่รู้คร่าวๆ) — ถ้าผู้ใช้บอกว่าไม่รู้จักใครเลย หรือรู้ไม่ครบ ให้ระบุว่าจะ "ค้นคว้าเพิ่ม" และถามว่าต้องการโฟกัสตลาดไหน (ประเทศ/ภูมิภาค/segment)
- มีข้อมูลผลประกอบการ/ยอดขาย/ฐานลูกค้าของตัวเองบ้างไหม (ใช้ประเมิน Strengths/Weaknesses ที่เป็นรูปธรรม)
- เป้าหมายของการวิเคราะห์นี้คืออะไร (ใช้ตัดสินใจอะไรต่อ เช่น จะเข้าตลาดใหม่ / จะปรับราคา / จะ pitch นักลงทุน) — คำตอบนี้กำหนดว่าควรเน้นมุมไหนของ SWOT มากเป็นพิเศษ

### 2. ทำ SWOT แบบเจาะจง (ไม่ใช่ generic list)
ใช้กรอบคำถามนี้ในแต่ละช่อง เพื่อบังคับให้ตอบแบบเจาะจง:

- **Strengths (จุดแข็ง)**: อะไรที่เราทำได้ดีกว่าค่าเฉลี่ยตลาด และพิสูจน์ได้ด้วยข้อมูล/ผลลัพธ์จริง (ไม่ใช่แค่ "ทีมเก่ง")? ลูกค้าจริงเคยชมเรื่องอะไรซ้ำๆ?
- **Weaknesses (จุดอ่อน)**: อะไรที่ลูกค้าเคยบ่น หรือทำให้เสียดีลไปแล้ว? ทรัพยากรอะไรที่เราขาดเทียบกับคู่แข่งชั้นนำ?
- **Opportunities (โอกาส)**: การเปลี่ยนแปลงภายนอกอะไร (พฤติกรรมผู้บริโภค, กฎหมาย, เทคโนโลยี, ช่องว่างที่คู่แข่งไม่ได้ทำ) ที่เราสามารถใช้ประโยชน์ได้ในเวลาที่เหมาะสม?
- **Threats (ภัยคุกคาม)**: อะไรจากภายนอกที่อาจทำร้ายธุรกิจ (คู่แข่งใหม่, สินค้าทดแทน, การเปลี่ยนกฎระเบียบ, ความผันผวนของต้นทุน) และมีโอกาสเกิดสูงแค่ไหน?

กฎสำคัญ: ทุกข้อใน SWOT ต้องตอบคำถาม "แล้วไง" (so what) ได้ — ถ้าเขียนแล้วนำไปวางแผนต่อไม่ได้ ให้เขียนใหม่ให้เจาะจงกว่าเดิม

### 3. เลือกคู่แข่งและเกณฑ์เปรียบเทียบ
- เลือกคู่แข่ง 3-5 รายที่เกี่ยวข้องที่สุด (direct competitor ที่แย่งลูกค้ากลุ่มเดียวกันโดยตรง อย่างน้อย 2 ราย + indirect/substitute อย่างน้อย 1 ราย)
- ถ้าข้อมูลคู่แข่งที่ผู้ใช้ให้มาไม่พอ ให้ค้นคว้าเพิ่มเติม (ราคา, feature หลัก, จุดเด่นที่ตลาดพูดถึง, กลุ่มลูกค้าเป้าหมาย) และระบุแหล่งที่มา/ความมั่นใจของข้อมูลอย่างตรงไปตรงมา
- เลือกเกณฑ์เปรียบเทียบ 5-8 ข้อที่ **ลูกค้าใช้ตัดสินใจจริง** เช่น ราคา, คุณภาพ/ฟีเจอร์หลัก, ความสะดวกในการเข้าถึง, บริการหลังการขาย, ชื่อเสียง/ความน่าเชื่อถือ, ความเร็วในการส่งมอบ — หลีกเลี่ยงเกณฑ์ที่มีแต่บริษัทตัวเองสนใจ

### 4. สร้างตารางเปรียบเทียบ (Competitive Matrix)
ให้คะแนนแต่ละเกณฑ์แบบ 1-5 หรือ ดี/ปานกลาง/แย่ สำหรับทุกราย (รวมตัวเอง) พร้อมหมายเหตุสั้นๆ อธิบายเหตุผลของคะแนน ไม่ใช่แค่ใส่ตัวเลขลอยๆ

### 5. สังเคราะห์ข้อสรุปเชิงกลยุทธ์
เชื่อม SWOT กับ Competitive Matrix เข้าด้วยกัน:
- Strengths ของเราตรงกับเกณฑ์ที่เราชนะในตารางหรือไม่ (ถ้าไม่ตรง แปลว่า SWOT อาจหลอกตัวเอง)
- Weaknesses ของเราคือเกณฑ์ที่เราแพ้คู่แข่งข้อไหนบ้าง
- Opportunities ควรใช้ประโยชน์จากช่องว่างที่ตารางแสดงว่า "ไม่มีใครทำดี" ในเกณฑ์ไหน
- สรุปเป็น 2-3 ข้อเสนอเชิงกลยุทธ์ที่ทำได้จริงในระยะสั้น (quick win) และระยะยาว

```
# SWOT + Competitive Analysis: [ชื่อธุรกิจ/ผลิตภัณฑ์]

## SWOT Analysis
### Strengths
- ... (อ้างอิงหลักฐาน/ข้อมูล)

### Weaknesses
- ...

### Opportunities
- ...

### Threats
- ...

## Competitive Matrix
| เกณฑ์เปรียบเทียบ | เรา | คู่แข่ง A | คู่แข่ง B | คู่แข่ง C |
|---|---|---|---|---|
| ราคา | ... | ... | ... | ... |
| คุณภาพ/ฟีเจอร์หลัก | ... | ... | ... | ... |
| ช่องทางเข้าถึง | ... | ... | ... | ... |
| บริการหลังการขาย | ... | ... | ... | ... |
| ชื่อเสียง/ความน่าเชื่อถือ | ... | ... | ... | ... |

(หมายเหตุระบุที่มาของข้อมูลคู่แข่ง และระดับความมั่นใจ)

## สังเคราะห์เชิงกลยุทธ์
- จุดที่ SWOT กับตารางสอดคล้องกัน: ...
- จุดที่ขัดแย้งกัน (ต้องทบทวน): ...
- ข้อเสนอ Quick Win (ทำได้ใน 1-3 เดือน): ...
- ข้อเสนอระยะยาว (6-12 เดือนขึ้นไป): ...
```

## ตัวอย่าง

**Input:** "ร้านกาแฟ specialty แห่งใหม่ในย่านทองหล่อ อยากรู้ว่าสู้กับร้านกาแฟเชนใหญ่และร้าน specialty ที่มีอยู่แล้วได้ไหม"

**Output (คร่าวๆ):** Strengths: บาริสต้ามีใบรับรอง Q-grader, เมล็ดกาแฟ single-origin เปลี่ยนทุกเดือน (พิสูจน์ได้จากซัพพลายเออร์) / Weaknesses: ที่นั่งน้อย จอดรถยาก / Opportunities: กระแส "third wave coffee" ในกลุ่มคนทำงาน WFH ที่ต้องการที่นั่งทำงานคุณภาพสูง / Threats: ร้านเชนใหญ่เริ่มทำเมนู specialty เจาะกลุ่มเดียวกัน — Competitive Matrix เทียบกับเชนใหญ่และร้าน specialty คู่แข่ง 2 ราย ในเกณฑ์ ราคา/คุณภาพ/บรรยากาศ/ที่จอดรถ/ความเร็วบริการ พบว่าจุดที่ยังไม่มีใครทำดีคือ "พื้นที่ทำงานเงียบสำหรับ WFH" → เสนอเป็น quick win

## เกณฑ์คุณภาพ

- [ ] ทุกข้อใน SWOT เจาะจงและมีหลักฐาน/เหตุผลรองรับ ไม่ใช่คำคุณศัพท์ลอยๆ
- [ ] เลือกคู่แข่งที่เกี่ยวข้องจริงอย่างน้อย 3 ราย และระบุว่าเป็น direct หรือ indirect competitor
- [ ] เกณฑ์เปรียบเทียบในตารางสะท้อนสิ่งที่ลูกค้าตัดสินใจจริง ไม่ใช่เกณฑ์ที่เข้าข้างตัวเอง
- [ ] มีการเชื่อมโยง SWOT กับผลตารางเปรียบเทียบอย่างชัดเจน ไม่ใช่สองส่วนที่แยกขาดจากกัน
- [ ] มีข้อเสนอเชิงกลยุทธ์ที่นำไปปฏิบัติได้จริง แบ่งเป็น quick win และระยะยาว
- [ ] ถ้าข้อมูลคู่แข่งมาจากการค้นคว้าเพิ่ม ต้องระบุแหล่งที่มา/ความมั่นใจอย่างตรงไปตรงมา
