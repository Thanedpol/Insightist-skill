# Cleaning Service Schedule and Checklist Writer

Skill นี้ช่วยพนักงานทำความสะอาดและผู้ช่วย (ISCO-08 กลุ่ม 91 — Skill Level 1) เขียนตารางทำความสะอาดและเช็คลิสต์ตรวจคุณภาพงานที่เข้าใจง่าย ไม่ต้องใช้ศัพท์เทคนิค เหมาะสำหรับติดบอร์ดหน้างานหรือพกไปเช็คทีละจุดขณะทำงานจริง ช่วยให้ทำงานไม่ตกหล่น แบ่งงานในทีมได้ชัดเจน และมีหลักฐานว่าตรวจงานแล้ว

## เมื่อไหร่ควรใช้ skill นี้

- แม่บ้านประจำบ้านต้องการตารางทำความสะอาดบ้านทั้งหลังแบ่งเป็นวันๆ
- พนักงานทำความสะอาดสำนักงาน/โรงแรมต้องการตารางแบ่งโซนพื้นที่และความถี่งาน
- พนักงานทำความสะอาดยานพาหนะ (รถบัส รถตู้ รถโดยสาร) ต้องการเช็คลิสต์ก่อน-หลังทำความสะอาดแต่ละคัน
- คนซักรีดต้องการตารางคิวงานซัก-รีด-ส่งคืนที่ไม่สับสน
- คนเช็ดกระจกอาคารต้องการตารางรอบเช็ดตามชั้น/ด้านอาคาร พร้อมจุดตรวจความปลอดภัย

## ขั้นตอนการทำงาน

### 1. สำรวจพื้นที่และแบ่งโซน
สอบถามหรือรวบรวมว่าพื้นที่ทั้งหมดมีกี่โซน/กี่ห้อง/กี่จุด เช่น ห้องนอน ห้องน้ำ ห้องครัว ล็อบบี้ ห้องประชุม จุดรับรถ กระจกอาคารชั้นไหนบ้าง แล้วตั้งชื่อโซนให้จำง่าย

### 2. กำหนดความถี่งานของแต่ละโซน
ระบุว่าแต่ละโซนต้องทำความสะอาดบ่อยแค่ไหน เช่น ทุกวัน (ห้องน้ำ พื้นทางเดิน), 2-3 วันครั้ง (ห้องประชุม), สัปดาห์ละครั้ง (กระจก พัดลมเพดาน), เดือนละครั้ง (ผ้าม่าน พรม)

### 3. จัดตารางเวลาต่อกะหรือต่อวัน
เรียงลำดับงานตามเวลาที่มี เช่น กะเช้า 08:00-10:00 ทำโซน A, 10:00-12:00 ทำโซน B ถ้ามีทีมหลายคนให้ระบุชื่อผู้รับผิดชอบแต่ละโซนด้วย

### 4. ระบุอุปกรณ์และวิธีทำความสะอาดแบบทั่วไปต่อจุด
บอกอุปกรณ์หลักที่ต้องใช้ต่อโซน (ไม้ถูพื้น ผ้าไมโครไฟเบอร์ น้ำยาทำความสะอาดพื้นผิว) แบบทั่วไป **ไม่ระบุยี่ห้อหรือสูตรเคมีเฉพาะเจาะจง** และเตือนให้อ่านฉลากคำเตือนบนภาชนะน้ำยาก่อนใช้ทุกครั้ง โดยเฉพาะการห้ามผสมน้ำยาต่างชนิดกัน

### 5. สร้างเช็คลิสต์ตรวจคุณภาพหลังทำความสะอาด
ทำรายการจุดตรวจสั้นๆ ที่กาถูก/ผิดได้ทันที เช่น พื้นแห้งไม่มีคราบ, ถังขยะเทและใส่ถุงใหม่แล้ว, กระจกไม่มีรอยเปื้อน, ห้องน้ำมีสบู่/กระดาษชำระครบ

### 6. ทำเครื่องหมายจุดที่ต้องดูแลเป็นพิเศษ
ระบุจุดสัมผัสบ่อย (ลูกบิดประตู ราวบันได ปุ่มลิฟต์) และจุดเสี่ยงลื่น/อันตราย (พื้นเปียกหลังถูใหม่ๆ ต้องตั้งป้ายเตือน) ให้เห็นชัดในตาราง

### 7. สรุปเป็นเอกสารที่ใช้งานจริงได้
รวมตารางและเช็คลิสต์เป็นแผ่นเดียวหรือชุดเดียว จัดตัวอักษรให้อ่านง่าย เหมาะสำหรับติดบอร์ดหรือพิมพ์พกติดตัว

## โครงสร้าง Output

```
=== ตารางทำความสะอาด [ชื่อสถานที่] ===
ช่วงเวลา: [ระบุ]  ผู้รับผิดชอบ: [ระบุ]

1) ตารางความถี่งานตามโซน
   [โซน] [ความถี่] [เวลาที่ทำ] [ผู้รับผิดชอบ]

2) ตารางเวลาต่อกะ
   [เวลา] [โซน/งาน] [หมายเหตุ]

3) อุปกรณ์ที่ต้องใช้ต่อโซน
   [โซน]: [อุปกรณ์หลัก] — อ่านฉลากคำเตือนก่อนใช้ทุกครั้ง

4) เช็คลิสต์ตรวจคุณภาพ (กาหลังทำเสร็จ)
   - [ ] [จุดตรวจที่ 1]
   - [ ] [จุดตรวจที่ 2]
   - [ ] [จุดตรวจที่ 3]

5) จุดที่ต้องดูแลเป็นพิเศษ
   - [จุดสัมผัสบ่อย/จุดเสี่ยงลื่น]: [วิธีดูแล/ป้ายเตือนที่ต้องตั้ง]
```

## ตัวอย่าง

**Input:** โรงแรมขนาดเล็ก 20 ห้อง มีพนักงานทำความสะอาด 3 คน ต้องการตารางประจำวันสำหรับล็อบบี้ ห้องพัก และห้องน้ำส่วนกลาง

**Output (คร่าวๆ):**
- ตารางความถี่: ห้องพักที่เช็คเอาต์ทำความสะอาดทุกวัน, ล็อบบี้เช็ดพื้น/กระจกทุกวัน, ห้องน้ำส่วนกลางเช็คทุก 2 ชั่วโมง
- ตารางเวลา: 08:00-11:00 คนที่ 1 ทำห้องพักชั้น 1-2, คนที่ 2 ทำห้องพักชั้น 3-4, คนที่ 3 ดูแลล็อบบี้และห้องน้ำส่วนกลางทั้งวัน
- เช็คลิสต์: พื้นห้องไม่มีเศษขยะ, ผ้าปูเตียงเปลี่ยนใหม่, สบู่/แชมพูเติมครบ, ถังขยะเทแล้ว, กระจกไม่มีรอยนิ้วมือ
- จุดพิเศษ: ลูกบิดประตูและปุ่มลิฟต์เช็ดด้วยผ้าสะอาดทุกรอบ 2 ชั่วโมง

## เกณฑ์คุณภาพ

- [ ] แบ่งโซนพื้นที่ชัดเจน ไม่มีจุดตกหล่น
- [ ] ระบุความถี่และผู้รับผิดชอบของแต่ละโซนอย่างชัดเจน
- [ ] เช็คลิสต์เป็นข้อความสั้น กาถูก/ผิดได้ทันที ไม่ใช่ประโยคยาว
- [ ] ไม่ระบุยี่ห้อหรือสูตรน้ำยาเคมีเฉพาะเจาะจง เตือนให้อ่านฉลากคำเตือนก่อนใช้เสมอ
- [ ] มีจุดสัมผัสบ่อยและจุดเสี่ยงลื่นระบุแยกไว้ให้เห็นชัด
- [ ] ภาษาที่ใช้เรียบง่าย อ่านแล้วนำไปปฏิบัติได้ทันทีโดยไม่ต้องอธิบายเพิ่ม
