# NDA Drafting Assistant

Skill นี้ช่วยร่าง **สัญญาไม่เปิดเผยข้อมูล (Non-Disclosure Agreement / NDA)** ฉบับเบื้องต้น จากข้อมูลที่ผู้ใช้ให้มา เช่น ชื่อคู่สัญญา ลักษณะความสัมพันธ์ (จะคุยเรื่องอะไรกัน) ประเภทข้อมูลที่ต้องการปกปิด และระยะเวลาที่ต้องการให้ข้อมูลนั้นถูกคุ้มครอง เหมาะสำหรับสถานการณ์ทั่วไป เช่น ก่อนคุยไอเดียธุรกิจกับนักลงทุน ก่อนจ้างฟรีแลนซ์เข้าถึงข้อมูลลูกค้า หรือก่อนเริ่ม due diligence กับพาร์ทเนอร์

ผลลัพธ์ที่ได้เป็น **ฉบับร่างเบื้องต้น (draft) สำหรับใช้เริ่มต้นการเจรจา** เท่านั้น ไม่ใช่เอกสารกฎหมายฉบับสมบูรณ์ที่พร้อมเซ็นทันที ผู้ใช้ควรให้ทนายความตรวจสอบและปรับให้เหมาะกับกฎหมายในเขตอำนาจศาลที่เกี่ยวข้องก่อนใช้งานจริงเสมอ

## เมื่อไหร่ควรใช้ skill นี้

- กำลังจะคุยไอเดียธุรกิจ แผนธุรกิจ หรือข้อมูลทางการเงินกับนักลงทุน/พาร์ทเนอร์ที่มีศักยภาพ และอยากมีเอกสารป้องกันก่อนเริ่มคุย
- จะจ้างฟรีแลนซ์ ที่ปรึกษา หรือ vendor ภายนอกที่ต้องเข้าถึงข้อมูลลูกค้า ข้อมูลภายใน หรือ source code
- ต้องแชร์ข้อมูลกับผู้สมัครงาน/พนักงานใหม่ ก่อนเริ่มงานจริง (เช่น ให้ดู business plan หรือ dataset)
- ทำ due diligence ก่อนการควบรวมกิจการ (M&A) หรือระดมทุน และต้องการ NDA คลุมช่วงเจรจา
- ต้องการ NDA แบบฝ่ายเดียว (unilateral — มีฝ่ายเดียวเปิดเผยข้อมูล) หรือแบบสองฝ่าย (mutual — เปิดเผยข้อมูลให้กันทั้งคู่)
- อยากได้ต้นแบบ (template) เพื่อนำไปปรับแก้ต่อเอง ก่อนส่งให้ทนายความ finalize

## ขั้นตอนการทำงาน

1. **เก็บข้อมูลพื้นฐานจากผู้ใช้** — ถ้าผู้ใช้ยังให้ข้อมูลไม่ครบ ให้ถามหรือระบุสมมติฐานที่ใช้แทนอย่างชัดเจน อย่างน้อยต้องมี:
   - ชื่อคู่สัญญาทั้งสองฝ่าย (หรือระบุ [ชื่อฝ่าย A] / [ชื่อฝ่าย B] ถ้ายังไม่ทราบ)
   - ประเภทความสัมพันธ์/วัตถุประสงค์ในการแชร์ข้อมูล (เช่น เจรจาการลงทุน, ว่าจ้างงาน, พันธมิตรทางธุรกิจ)
   - เป็น NDA แบบฝ่ายเดียว (unilateral) หรือสองฝ่าย (mutual)
   - ประเภทข้อมูลที่ต้องการคุ้มครอง (ข้อมูลลูกค้า, แผนธุรกิจ, ซอร์สโค้ด, สูตร/เทคนิคการผลิต ฯลฯ)
   - ระยะเวลาคุ้มครองความลับที่ต้องการ (เช่น 2 ปี, 5 ปี, หรือไม่มีกำหนด)
   - เขตอำนาจศาล/กฎหมายที่ใช้บังคับ (governing law) ถ้าผู้ใช้ไม่ระบุ ให้ตั้งสมมติฐานเป็นกฎหมายไทยและระบุไว้ให้ชัดว่าเป็นสมมติฐาน
2. **กำหนดขอบเขตนิยาม "ข้อมูลลับ" (Confidential Information)** — เขียนคำนิยามให้ครอบคลุมประเภทข้อมูลที่ผู้ใช้ต้องการคุ้มครอง แต่ไม่กว้างจนตีความไม่ได้ และระบุข้อยกเว้นมาตรฐาน (เช่น ข้อมูลที่เปิดเผยต่อสาธารณะอยู่แล้ว, ข้อมูลที่รู้อยู่ก่อนแล้ว, ข้อมูลที่ต้องเปิดเผยตามกฎหมาย)
3. **ร่างข้อผูกพันหลัก (Obligations)** — ระบุหน้าที่ของฝ่ายผู้รับข้อมูล เช่น ห้ามเปิดเผยต่อบุคคลที่สาม ห้ามใช้ข้อมูลนอกวัตถุประสงค์ที่ตกลงกัน ต้องเก็บรักษาข้อมูลด้วยความระมัดระวังตามมาตรฐาน
4. **ร่างระยะเวลาคุ้มครองและการคืน/ทำลายข้อมูล** — ระบุว่าความลับต้องถูกรักษาไว้นานเท่าใด และเมื่อสิ้นสุดความสัมพันธ์ ต้องคืนหรือทำลายเอกสาร/ข้อมูลอย่างไร
5. **ร่างเงื่อนไขอื่นที่จำเป็น** — เขตอำนาจศาล/กฎหมายที่ใช้บังคับ, วิธีระงับข้อพิพาท, ผลของการผิดสัญญา (เช่น สิทธิขอคำสั่งห้ามชั่วคราว/injunctive relief), และเงื่อนไขทั่วไป (severability, การแก้ไขสัญญาต้องทำเป็นหนังสือ)
6. **ประกอบร่างเต็มฉบับ** — จัดเรียงทุกส่วนตาม "โครงสร้าง Output" ด้านล่าง ใช้ภาษาสัญญาที่เป็นทางการแต่ยังอ่านเข้าใจได้ ใส่ [วงเล็บ] ในจุดที่ต้องกรอกข้อมูลเพิ่มเติมหรือปรับแต่งตามจริง
7. **สรุปจุดที่ผู้ใช้ควรตัดสินใจเพิ่มเติม** — เช่น ระยะเวลาคุ้มครองที่เหมาะสม, ควรระบุค่าปรับกรณีผิดสัญญาหรือไม่, ต้องการเขตอำนาจศาลที่ไหน
8. **ปิดท้ายด้วยคำแนะนำให้ทนายความตรวจสอบ** และแนบ disclaimer เสมอ

## โครงสร้าง Output

```
# ร่างสัญญาไม่เปิดเผยข้อมูล (Non-Disclosure Agreement) — ฉบับเบื้องต้น

หมายเหตุ: นี่คือฉบับร่างเบื้องต้นสำหรับเริ่มต้นการเจรจา ยังไม่ใช่เอกสารฉบับสมบูรณ์

ประเภท: [Unilateral / Mutual] NDA
คู่สัญญา: [ชื่อฝ่าย A] ("ผู้เปิดเผยข้อมูล/Disclosing Party") และ [ชื่อฝ่าย B] ("ผู้รับข้อมูล/Receiving Party")
วัตถุประสงค์ในการแชร์ข้อมูล: [ระบุวัตถุประสงค์]

---

**ข้อ 1. นิยามข้อมูลลับ (Confidential Information)**
[คำนิยามที่ครอบคลุมประเภทข้อมูลตามที่ผู้ใช้ระบุ พร้อมข้อยกเว้นมาตรฐาน]

**ข้อ 2. หน้าที่ของผู้รับข้อมูล**
[รายการข้อผูกพัน เช่น ห้ามเปิดเผย ห้ามใช้นอกวัตถุประสงค์ ต้องเก็บรักษาด้วยความระมัดระวัง]

**ข้อ 3. ระยะเวลาคุ้มครอง**
[ระยะเวลาที่ต้องรักษาความลับ เช่น X ปีนับจากวันลงนาม]

**ข้อ 4. การคืนหรือทำลายข้อมูล**
[เงื่อนไขเมื่อสิ้นสุดความสัมพันธ์]

**ข้อ 5. ผลของการผิดสัญญา**
[สิทธิเรียกร้องค่าเสียหาย / คำสั่งห้ามชั่วคราว]

**ข้อ 6. กฎหมายที่ใช้บังคับและการระงับข้อพิพาท**
[เขตอำนาจศาล/อนุญาโตตุลาการ]

**ข้อ 7. เงื่อนไขทั่วไป**
[Severability, การแก้ไขสัญญาต้องทำเป็นหนังสือ, ฉบับสมบูรณ์ของสัญญา]

ลงชื่อ ______________________ ผู้เปิดเผยข้อมูล      วันที่ ___________
ลงชื่อ ______________________ ผู้รับข้อมูล            วันที่ ___________

---

## จุดที่ควรตัดสินใจ/ปรับแต่งเพิ่มเติม
- ...
- ...

```

## ตัวอย่าง

**Input:** "ช่วยร่าง NDA ให้หน่อย บริษัทเราชื่อ ABC Tech จะคุยไอเดียแอปกับนักลงทุนรายหนึ่ง อยากคุ้มครองข้อมูลแผนธุรกิจกับข้อมูลผู้ใช้ต้นแบบ อยากได้แบบฝ่ายเดียวเพราะมีแต่เราที่เปิดเผยข้อมูล อยากคุ้มครอง 3 ปี"

**Output คร่าวๆ ที่ควรได้:**
- ระบุประเภท NDA เป็น Unilateral, ฝ่ายเปิดเผย = ABC Tech, ฝ่ายรับข้อมูล = [ชื่อนักลงทุน]
- นิยามข้อมูลลับครอบคลุม "แผนธุรกิจ" และ "ข้อมูลผู้ใช้ต้นแบบ (beta user data)" พร้อมข้อยกเว้นมาตรฐาน
- ระยะเวลาคุ้มครอง 3 ปีนับจากวันลงนาม
- ตั้งสมมติฐานกฎหมายไทยเป็น governing law พร้อมระบุไว้ชัดว่าเป็นสมมติฐานที่ควรยืนยันกับทนายความ
- ท้ายเอกสารสรุปจุดที่ควรตัดสินใจเพิ่ม เช่น ควรใส่ค่าปรับกรณีผิดสัญญาหรือไม่

## เกณฑ์คุณภาพ

- ระบุให้ชัดว่าเป็น Unilateral หรือ Mutual NDA ตั้งแต่ต้นฉบับ ไม่ปล่อยให้คลุมเครือ
- คำนิยาม "ข้อมูลลับ" ต้องครอบคลุมสิ่งที่ผู้ใช้ต้องการคุ้มครองจริง ไม่กว้างหรือแคบเกินไป
- ทุกจุดที่ยังขาดข้อมูล (ชื่อ, วันที่, เขตอำนาจศาล) ต้องใส่ [วงเล็บ] ให้ผู้ใช้กรอกเอง ไม่สมมติขึ้นเองโดยไม่บอก
- มีข้อยกเว้นมาตรฐานของคำนิยามข้อมูลลับเสมอ (ข้อมูลสาธารณะ, ข้อมูลที่รู้มาก่อน, ข้อมูลที่ต้องเปิดเผยตามกฎหมาย)
- สรุปจุดที่ผู้ใช้ควรตัดสินใจเพิ่มเติมไว้ท้ายเอกสารเสมอ
- ย้ำชัดเจนว่าเป็นฉบับร่างเบื้องต้น ต้องให้ทนายความตรวจสอบก่อนใช้งานจริง

> ⚠️ เนื้อหานี้เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางกฎหมาย ควรปรึกษาทนายความ/นักกฎหมายก่อนใช้งานจริงเสมอ
