# Hospitality & Personal Service Standard Writer

Skill นี้ช่วยเขียนมาตรฐานการให้บริการและ checklist ขั้นตอนปฏิบัติงานสำหรับกลุ่มพนักงานบริการส่วนบุคคล (ISCO-08 กลุ่มย่อย 51) ให้เป็นเอกสารที่ใช้ฝึกพนักงานใหม่ได้จริง ตรวจสอบคุณภาพงานประจำวันได้ และรักษามาตรฐานการบริการให้สม่ำเสมอไม่ว่าใครจะเข้ากะ

## เมื่อไหร่ควรใช้ skill นี้

- ต้องการเขียนมาตรฐานการต้อนรับแขกสำหรับพนักงานต้อนรับโรงแรมหรือแม่บ้านโรงแรม
- ต้องการ checklist ขั้นตอนบริการอาหาร-เครื่องดื่มสำหรับพนักงานเสิร์ฟ บาร์เทนเดอร์ หรือพ่อครัว/แม่ครัวทั่วไป (ไม่รวมเชฟผู้เชี่ยวชาญซึ่งจัดอยู่กลุ่มอาชีพเฉพาะทางอื่น)
- ต้องการโปรโตคอลงานเสริมสวยสำหรับช่างทำผม ช่างเสริมสวย หรือช่างสัก ที่ครอบคลุมความสะอาดและความปลอดภัยของลูกค้า
- ต้องการมาตรฐานงานสำหรับมัคคุเทศก์ พนักงานต้อนรับบนเครื่องบิน หรือผู้ดูแลสัตว์เลี้ยง
- ต้องการเอกสารสำหรับฝึกพนักงานใหม่ให้บริการได้มาตรฐานเดียวกันตั้งแต่วันแรก

## ขั้นตอนการทำงาน

### 1. ระบุตำแหน่งงานและจุดสัมผัสลูกค้า (touchpoint)
สอบถามหรือระบุให้ชัดว่าเป็นงานประเภทใด (ต้อนรับ/เสิร์ฟ/เสริมสวย/นำเที่ยว/ดูแลสัตว์) และลูกค้าจะเจอพนักงานตอนไหนบ้าง เช่น ก่อนเข้าใช้บริการ ระหว่างใช้บริการ และหลังใช้บริการ

### 2. กำหนดมาตรฐานรูปลักษณ์และการเตรียมตัวก่อนเริ่มงาน
ระบุมาตรฐานเครื่องแบบ ความสะอาดส่วนบุคคล อุปกรณ์ที่ต้องเตรียม และการตรวจสอบพื้นที่ทำงานก่อนเปิดให้บริการ

### 3. เขียนขั้นตอนการต้อนรับและเปิดการบริการ
ระบุคำทักทายมาตรฐาน ระยะเวลาที่ควรทักทายลูกค้า (เช่น ภายใน 30 วินาทีหลังลูกค้าเข้ามา) และวิธีสอบถามความต้องการเบื้องต้น

### 4. เขียนขั้นตอนการให้บริการหลัก
แตกเป็นขั้นตอนย่อยตามลำดับเวลาจริง เช่น สำหรับพนักงานเสิร์ฟ: รับออเดอร์ → ยืนยันรายการ → เสิร์ฟตามลำดับ → เช็คความพึงพอใจระหว่างมื้อ สำหรับช่างทำผม: ปรึกษาทรงผม → ยืนยันราคา → ให้บริการ → ตรวจสอบผลลัพธ์ร่วมกับลูกค้า

### 5. ระบุมาตรฐานความปลอดภัยและสุขอนามัยเฉพาะงาน
เช่น การล้างมือและฆ่าเชื้ออุปกรณ์สำหรับช่างทำผม/ช่างสัก การจัดการอาหารตามหลักสุขาภิบาลสำหรับครัว การดูแลความปลอดภัยสัตว์เลี้ยงและเจ้าของ

### 6. เขียนขั้นตอนการจัดการข้อร้องเรียนหรือสถานการณ์ไม่คาดคิด
ระบุขั้นตอนเบื้องต้นเมื่อลูกค้าไม่พอใจ เช่น รับฟัง ขอโทษ แก้ไขในอำนาจที่มี และเมื่อไหร่ต้องส่งต่อหัวหน้างาน

### 7. เขียนขั้นตอนปิดการบริการและส่งต่องาน
ระบุการเก็บพื้นที่ การบันทึกข้อมูลที่จำเป็น (เช่น รายการที่ลูกค้าชอบ) และการส่งต่อกะถัดไป

### 8. สรุปเป็น checklist ที่ใช้ตรวจสอบได้จริง
แปลงขั้นตอนทั้งหมดเป็นรายการเช็คสั้นๆ ที่พนักงานหรือหัวหน้างานกาเครื่องหมายได้ระหว่างหรือหลังกะ

## โครงสร้าง Output

```
=== มาตรฐานการให้บริการ: [ชื่อตำแหน่งงาน] ===
สถานประกอบการ: [ชื่อ/ประเภทธุรกิจ]
จุดสัมผัสลูกค้าที่ครอบคลุม: [ก่อน/ระหว่าง/หลังใช้บริการ]

1) การเตรียมตัวก่อนเริ่มงาน
   - [ ] [รายการเตรียมตัว 1]
   - [ ] [รายการเตรียมตัว 2]

2) ขั้นตอนการต้อนรับ/เปิดการบริการ
   - [ ] [ขั้นตอน 1]
   - [ ] [ขั้นตอน 2]

3) ขั้นตอนการให้บริการหลัก
   - [ ] [ขั้นตอน 1]
   - [ ] [ขั้นตอน 2]
   - [ ] [ขั้นตอน 3]

4) มาตรฐานความปลอดภัย/สุขอนามัย
   - [ ] [รายการ 1]
   - [ ] [รายการ 2]

5) การจัดการข้อร้องเรียน
   - [ ] [ขั้นตอนเบื้องต้น]
   - [ ] [เกณฑ์ส่งต่อหัวหน้างาน]

6) การปิดงาน/ส่งต่อกะ
   - [ ] [รายการ 1]
   - [ ] [รายการ 2]
```

## ตัวอย่าง

**Input:** ขอมาตรฐานการต้อนรับสำหรับพนักงานต้อนรับโรงแรมขนาดเล็ก (บูทีคโฮเทล 20 ห้อง)

**Output (คร่าวๆ):**
```
1) การเตรียมตัวก่อนเริ่มงาน
   - [ ] ตรวจสอบรายชื่อแขกที่จะเช็คอินวันนี้และห้องที่จัดไว้
   - [ ] เตรียมกุญแจห้อง เอกสารเช็คอิน และของต้อนรับ (ถ้ามี)

2) ขั้นตอนการต้อนรับ
   - [ ] ทักทายแขกภายใน 10 วินาทีหลังเข้าประตู พร้อมสบตาและยิ้ม
   - [ ] เรียกชื่อแขกถ้าทราบชื่อล่วงหน้า เพื่อสร้างความรู้สึกเป็นกันเอง

3) ขั้นตอนเช็คอิน
   - [ ] ยืนยันข้อมูลการจอง ระยะเวลาพัก และวิธีชำระเงิน
   - [ ] แจ้งสิ่งอำนวยความสะดวกหลักและเวลาเสิร์ฟอาหารเช้า
```

## เกณฑ์คุณภาพ

- [ ] ครอบคลุมทุกจุดสัมผัสลูกค้าตั้งแต่ก่อนถึงหลังใช้บริการ
- [ ] แต่ละขั้นตอนเป็นการกระทำที่ตรวจสอบได้จริง ไม่ใช่คำแนะนำกว้างๆ
- [ ] มีมาตรฐานความปลอดภัย/สุขอนามัยที่เหมาะกับลักษณะงานนั้นโดยเฉพาะ
- [ ] มีขั้นตอนจัดการข้อร้องเรียนหรือสถานการณ์ไม่คาดคิดอย่างชัดเจน
- [ ] ไม่อ้างมาตรฐานหรือกฎระเบียบเฉพาะขององค์กร/ใบอนุญาตที่ไม่มีข้อมูลยืนยัน ให้ระบุว่าต้องตรวจสอบกับหน่วยงานที่เกี่ยวข้องแทน
- [ ] เขียนเป็นภาษาที่พนักงานหน้างานอ่านและปฏิบัติตามได้ทันที ไม่ใช้ศัพท์วิชาการเกินจำเป็น
