# Farm Labour Daily Task Assignment Writer

Skill นี้ช่วยหัวหน้าทีมหรือเจ้าของแปลง/ฟาร์ม/เรือประมง เขียนใบมอบหมายงานประจำวันให้คนงานด้านการเกษตร ป่าไม้ และประมง (ISCO-08 กลุ่ม 92 — Skill Level 1) โดยระบุชัดว่าใครทำอะไร ที่จุดไหน และคาดหวังผลงานเท่าไหร่ในวันนั้น ช่วยลดความสับสนหน้างาน ตรวจสอบผลงานได้ง่าย และมีหลักฐานจ่ายค่าแรงที่ตรงกับงานจริง

## เมื่อไหร่ควรใช้ skill นี้

- หัวหน้าทีมคนงานรับจ้างเกษตรต้องการแบ่งงานประจำวันในแปลง
- หัวหน้าทีมตัดอ้อยต้องการกำหนดว่าใครตัดแปลงไหน คาดหวังกี่ตัน
- เจ้าของสวนผลไม้ต้องการแบ่งคนเก็บผลไม้ตามแปลง/ต้น พร้อมเป้าหมายจำนวนเข่ง/ตะกร้า
- ผู้จัดการฟาร์มต้องการมอบหมายงานให้ดูแลสัตว์ ให้อาหาร ทำความสะอาดคอก
- ต้นเรือ/ไต๋เรือประมงต้องการแบ่งหน้าที่คนงานบนเรือแต่ละเที่ยวออกเรือ
- หัวหน้าทีมงานป่าไม้ต้องการมอบหมายพื้นที่ปลูก/ตัดแต่ง/เก็บเกี่ยวไม้ประจำวัน

## ขั้นตอนการทำงาน

### 1. รวบรวมรายชื่อคนงานและจำนวนที่มีวันนี้
สอบถามว่าวันนี้มีคนงานกี่คน ใครมาบ้าง มีคนที่ทำงานเฉพาะทาง (เช่น ขับรถแทรกเตอร์ได้) หรือไม่

### 2. แบ่งพื้นที่หรือจุดทำงานให้ชัดเจน
ระบุแปลง/แถว/บ่อ/จุดจับปลาที่ต้องทำงานวันนี้ ตั้งชื่อหรือหมายเลขให้จำง่าย เช่น แปลง A, แถว 1-10, บ่อเลี้ยงหมายเลข 2

### 3. จับคู่คนงานกับงานและจุด
มอบหมายให้ชัดว่าใครทำงานอะไรที่จุดไหน เช่น สมชาย-ตัดอ้อยแปลง A, มาลี-เก็บผลไม้แปลง B โดยพิจารณาความถนัดและระยะทางเดินให้เหมาะสม

### 4. กำหนดเป้าหมายผลงานที่คาดหวังของแต่ละคน/ทีม
ระบุจำนวนที่คาดหวังให้ชัด เช่น ตัดอ้อยให้ได้ [X] ตัน, เก็บผลไม้ให้ได้ [X] เข่ง, ให้อาหารสัตว์ครบ [X] คอกภายในเที่ยง เพื่อให้คนงานรู้เป้าหมายตั้งแต่เริ่มงาน

### 5. ระบุเวลาเริ่ม-เลิกงานและจุดนัดพบ
บอกเวลาเริ่มงาน เวลาพักเที่ยง เวลาเลิกงาน และจุดนัดรวมพลตอนเช้า/จุดส่งมอบผลผลิตตอนเย็น

### 6. เตือนอุปกรณ์และความปลอดภัยเบื้องต้นที่ต้องเตรียม
ระบุอุปกรณ์ที่แต่ละคนต้องพกมาเอง (มีด เคียว ตะกร้า รองเท้าบูท) และเตือนจุดเสี่ยงในพื้นที่วันนั้น เช่น พื้นที่ลื่นหลังฝนตก สัตว์มีพิษในแปลง

### 7. สรุปเป็นใบงานแจกหรือติดบอร์ดก่อนเริ่มงาน
รวมทุกส่วนเป็นเอกสารสั้น อ่านออกเสียงให้ทีมฟังตอนเช้าได้ หรือติดบอร์ดจุดรวมพล

## โครงสร้าง Output

```
=== ใบมอบหมายงานประจำวัน [ชื่อฟาร์ม/ทีม] ===
วันที่: [ระบุ]  จุดนัดพบตอนเช้า: [ระบุ]  เวลาเริ่ม-เลิกงาน: [ระบุ]

1) มอบหมายงานรายบุคคล/ทีมย่อย
   [ชื่อคนงาน/ทีม] | [งานที่ทำ] | [จุด/แปลง] | [เป้าหมายผลงานวันนี้]

2) อุปกรณ์ที่ต้องเตรียมเอง
   - [รายการอุปกรณ์]

3) จุดเสี่ยง/ข้อควรระวังวันนี้
   - [จุดเสี่ยง]: [สิ่งที่ต้องทำเพื่อความปลอดภัย]

4) จุดส่งมอบผลผลิต/รายงานผลตอนเย็น
   เวลา: [ระบุ]  จุดส่งมอบ: [ระบุ]
```

## ตัวอย่าง

**Input:** หัวหน้าทีมตัดอ้อยมีคนงาน 6 คน แปลงอ้อยแบ่งเป็น A และ B วันนี้ต้องการตัดให้เสร็จก่อนฝนตก

**Output (คร่าวๆ):**
- มอบหมายงาน: สมชาย, ดำ, แดง ตัดอ้อยแปลง A เป้าหมาย 4 ตัน / มาลี, สมศรี, จันทร์ ตัดอ้อยแปลง B เป้าหมาย 4 ตัน
- อุปกรณ์: มีดตัดอ้อยของตัวเอง, ถุงมือหนา, รองเท้าบูท
- จุดเสี่ยง: พื้นแปลง B ลื่นเพราะฝนตกเมื่อคืน ให้เดินระวังทางลาด
- ส่งมอบผลผลิต: เวลา 16:00 น. จุดชั่งน้ำหนักหน้าโรงเก็บ

## เกณฑ์คุณภาพ

- [ ] ระบุชื่อคนงาน งาน และจุดทำงานครบทุกคนที่มาในวันนั้น
- [ ] มีเป้าหมายผลงานที่จับต้องได้ (จำนวน/หน่วยที่ชัดเจน) ไม่ใช่แค่บอกให้ "ไปทำงาน"
- [ ] ระบุเวลาเริ่ม-เลิกงานและจุดนัดพบชัดเจน
- [ ] มีจุดเสี่ยง/ข้อควรระวังของวันนั้นโดยเฉพาะ ไม่ใช่คำเตือนทั่วไปที่ใช้ซ้ำทุกวัน
- [ ] ภาษาที่ใช้เข้าใจง่าย อ่านให้ทีมฟังตอนเช้าแล้วลงมือทำได้ทันที
