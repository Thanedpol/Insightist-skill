# Executive Strategic Memo Writer

Skill นี้ช่วยผู้บริหารระดับสูง ข้าราชการอาวุโส และผู้บัญญัติกฎหมาย แปลงความคิดเชิงกลยุทธ์หรือประเด็นที่ต้องตัดสินใจให้เป็นเอกสารทางการที่กระชับ มีน้ำหนัก และพร้อมส่งต่อให้คณะกรรมการ สภา หรือทั้งองค์กรอ่านแล้วตัดสินใจหรือรับทราบได้ทันที โดยไม่ต้องเสียเวลาตีความหรือถามกลับ

## เมื่อไหร่ควรใช้ skill นี้

- CEO หรือกรรมการผู้จัดการต้องการเสนอทิศทางกลยุทธ์ใหม่ให้คณะกรรมการบริษัทพิจารณาอนุมัติ
- ปลัดกระทรวงหรืออธิบดีต้องร่างบันทึกเสนอนโยบายหรือสรุปประเด็นให้รัฐมนตรี/ผู้บังคับบัญชาตัดสินใจ
- ส.ส./ส.ว. ต้องการร่างแถลงการณ์จุดยืนนโยบาย หรือสรุปเหตุผลประกอบการเสนอญัตติ
- นายกเทศมนตรีต้องประกาศนโยบายหรือแผนงานใหม่ให้ประชาชนหรือสภาเทศบาลรับทราบ
- ผู้นำองค์กรไม่แสวงหากำไรหรือผู้นำสหภาพแรงงานต้องการแถลงจุดยืนต่อสมาชิกหรือคู่เจรจาอย่างเป็นทางการ
- ต้องการร่างมติที่ประชุมคณะกรรมการให้มีผลผูกพันและตรวจสอบย้อนหลังได้

## ขั้นตอนการทำงาน

### 1. กำหนดวัตถุประสงค์และผู้อ่านเป้าหมาย
ระบุให้ชัดว่าเอกสารนี้ต้องการอะไรจากผู้อ่าน — ขออนุมัติ, ขอมติ, แจ้งเพื่อทราบ, หรือประกาศจุดยืน — และผู้อ่านคือใคร (คณะกรรมการ, สภา, พนักงานทั้งองค์กร, สื่อมวลชน) เพราะจะกำหนดโทนและระดับรายละเอียดที่ต่างกัน

### 2. รวบรวมข้อเท็จจริงและบริบทประกอบการตัดสินใจ
รวบรวมข้อมูลพื้นหลัง (background), สถานการณ์ปัจจุบัน, และเหตุผลที่ต้องตัดสินใจตอนนี้ ถ้ามีตัวเลขหรือข้อมูลอ้างอิง ให้ใช้เฉพาะที่มีแหล่งที่มายืนยันได้ ห้ามเติมตัวเลขที่ไม่แน่ใจ

### 3. วางโครงเรื่องแบบ "สรุปก่อน รายละเอียดทีหลัง" (BLUF)
เริ่มด้วยประเด็น/ข้อเสนอหลักใน 2-3 ประโยคแรก (Bottom Line Up Front) ก่อนอธิบายเหตุผลและรายละเอียด เพื่อให้ผู้บริหารที่มีเวลาจำกัดจับประเด็นได้ทันทีแม้อ่านแค่ย่อหน้าแรก

### 4. ระบุทางเลือกและข้อเสนอแนะอย่างชัดเจน
ถ้าเป็นเอกสารขอการตัดสินใจ ให้เสนอทางเลือก 2-3 ทาง พร้อมข้อดี-ข้อเสีย และความเสี่ยงของแต่ละทาง แล้วปิดท้ายด้วยข้อเสนอแนะที่ชัดเจนว่าควรเลือกทางไหนและเพราะอะไร

### 5. ร่างส่วนมติ/ข้อเรียกร้องให้ปฏิบัติได้จริง (Action/Resolution)
เขียนสิ่งที่ต้องการให้เกิดขึ้นเป็นประโยคปฏิบัติได้ทันที เช่น "ขอให้คณะกรรมการอนุมัติงบประมาณ X บาท ภายในไตรมาสที่ Y" ระบุผู้รับผิดชอบ กรอบเวลา และเงื่อนไขที่ต้องมี (ถ้ามี)

### 6. ตรวจสอบโทนและความเป็นทางการ
ปรับภาษาให้เหมาะกับระดับผู้อ่านและบริบท (สื่อสารภายในองค์กร vs. แถลงต่อสาธารณะ vs. เอกสารทางราชการ) หลีกเลี่ยงคำฟุ่มเฟือย ใช้ประโยคสั้น ตรงประเด็น และคงความเป็นกลางเมื่อพูดถึงประเด็นที่มีความอ่อนไหวทางการเมืองหรือแรงงาน

### 7. ตรวจทานความเสี่ยงเชิงกฎหมายและข้อเท็จจริง
ก่อนส่งจริง ให้ทำเครื่องหมายจุดที่อ้างอิงกฎหมาย ระเบียบ หรือตัวเลขที่ผู้เขียนไม่มั่นใจ 100% และแนะนำให้ตรวจสอบกับฝ่ายกฎหมาย เลขานุการบริษัท หรือหน่วยงานที่เกี่ยวข้องก่อนเผยแพร่จริง

## โครงสร้าง Output

```
บันทึกข้อความ / MEMO
เรื่อง: [หัวข้อ]
ถึง: [ผู้รับ]
จาก: [ผู้เขียน/ตำแหน่ง]
วันที่: [วันที่]

1) สรุปประเด็น (Executive Summary)
   [2-3 ประโยค สรุปสิ่งที่ต้องการให้ผู้อ่านรู้/ตัดสินใจ]

2) บริบทและที่มา (Background)
   [สถานการณ์ปัจจุบัน เหตุผลที่ต้องพิจารณาเรื่องนี้ตอนนี้]

3) ทางเลือกและการวิเคราะห์ (Options)
   - ทางเลือก A: [รายละเอียด] → ข้อดี / ข้อเสีย / ความเสี่ยง
   - ทางเลือก B: [รายละเอียด] → ข้อดี / ข้อเสีย / ความเสี่ยง

4) ข้อเสนอแนะ (Recommendation)
   [ทางเลือกที่แนะนำ พร้อมเหตุผลสนับสนุน]

5) ข้อเสนอมติ/สิ่งที่ขอให้พิจารณา (Resolution / Ask)
   [ประโยคปฏิบัติได้จริง ระบุผู้รับผิดชอบและกรอบเวลา]

6) ภาคผนวก/เอกสารอ้างอิง (ถ้ามี)
```

## ตัวอย่าง

**Input:** กรรมการผู้จัดการต้องการเสนอคณะกรรมการบริษัทให้อนุมัติแผนขยายสาขาไปต่างจังหวัด 3 แห่งในปีหน้า

**Output (คร่าวๆ):**
"เรียน คณะกรรมการบริษัท — ฝ่ายบริหารขอเสนอแผนขยายสาขาไปยัง 3 จังหวัดในปี 2569 เพื่อรองรับดีมานด์ที่เติบโตในภูมิภาค... ทางเลือกที่ 1 ขยายพร้อมกันทั้ง 3 แห่ง (เร็วแต่เสี่ยงด้านเงินทุน) ทางเลือกที่ 2 ทยอยเปิดทีละแห่งเริ่มจากจังหวัดที่มีศักยภาพสูงสุด (ช้ากว่าแต่บริหารความเสี่ยงได้ดีกว่า)... ฝ่ายบริหารขอเสนอทางเลือกที่ 2 และขอให้คณะกรรมการอนุมัติงบลงทุนสาขาแรกภายในไตรมาส 2/2569"

## เกณฑ์คุณภาพ

- [ ] ขึ้นต้นด้วยสรุปประเด็นหลัก (BLUF) ก่อนรายละเอียด ไม่ให้ผู้อ่านต้องไล่หาใจความเอง
- [ ] มีข้อเสนอแนะที่ชัดเจนเป็นรูปธรรม ไม่ใช่แค่นำเสนอข้อมูลลอยๆ โดยไม่สรุป
- [ ] ระบุผู้รับผิดชอบและกรอบเวลาในส่วนมติ/ข้อเรียกร้องอย่างชัดเจน
- [ ] โทนและความเป็นทางการเหมาะสมกับผู้อ่านเป้าหมายและบริบท (บอร์ด/สภา/สาธารณะ)
- [ ] ห้ามกุตัวเลข/ระเบียบ/กฎหมายที่ไม่แน่ใจ — ถ้าไม่มีข้อมูลจริงให้ระบุว่าควรตรวจสอบกับผู้เชี่ยวชาญ/แหล่งข้อมูลทางการก่อนใช้จริง
- [ ] รักษาความเป็นกลางและความรอบคอบเมื่อพูดถึงประเด็นอ่อนไหวทางการเมือง แรงงาน หรือกฎหมาย
