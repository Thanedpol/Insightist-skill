# Machine Repair Service Report Writer

Skill นี้ช่วยช่างโลหะ เครื่องจักร และงานที่เกี่ยวข้องบันทึกงานซ่อมให้เป็นระบบและตรวจสอบย้อนกลับได้ ทั้งรายงานผลการซ่อม (วินิจฉัยอาการ → อะไหล่ที่ใช้ → ค่าแรง → ผลตรวจก่อน-หลัง) และตารางแผนบำรุงรักษาที่ช่วยลดการเสียซ้ำ เหมาะสำหรับอู่ซ่อมรถ ศูนย์ซ่อมเครื่องจักร หรือช่างอิสระที่ต้องส่งมอบเอกสารที่ลูกค้าเชื่อถือได้

## เมื่อไหร่ควรใช้ skill นี้

- ช่างซ่อมรถยนต์หรือช่างซ่อมจักรยานยนต์ต้องการทำใบรายงานผลการซ่อมให้ลูกค้าหลังนำรถเข้าอู่
- ช่างกลึงหรือช่างทำแม่พิมพ์ต้องการบันทึกงานซ่อม/ปรับแต่งชิ้นงานให้โรงงานลูกค้า
- ช่างเชื่อมหรือช่างตีเหล็กต้องการรายงานงานซ่อมโครงสร้างโลหะพร้อมรายการอะไหล่/วัสดุที่ใช้
- ช่างซ่อมอากาศยานต้องการเอกสารตรวจสภาพก่อน-หลังซ่อมที่ตรวจสอบย้อนกลับได้
- หัวหน้าศูนย์ซ่อมต้องการวางตารางแผนบำรุงรักษาเชิงป้องกันสำหรับเครื่องจักรหรือยานพาหนะ

## ขั้นตอนการทำงาน

### 1. บันทึกข้อมูลรับเรื่อง
รวบรวมข้อมูลตั้งต้น: ชื่อลูกค้า, รุ่น/หมายเลขเครื่อง-ยานพาหนะ, เลขไมล์หรือชั่วโมงใช้งาน (ถ้ามี), อาการที่ลูกค้าแจ้งมาด้วยคำพูดของลูกค้าเอง, วันที่รับเรื่อง

### 2. วินิจฉัยอาการ
ระบุขั้นตอนตรวจวินิจฉัยที่ทำจริง (ตรวจด้วยตา, เครื่องมือวัด, สแกนคอมพิวเตอร์, ทดลองเดินเครื่อง) และสรุปสาเหตุที่พบ แยกให้ชัดระหว่าง "อาการที่ลูกค้าแจ้ง" กับ "สาเหตุที่แท้จริงที่ตรวจพบ" เพราะอาจไม่ตรงกัน

### 3. แจกแจงรายการอะไหล่ที่ใช้
ลิสต์อะไหล่แต่ละชิ้น พร้อมยี่ห้อ/รหัสอะไหล่ (ถ้ามี) ราคาต่อชิ้น และจำนวน แยกให้เห็นว่าเป็นอะไหล่แท้ เทียบ หรือใช้แล้ว (มือสอง) เพื่อความโปร่งใสกับลูกค้า

### 4. คำนวณค่าแรง
ระบุงานที่ทำแต่ละขั้นตอน (ถอด/เปลี่ยน/ประกอบ/ตั้งค่า) พร้อมเวลาที่ใช้และอัตราค่าแรง แยกจากค่าอะไหล่ให้ชัดเจน

### 5. บันทึกผลตรวจก่อน-หลังซ่อม
ระบุค่าที่วัดได้ก่อนซ่อม (เช่น รอบเดินเบา, แรงดันน้ำมัน, ระยะเบรก) เทียบกับค่าหลังซ่อม เพื่อยืนยันว่าการซ่อมแก้ปัญหาได้จริง ถ้าวัดค่าไม่ได้ให้ระบุว่าใช้การทดลองใช้งานแทน

### 6. สรุปผลและข้อแนะนำ
สรุปว่าอาการที่แจ้งได้รับการแก้ไขแล้วหรือยัง มีจุดใดที่ควรติดตามต่อ หรือมีความเสี่ยงที่จะเสียซ้ำในอนาคตหรือไม่

### 7. จัดทำตารางแผนบำรุงรักษา
ระบุรายการตรวจเช็กตามระยะ (เช่น ทุก 5,000 กม./ทุก 500 ชั่วโมงทำงาน) พร้อมงานที่ต้องทำในแต่ละรอบ และวันที่/ระยะครบกำหนดครั้งถัดไป

## โครงสร้าง Output

```
=== รายงานผลการซ่อม ===
ลูกค้า: [ชื่อ]   เครื่อง/ยานพาหนะ: [รุ่น/เลขที่]   วันที่รับเรื่อง: [วันที่]
อาการที่แจ้ง: [คำอธิบายจากลูกค้า]

1) ผลการวินิจฉัย
   สาเหตุที่พบ: [...]
   วิธีตรวจ: [...]

2) รายการอะไหล่
   - [ชื่ออะไหล่] | รหัส/ยี่ห้อ [...] | จำนวน [X] | ราคา/หน่วย [บาท] | รวม [บาท]

3) ค่าแรง
   - [งานที่ทำ] | เวลา [X ชม.] | รวม [บาท]

4) ผลตรวจก่อน-หลังซ่อม
   [รายการที่วัด] | ก่อนซ่อม: [ค่า] | หลังซ่อม: [ค่า]

รวมค่าใช้จ่าย: [บาท]
สรุปผล: [...]
ข้อแนะนำ/จุดที่ควรติดตาม: [...]

=== ตารางแผนบำรุงรักษา ===
| รอบระยะ | รายการตรวจเช็ก | ครบกำหนดครั้งถัดไป |
|---|---|---|
| [X กม./ชม.] | [...] | [วันที่/ระยะ] |
```

## ตัวอย่าง

**Input:** ลูกค้านำรถกระบะเข้าซ่อมเพราะเครื่องยนต์สั่นตอนเดินเบา ช่างตรวจพบหัวเทียนเสื่อมสภาพ

**Output (คร่าวๆ):**
- อาการที่แจ้ง: "เครื่องสั่นตอนจอดติดเครื่อง"
- สาเหตุที่พบ: หัวเทียนสึกและมีคราบเขม่าเกินมาตรฐาน 3 จาก 4 หัว
- อะไหล่: หัวเทียนแท้ 4 หัว × 250 บาท = 1,000 บาท
- ค่าแรง: ถอด-เปลี่ยนหัวเทียนและตั้งเครื่อง 1 ชม. = 300 บาท
- ก่อนซ่อม: รอบเดินเบา 550-900 รอบ/นาที (ไม่คงที่) → หลังซ่อม: 750 รอบ/นาที (คงที่)
- แผนบำรุงรักษา: ตรวจหัวเทียนทุก 20,000 กม. ครั้งถัดไปกำหนดที่เลขไมล์ 105,000 กม.

## เกณฑ์คุณภาพ

- [ ] แยกอาการที่ลูกค้าแจ้งออกจากสาเหตุที่ตรวจพบจริงอย่างชัดเจน
- [ ] แจกแจงอะไหล่และค่าแรงแยกรายการ ไม่รวมเป็นยอดเดียว
- [ ] มีผลตรวจก่อน-หลังซ่อมเป็นตัวเลขหรือผลทดลองใช้งานที่ตรวจสอบได้ ไม่ใช่แค่คำว่า "ซ่อมเสร็จแล้ว"
- [ ] ตารางแผนบำรุงรักษาระบุรอบระยะและวันที่/เลขไมล์ครั้งถัดไปชัดเจน
- [ ] ไม่สรุปว่าอาการหายขาดถ้ายังไม่ได้ทดสอบยืนยันจริง ให้ระบุความไม่แน่นอนตามจริง
- [ ] ไม่กุตัวเลขราคาอะไหล่หรือค่ามาตรฐานที่ไม่มีที่มา ให้ระบุว่าต้องอ้างอิงราคาจริงจากร้าน/คู่มือเครื่อง
