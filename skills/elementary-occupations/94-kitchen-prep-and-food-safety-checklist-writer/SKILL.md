# Kitchen Prep and Food Safety Checklist Writer

Skill นี้ช่วยผู้ช่วยเตรียมอาหาร (ISCO-08 กลุ่ม 94 — Skill Level 1) เขียนเช็คลิสต์เตรียมอาหารประจำวันและเช็คลิสต์สุขอนามัยพื้นฐานในครัว เพื่อให้งานเตรียมของไม่ตกหล่นและลดความเสี่ยงอาหารปนเปื้อน **เช็คลิสต์นี้เป็นแนวทางสุขอนามัยทั่วไปสำหรับใช้งานหน้าครัวเท่านั้น ไม่ใช่การรับรองมาตรฐานความปลอดภัยอาหารอย่างเป็นทางการ** มาตรฐานอุณหภูมิและข้อกำหนดเฉพาะทางกฎหมายต้องตรวจสอบกับหน่วยงานสาธารณสุขในพื้นที่หรือสำนักงานคณะกรรมการอาหารและยา (อย.)

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ช่วยในครัวร้านอาหารต้องการเช็คลิสต์เตรียมวัตถุดิบก่อนเปิดร้าน
- พนักงานล้างจานต้องการเช็คลิสต์ล้าง-เก็บภาชนะให้ถูกสุขอนามัย
- พนักงานเตรียมอาหารจานด่วนต้องการเช็คลิสต์เตรียมของก่อนช่วงพีคลูกค้าเยอะ
- หัวหน้าครัวขนาดเล็กต้องการมอบเช็คลิสต์มาตรฐานให้ผู้ช่วยครัวทำตามทุกวัน
- ต้องการเช็คลิสต์ล้างมือและป้องกันการปนเปื้อนข้ามระหว่างวัตถุดิบดิบ-สุก

## ขั้นตอนการทำงาน

### 1. รวบรวมรายการงานเตรียมอาหารประจำวัน
สอบถามเมนูหรือวัตถุดิบหลักที่ต้องเตรียมก่อนเปิดร้าน เช่น ล้าง-หั่นผัก, หมักเนื้อ, ต้มน้ำซุป, จัดเตรียมเครื่องปรุง

### 2. จัดลำดับงานเตรียมตามเวลาก่อนเปิดร้าน
เรียงงานตามลำดับที่ควรทำก่อน-หลัง เช่น 1 ชั่วโมงก่อนเปิด: ล้างผัก, 30 นาทีก่อนเปิด: หั่นเตรียมพร้อมปรุง เพื่อให้ของสดพร้อมใช้ตอนลูกค้ามา

### 3. ทำเช็คลิสต์ล้างมือและสุขอนามัยส่วนบุคคล
ระบุจุดที่ต้องล้างมือเสมอ เช่น ก่อนเริ่มงาน, หลังจับเนื้อดิบ, หลังเข้าห้องน้ำ, หลังจับขยะ และเตือนเรื่องผูกผมมิดชิด ล้างมือด้วยสบู่อย่างน้อย 20 วินาที

### 4. ทำเช็คลิสต์แยกเก็บวัตถุดิบป้องกันปนเปื้อนข้าม
ระบุหลักการทั่วไป เช่น เก็บเนื้อดิบไว้ชั้นล่างสุดของตู้เย็นแยกจากของสุก/ผักสด, ใช้เขียง-มีดแยกสีสำหรับดิบและสุก, ไม่ใช้ผ้าเช็ดโต๊ะผืนเดียวกันกับเช็ดพื้นผิวที่โดนเนื้อดิบ

### 5. ทำเช็คลิสต์สังเกตความสดและการจัดเก็บ
ระบุสิ่งที่ต้องสังเกตด้วยตา/จมูก เช่น กลิ่นผิดปกติ สีเปลี่ยน วันหมดอายุบนฉลาก **ไม่ระบุตัวเลขอุณหภูมิเก็บรักษาที่เจาะจงเป็นมาตรฐานตายตัว** ให้ระบุแทนว่าต้องยึดตามคำแนะนำของหน่วยงานสาธารณสุข/อย. ในพื้นที่

### 6. สรุปเป็นเช็คลิสต์ที่ใช้กาถูก/ผิดหน้างานได้จริง
รวมทุกส่วนเป็นแผ่นเดียว ใช้ภาษาสั้นกระชับ ติดผนังครัวหรือพกติดตัวได้

### 7. ระบุข้อจำกัดของเช็คลิสต์ให้ชัดเจน
ปิดท้ายด้วยข้อความว่านี่คือเช็คลิสต์สุขอนามัยทั่วไป ไม่ใช่ใบรับรองมาตรฐานความปลอดภัยอาหารอย่างเป็นทางการ หากต้องการมาตรฐานที่ใช้ยื่นขออนุญาตหรือรับรอง ต้องติดต่อสาธารณสุขจังหวัดหรือ อย. โดยตรง

## โครงสร้าง Output

```
=== เช็คลิสต์เตรียมอาหารและสุขอนามัย [ชื่อร้าน/ครัว] ===
วันที่: [ระบุ]  ผู้รับผิดชอบ: [ระบุ]

1) เช็คลิสต์เตรียมอาหารก่อนเปิดร้าน
   - [ ] [งานเตรียมที่ 1] เวลา [ระบุ]
   - [ ] [งานเตรียมที่ 2] เวลา [ระบุ]

2) เช็คลิสต์ล้างมือ/สุขอนามัยส่วนบุคคล
   - [ ] ล้างมือก่อนเริ่มงาน
   - [ ] ล้างมือหลังจับเนื้อดิบ/เข้าห้องน้ำ/จับขยะ
   - [ ] ผูกผมมิดชิด สวมผ้ากันเปื้อนสะอาด

3) เช็คลิสต์ป้องกันปนเปื้อนข้าม
   - [ ] แยกเก็บของดิบ-สุกในตู้เย็น
   - [ ] แยกเขียง/มีดดิบ-สุก
   - [ ] แยกผ้าเช็ดพื้นผิวที่โดนของดิบ

4) เช็คลิสต์สังเกตความสดและวันหมดอายุ
   - [ ] ตรวจกลิ่น/สี วัตถุดิบก่อนใช้
   - [ ] ตรวจวันหมดอายุบนฉลาก

หมายเหตุ: เช็คลิสต์นี้เป็นแนวทางสุขอนามัยทั่วไป ไม่ใช่มาตรฐานรับรองความปลอดภัยอาหารอย่างเป็นทางการ ควรตรวจสอบข้อกำหนดเฉพาะกับสาธารณสุขจังหวัด/อย.
```

## ตัวอย่าง

**Input:** ร้านอาหารจานด่วนเล็กๆ ต้องการเช็คลิสต์เตรียมของก่อนเปิดร้าน 07:00 น. และเช็คลิสต์สุขอนามัยประจำวัน

**Output (คร่าวๆ):**
- เตรียมอาหาร: 06:00 ล้างผักและหั่นเตรียม, 06:30 หมักเนื้อไก่/หมู, 06:50 ต้มน้ำซุปให้เดือด
- สุขอนามัย: ล้างมือก่อนเริ่มงานและทุกครั้งหลังจับเนื้อดิบ, สวมผ้ากันเปื้อนสะอาดทุกวัน
- ป้องกันปนเปื้อนข้าม: เก็บไก่ดิบชั้นล่างสุดของตู้เย็น แยกจากผักสดชั้นบน ใช้เขียงสีแดงสำหรับของดิบเท่านั้น
- ความสด: ตรวจกลิ่นเนื้อก่อนหมักทุกเช้า ถ้ามีกลิ่นผิดปกติให้แจ้งหัวหน้าครัวทันที ไม่ใช้ต่อ

## เกณฑ์คุณภาพ

- [ ] มีเช็คลิสต์เตรียมอาหารเรียงตามลำดับเวลาก่อนเปิดร้าน
- [ ] มีเช็คลิสต์ล้างมือและสุขอนามัยส่วนบุคคลครบตามจุดสำคัญ
- [ ] มีเช็คลิสต์ป้องกันการปนเปื้อนข้ามระหว่างของดิบและของสุก
- [ ] **ห้ามระบุตัวเลขอุณหภูมิหรือมาตรฐานกฎหมายเฉพาะเจาะจงว่าเป็นมาตรฐานทางการ** และต้องมีข้อความระบุชัดว่านี่ไม่ใช่การรับรองมาตรฐานความปลอดภัยอาหารอย่างเป็นทางการ ให้ตรวจสอบกับสาธารณสุขจังหวัด/อย. เสมอ
- [ ] เช็คลิสต์เป็นข้อความสั้น กาถูก/ผิดได้ทันทีหน้างาน
- [ ] ภาษาที่ใช้เข้าใจง่าย ไม่ใช้ศัพท์เทคนิคด้านจุลชีววิทยาหรือกฎหมายอาหาร
