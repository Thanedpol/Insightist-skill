# Crop and Livestock Farm Plan Writer

Skill นี้ช่วยเกษตรกรมีฝีมือเพื่อการค้า (ISCO-08 กลุ่ม 61) เขียนแผนการผลิตพืชหรือปศุสัตว์ประจำฤดูกาล/ประจำปี ให้เป็นระบบ มีตารางกำหนดการใช้ปัจจัยการผลิต แบบติดตามต้นทุน-ผลผลิตที่ใช้งานได้จริงในแปลง/ฟาร์ม และเช็คลิสต์เฝ้าระวังศัตรูพืชหรือโรคสัตว์เบื้องต้น เพื่อให้วางแผนการผลิตได้ล่วงหน้า ลดความเสี่ยงขาดทุน และมีข้อมูลไว้ทบทวนทุกฤดูกาล กลุ่มอาชีพนี้เป็นกลุ่มอาชีพที่ใหญ่ที่สุดในประเทศไทย คิดเป็น 27.40% ของกำลังแรงงานทั้งหมด (ข้อมูลสำนักงานสถิติแห่งชาติ อ้างอิงมาตรฐาน ISCO-08)

## เมื่อไหร่ควรใช้ skill นี้

- ชาวนาต้องการวางแผนการทำนาตั้งแต่เตรียมดินจนถึงเก็บเกี่ยว
- ชาวไร่อ้อย/มันสำปะหลัง/ข้าวโพด ต้องการตารางใส่ปุ๋ยและกำหนดรอบปลูก-เก็บเกี่ยว
- ชาวสวนยาง หรือชาวสวนผลไม้ ต้องการวางแผนกรีดยาง/ดูแลสวนตามฤดูกาล
- ผู้ปลูกผัก ต้องการวางแผนปลูกหมุนเวียนหลายรอบต่อปี
- ผู้เลี้ยงไก่/สุกร/โคนม หรือผู้เลี้ยงผึ้ง ต้องการตารางให้อาหารและติดตามสุขภาพสัตว์
- เกษตรกรผสมผสาน ต้องการแผนจัดสรรพื้นที่และเวลาให้หลายกิจกรรมพร้อมกัน

## ขั้นตอนการทำงาน

### 1. เก็บข้อมูลพื้นฐานของแปลง/ฟาร์ม
สอบถามหรือรวบรวม: ชนิดพืช/สัตว์ที่จะผลิต, พื้นที่/จำนวนตัว, ฤดูกาลหรือช่วงเวลาที่จะเริ่ม, ประสบการณ์เดิม (เคยปลูก/เลี้ยงมาก่อนหรือไม่ ผลลัพธ์เป็นอย่างไร), แหล่งน้ำและข้อจำกัดด้านทรัพยากร

### 2. กำหนดปฏิทินการผลิตตามฤดูกาล
แบ่งช่วงเวลาเป็นระยะสำคัญ เช่น เตรียมดิน/เตรียมโรงเรือน → ปลูก/นำสัตว์เข้าเลี้ยง → ดูแลระหว่างเติบโต → เก็บเกี่ยว/จับขาย โดยอ้างอิงฤดูกาลจริงของพื้นที่ (ฤดูฝน/แล้ง/หนาว) และรอบชีวิตของพืช/สัตว์ชนิดนั้นๆ

### 3. ทำตารางกำหนดการใช้ปัจจัยการผลิต
จัดตารางว่าแต่ละสัปดาห์/เดือนต้องใช้อะไรบ้าง เช่น เมล็ดพันธุ์/พันธุ์สัตว์, ปุ๋ย (ระบุแค่ประเภทและช่วงเวลาใส่ เช่น ปุ๋ยรองพื้น/ปุ๋ยแต่งหน้า ไม่ระบุสูตรหรือปริมาณสารเคมีเฉพาะเจาะจง), อาหารสัตว์/หัวอาหาร, แรงงานที่ต้องใช้ในแต่ละช่วง

### 4. สร้างแบบติดตามต้นทุนและผลผลิต
ทำตารางบันทึกต้นทุนแยกหมวด (พันธุ์, ปุ๋ย/อาหารสัตว์, แรงงาน, ค่าน้ำ-ไฟ, อื่นๆ) เทียบกับผลผลิตที่คาดการณ์และผลผลิตจริงเมื่อเก็บเกี่ยว/จับขาย เพื่อคำนวณต้นทุนต่อหน่วยผลผลิตในภายหลัง

### 5. ทำเช็คลิสต์เฝ้าระวังศัตรูพืช/โรคสัตว์เบื้องต้น
ระบุอาการผิดปกติที่ควรสังเกต (ใบเหลือง, แมลงศัตรูพืชระบาด, สัตว์ซึม ไม่กินอาหาร) พร้อมความถี่ในการตรวจ (เช่น เดินสำรวจแปลง/คอกทุก 2-3 วัน) แต่ **ไม่ระบุชื่อสารเคมีกำจัดศัตรูพืชหรือยาสัตว์และปริมาณการใช้ที่เจาะจง** ให้ระบุแทนว่าต้องปรึกษานักวิชาการเกษตรหรือสัตวแพทย์/ปศุสัตว์อำเภอก่อนใช้จริงเสมอ

### 6. สรุปแผนเป็นเอกสารที่ใช้งานจริงได้
รวมทุกส่วนเป็นเอกสารเดียว จัดรูปแบบให้อ่านง่าย พิมพ์ติดผนังหรือพกไปดูในแปลงได้

### 7. เตือนจุดที่ต้องตรวจสอบกับผู้เชี่ยวชาญ
สรุปรายการที่ต้องยืนยันกับเกษตรอำเภอ/นักวิชาการเกษตร/สัตวแพทย์ ก่อนลงมือจริง เช่น สูตรปุ๋ยเฉพาะดิน ปริมาณยาสัตว์ ราคาตลาดล่าสุด

## โครงสร้าง Output

```
=== แผนการผลิต [ชนิดพืช/สัตว์] ฤดูกาล/ปี [ระบุ] ===
พื้นที่/จำนวน: [ระบุ]
ที่ตั้ง: [ระบุจังหวัด/ภูมิภาค]

1) ปฏิทินการผลิต
   [ระยะ] [ช่วงเวลา] [กิจกรรมหลัก]
   เตรียมดิน/โรงเรือน: ...
   ปลูก/นำเข้าเลี้ยง: ...
   ดูแลระหว่างเติบโต: ...
   เก็บเกี่ยว/จับขาย: ...

2) ตารางปัจจัยการผลิต
   [สัปดาห์/เดือน] [ปัจจัย] [ปริมาณโดยประมาณ] [หมายเหตุ]

3) แบบติดตามต้นทุน-ผลผลิต
   [หมวดต้นทุน] [ประมาณการ] [ค่าจริง] [ส่วนต่าง]
   ผลผลิตคาดการณ์: [ระบุหน่วย]  ผลผลิตจริง: [กรอกภายหลัง]

4) เช็คลิสต์เฝ้าระวังศัตรูพืช/โรคสัตว์
   - [ ] จุดสังเกต: ...
   - [ ] ความถี่ตรวจ: ...
   - [ ] หากพบผิดปกติ: ปรึกษา [นักวิชาการเกษตร/สัตวแพทย์] ก่อนใช้สารเคมีหรือยาใดๆ

5) ประเด็นที่ต้องยืนยันกับผู้เชี่ยวชาญก่อนลงมือ
   - [...]
```

## ตัวอย่าง

**Input:** ชาวนาในจังหวัดสุพรรณบุรี ปลูกข้าวนาปี พื้นที่ 15 ไร่ เริ่มฤดูฝนนี้ อยากได้แผนตั้งแต่เตรียมดินถึงเก็บเกี่ยว

**Output (คร่าวๆ):**
- ปฏิทินการผลิต: เตรียมดิน (พ.ค.) → หว่าน/ดำนา (มิ.ย.) → ดูแล ใส่ปุ๋ยรองพื้นและปุ๋ยแต่งหน้า กำจัดวัชพืช (ก.ค.-ก.ย.) → เก็บเกี่ยว (พ.ย.-ธ.ค.)
- ตารางปัจจัยการผลิต: เมล็ดพันธุ์ข้าวจำนวนตามพื้นที่ 15 ไร่, ปุ๋ยรองพื้นช่วงหว่าน/ดำ, ปุ๋ยแต่งหน้าช่วงแตกกอ (ให้ตรวจสูตรและอัตราใส่กับเกษตรอำเภอตามผลตรวจดิน)
- เช็คลิสต์: เดินสำรวจแปลงทุก 3-4 วัน สังเกตใบเหลือง รอยกัดแทะ หากพบเพลี้ยหรือหนอนระบาด ให้ติดต่อเกษตรอำเภอเพื่อยืนยันชนิดสารและอัตราใช้ ห้ามผสมสารเองจากความจำ

## เกณฑ์คุณภาพ

- [ ] มีปฏิทินการผลิตครบทุกระยะ ตั้งแต่เตรียมจนถึงเก็บเกี่ยว/จับขาย
- [ ] ตารางปัจจัยการผลิตระบุช่วงเวลาชัดเจน อ่านแล้วนำไปปฏิบัติได้ทันที
- [ ] มีแบบติดตามต้นทุน-ผลผลิตที่กรอกข้อมูลจริงต่อได้
- [ ] มีเช็คลิสต์เฝ้าระวังศัตรูพืช/โรคสัตว์ที่ชัดเจนและปฏิบัติได้
- [ ] **ห้ามระบุชื่อสารเคมีกำจัดศัตรูพืช สูตรปุ๋ยเฉพาะ ปริมาณยาสัตว์ หรือราคาตลาดที่เจาะจงเอง** ให้ทำเครื่องหมายว่าต้องตรวจสอบกับนักวิชาการเกษตร สัตวแพทย์ หรือเกษตรอำเภอเสมอ
- [ ] ภาษาที่ใช้ตรงไปตรงมา ปฏิบัติได้จริงในพื้นที่การเกษตรของไทย
