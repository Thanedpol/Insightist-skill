# Quiz Generator

Skill นี้ช่วยครู วิทยากร และผู้ทำ e-learning สร้างแบบทดสอบที่มีคุณภาพจากเนื้อหาที่ผู้ใช้ให้มาโดยตรง (บทความ เอกสาร สไลด์ transcript) หรือจากหัวข้อวิชาที่ระบุ พร้อมเฉลยที่ถูกต้องและคำอธิบายเหตุผลของทุกข้อ เพื่อให้นำไปใช้วัดความเข้าใจของผู้เรียนได้ทันที ไม่ใช่แค่โยนคำถามสุ่มๆ ที่ไม่เชื่อมโยงกับเนื้อหาต้นฉบับ

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้แปะเนื้อหา บทความ หรือเอกสาร แล้วขอให้ "ทำแบบทดสอบ" หรือ "ออกคำถาม" จากเนื้อหานั้น
- ผู้ใช้ขอ "quiz", "ข้อสอบ", "แบบฝึกหัด" สำหรับหัวข้อวิชาที่ระบุมา
- ผู้ใช้เป็นครู/วิทยากรที่ต้องการวัดความเข้าใจผู้เรียนหลังจบบทเรียนหรือคอร์ส
- ผู้ใช้ทำ e-learning หรือ online course และต้องการ assessment ประกอบแต่ละบท
- ผู้ใช้ขอ "เฉลยพร้อมคำอธิบาย" ของคำถามที่มีอยู่แล้ว หรือขอให้ตรวจสอบว่าเฉลยที่ตนเขียนถูกต้องหรือไม่
- ผู้ใช้ต้องการแบบทดสอบก่อนเรียน (pre-test) เพื่อประเมินพื้นฐาน หรือหลังเรียน (post-test) เพื่อวัดผล

## ขั้นตอนการทำงาน

1. **ยืนยันแหล่งเนื้อหาและขอบเขต** — ตรวจสอบว่าเนื้อหาต้นฉบับคืออะไร (ข้อความที่ผู้ใช้แปะมา, เอกสารแนบ, หรือหัวข้อกว้างๆ ที่ต้องใช้ความรู้ทั่วไป) ถ้าเป็นหัวข้อกว้างไม่มีเนื้อหาอ้างอิง ให้แจ้งผู้ใช้ว่าจะยึดความรู้ทั่วไปที่เชื่อถือได้ในการออกโจทย์ และควรให้ผู้เชี่ยวชาญตรวจทานอีกครั้ง
2. **กำหนดสเปกของแบบทดสอบ** — สอบถามหรืออนุมาน: จำนวนข้อ, รูปแบบคำถาม (ปรนัย 4 ตัวเลือก, ถูก/ผิด, เติมคำ, อัตนัยสั้น), ระดับความยาก (ง่าย/ปานกลาง/ยาก หรือผสม), และวัตถุประสงค์ (pre-test/post-test/quiz ระหว่างเรียน)
3. **แตกเนื้อหาเป็นประเด็นย่อย** — อ่านเนื้อหาต้นฉบับแล้ว list ประเด็นสำคัญที่ควรถูกทดสอบ (concept, fact, ขั้นตอน, ความสัมพันธ์ระหว่างแนวคิด) กระจายคำถามให้ครอบคลุมเนื้อหาทั้งหมด ไม่กระจุกอยู่แค่ส่วนต้นของเอกสาร
4. **เขียนคำถามตามระดับความคิด** — ผสมระดับคำถามตาม Bloom's Taxonomy: จำ/เข้าใจ (recall), ประยุกต์ใช้ (application), วิเคราะห์/เปรียบเทียบ (analysis) ไม่ให้เป็นคำถามท่องจำล้วนทั้งชุด โดยเฉพาะแบบทดสอบระดับ intermediate ขึ้นไป
5. **ออกแบบตัวเลือกที่มีคุณภาพ (สำหรับปรนัย)** — ตัวลวง (distractor) ต้องสมเหตุสมผลและมาจากความเข้าใจผิดที่พบได้จริง ไม่ใช่ตัวเลือกที่ผิดชัดเจนจนตัดได้ทันที หลีกเลี่ยงตัวเลือกที่ยาว/สั้นผิดปกติจนเดาได้จากรูปแบบ
6. **เขียนเฉลยพร้อมคำอธิบายเหตุผล** — ทุกข้อต้องมีคำอธิบายว่าทำไมคำตอบนั้นถูก และถ้าเป็นปรนัย ควรอธิบายสั้นๆ ว่าทำไมตัวเลือกอื่นถึงผิด เพื่อให้ผู้เรียนเรียนรู้จากการทำผิดได้ด้วย
7. **ตรวจทานความถูกต้องกับเนื้อหาต้นฉบับ** — เทียบทุกข้อและเฉลยกลับกับเนื้อหาต้นฉบับอีกครั้งก่อนส่งมอบ เพื่อป้องกันคำถามที่ตีความผิดหรือเฉลยที่ขัดแย้งกับต้นฉบับ แล้วจัดรูปแบบตามโครงสร้าง Output ด้านล่าง

## โครงสร้าง Output

```
# แบบทดสอบ: [ชื่อเรื่อง/หัวข้อ]

**จำนวนข้อ:** [X] ข้อ
**รูปแบบ:** [ปรนัย/ถูกผิด/เติมคำ/ผสม]
**ระดับความยาก:** [ง่าย/ปานกลาง/ยาก/ผสม]
**อ้างอิงจาก:** [ระบุแหล่งเนื้อหา หรือ "ความรู้ทั่วไปในหัวข้อนี้"]

## ชุดคำถาม

**ข้อ 1.** [คำถาม]
   ก. [ตัวเลือก]
   ข. [ตัวเลือก]
   ค. [ตัวเลือก]
   ง. [ตัวเลือก]

**ข้อ 2.** [คำถาม]
...

## เฉลยและคำอธิบาย

**ข้อ 1.** เฉลย: [ตัวเลือกที่ถูก]
   คำอธิบาย: [เหตุผลว่าทำไมถูก และทำไมตัวเลือกอื่นผิด]

**ข้อ 2.** เฉลย: [ตัวเลือกที่ถูก]
   คำอธิบาย: [เหตุผล]
...

## สรุปการกระจายคำถาม (ถ้าต้องการ)
- ระดับจำ/เข้าใจ: [X] ข้อ
- ระดับประยุกต์ใช้: [X] ข้อ
- ระดับวิเคราะห์: [X] ข้อ
```

## รูปแบบคำถามที่รองรับ

- **ปรนัย (Multiple Choice)** — 4 ตัวเลือก เหมาะกับการวัดผลจำนวนมากและตรวจง่าย
- **ถูก/ผิด (True/False)** — เหมาะกับการเช็คความเข้าใจข้อเท็จจริงพื้นฐานอย่างรวดเร็ว ควรหลีกเลี่ยงการใช้มากเกินไปเพราะเดาถูกได้ง่าย
- **เติมคำ (Fill in the blank)** — เหมาะกับการวัดคำศัพท์เฉพาะหรือสูตร/ขั้นตอนที่ต้องจำแม่นยำ
- **อัตนัยสั้น (Short answer)** — เหมาะกับการวัดความเข้าใจเชิงอธิบายหรือการวิเคราะห์ ควรระบุ "แนวคำตอบที่ยอมรับได้" ในเฉลยแทนคำตอบตายตัวเดียว

## ข้อควรระวัง

- ถ้าเนื้อหาต้นฉบับสั้นเกินกว่าจะออกคำถามได้ตามจำนวนที่ขอ ให้แจ้งผู้ใช้ตรงๆ แทนการแต่งเนื้อหาที่ไม่มีในต้นฉบับขึ้นมาเอง
- ระวังคำถามที่ตอบได้จากสามัญสำนึกโดยไม่ต้องอ่านเนื้อหาเลย เพราะวัดความเข้าใจเนื้อหาจริงไม่ได้
- อย่าเฉลยผิดหรือเฉลยที่ขัดแย้งกับสิ่งที่เขียนไว้ในเนื้อหาต้นฉบับ — ต้องตรวจทานทุกครั้งก่อนส่งมอบ
- หากเนื้อหาต้นฉบับมีจุดที่คลุมเครือหรือตีความได้หลายทาง ให้หลีกเลี่ยงการออกคำถามจากจุดนั้น หรือระบุไว้ในคำอธิบายเฉลยว่ามีข้อควรพิจารณาเพิ่มเติม
- สำหรับแบบทดสอบก่อนเรียน (pre-test) ให้เน้นคำถามพื้นฐานเพื่อประเมินพื้นความรู้ ส่วนแบบทดสอบหลังเรียน (post-test) ควรมีคำถามระดับประยุกต์ใช้และวิเคราะห์มากขึ้นเพื่อวัดผลลัพธ์การเรียนรู้ที่แท้จริง

## ตัวอย่าง

**Input:** ผู้ใช้แปะบทความสั้นเกี่ยวกับ "วงจรน้ำ (Water Cycle)" แล้วขอ "ทำ quiz 5 ข้อ ปรนัย สำหรับนักเรียนมัธยมต้น"

**Output (คร่าวๆ):**
- ข้อ 1 (ระดับจำ): "กระบวนการที่น้ำระเหยจากผิวน้ำกลายเป็นไอน้ำเรียกว่าอะไร" — ก. การควบแน่น ข. การระเหย (ถูก) ค. การตกตะกอน ง. การซึมผ่าน — คำอธิบาย: การระเหย (Evaporation) คือการเปลี่ยนสถานะจากของเหลวเป็นไอด้วยความร้อน ส่วนการควบแน่นคือกระบวนการย้อนกลับ
- ข้อ 4 (ระดับประยุกต์ใช้): "ถ้าอุณหภูมิโลกสูงขึ้น จะส่งผลต่อวงจรน้ำอย่างไร" — ให้เลือกตอบที่เชื่อมโยงเหตุและผล ไม่ใช่แค่ท่องนิยาม
- จบด้วยเฉลยครบทุกข้อพร้อมคำอธิบาย และสรุปว่ามี 2 ข้อระดับจำ, 2 ข้อระดับประยุกต์ใช้, 1 ข้อระดับวิเคราะห์

## เกณฑ์คุณภาพ

- [ ] ทุกคำถามอ้างอิงได้กับเนื้อหาต้นฉบับหรือความรู้ที่ถูกต้องตามหลักวิชา ไม่มีข้อมูลผิดพลาด
- [ ] เฉลยทุกข้อถูกต้อง ตรวจทานไขว้กับเนื้อหาต้นฉบับแล้ว ไม่มีข้อขัดแย้งกันเอง
- [ ] มีคำอธิบายเหตุผลประกอบทุกข้อ ไม่ใช่แค่บอกเฉลยเปล่าๆ
- [ ] ตัวเลือกลวง (distractor) สมเหตุสมผล ไม่ใช่ตัวเลือกที่ผิดชัดจนเดาได้ทันที
- [ ] คำถามกระจายครอบคลุมเนื้อหาทั้งหมด ไม่กระจุกอยู่จุดใดจุดหนึ่ง และผสมระดับความคิดตามที่เหมาะกับกลุ่มเป้าหมาย
- [ ] ภาษาที่ใช้ในคำถามเหมาะสมกับระดับผู้เรียนที่ระบุ ไม่ใช้ศัพท์เทคนิคเกินระดับโดยไม่จำเป็น
