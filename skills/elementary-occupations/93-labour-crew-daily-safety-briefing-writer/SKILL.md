# Labour Crew Daily Safety Briefing Writer

Skill นี้ช่วยหัวหน้าทีม/หัวหน้ากะ เขียนสคริปต์พูดสั้นๆ (Safety Briefing / Toolbox Talk) ให้คนงานด้านเหมืองแร่ ก่อสร้าง การผลิต และการขนส่ง (ISCO-08 กลุ่ม 93 — Skill Level 1) ฟังก่อนเริ่มกะทุกวัน เนื้อหาเน้นอันตรายเฉพาะของวันนั้น อุปกรณ์ป้องกันที่ต้องใส่ และเบอร์ติดต่อฉุกเฉิน ใช้ภาษาพูดง่ายๆ อ่านออกเสียงได้ตรงไม่ต้องท่องจำ

## เมื่อไหร่ควรใช้ skill นี้

- หัวหน้าทีมกรรมกรก่อสร้างต้องการพูดเตือนอันตรายหน้างานก่อนเริ่มเทปูน/ยกของสูง
- หัวหน้ากะคนงานเหมืองต้องการแจ้งจุดเสี่ยงในเหมืองประจำวัน
- หัวหน้าไลน์คนงานโรงงานต้องการเตือนเครื่องจักรอันตรายก่อนเริ่มกะ
- หัวหน้าทีมคนแบกหาม/คนบรรจุหีบห่อ/คนงานคลังสินค้าต้องการเตือนวิธียกของถูกท่าและจุดเสี่ยงชนกัน
- หัวหน้าทีมคนเข็นของต้องการเตือนเส้นทางเสี่ยงและจุดที่มีรถวิ่งเข้า-ออก

## ขั้นตอนการทำงาน

### 1. ระบุงานหลักของวันนี้
สอบถามว่าวันนี้ทีมจะทำงานอะไรเป็นหลัก เช่น เทปูนชั้น 3, ขนของขึ้นรถบรรทุก, เดินเครื่องจักรตัวใหม่

### 2. ระบุอันตรายเฉพาะของงานวันนี้
เชื่อมงานหลักกับความเสี่ยงจริงในวันนั้น เช่น ทำงานที่สูง = เสี่ยงตกจากที่สูง, ยกของหนัก = เสี่ยงหลังเคล็ด, พื้นเปียกจากฝน = เสี่ยงลื่นล้ม ไม่ใช้คำเตือนทั่วไปที่ไม่เกี่ยวกับงานวันนั้น

### 3. ระบุอุปกรณ์ป้องกันส่วนบุคคล (PPE) ที่ต้องใส่วันนี้
บอกให้ชัดว่าต้องใส่อะไรบ้างสำหรับงานวันนี้ เช่น หมวกนิรภัย รองเท้าหัวเหล็ก ถุงมือ สายรัดนิรภัยเมื่อทำงานที่สูงเกิน 2 เมตร ที่อุดหูเมื่ออยู่ใกล้เครื่องจักรเสียงดัง

### 4. กำหนดจุดเสี่ยงในพื้นที่ทำงานวันนี้
ระบุจุดที่ต้องระวังเป็นพิเศษ เช่น ใกล้ปั้นจั่นกำลังยกของ, ทางรถวิ่งเข้า-ออกคลังสินค้า, พื้นที่ที่ยังไม่แห้งสนิท

### 5. ทบทวนขั้นตอนกรณีเกิดเหตุฉุกเฉิน
สรุปสั้นๆ ว่าถ้าเกิดอุบัติเหตุต้องทำอะไรก่อน เช่น หยุดเครื่องจักรทันที แจ้งหัวหน้ากะ โทรเบอร์ฉุกเฉิน และจุดปฐมพยาบาลอยู่ที่ไหน

### 6. ระบุเบอร์ติดต่อฉุกเฉิน
ใส่เบอร์หัวหน้ากะ เบอร์เจ้าหน้าที่ความปลอดภัย (ถ้ามี) และเบอร์ 1669 สำหรับเหตุฉุกเฉินทางการแพทย์

### 7. เขียนเป็นสคริปต์พูดสั้น ไม่เกิน 2-3 นาที
เรียบเรียงทุกข้อเป็นประโยคพูดสั้นๆ ต่อเนื่องกัน ให้หัวหน้ากะอ่านออกเสียงหน้าแถวก่อนเริ่มงานได้เลยโดยไม่ต้องท่อง

## โครงสร้าง Output

```
=== สคริปต์ Safety Briefing ประจำวัน [ชื่อไซต์/ทีม] ===
วันที่: [ระบุ]  งานหลักวันนี้: [ระบุ]  ผู้พูด: [ระบุหัวหน้ากะ]

[เปิดบท] "สวัสดีทุกคน วันนี้เรามีงาน [งานหลัก] ก่อนเริ่มงานขอทบทวนความปลอดภัยสั้นๆ..."

1) อันตรายของวันนี้
   - [อันตรายที่ 1] เพราะ [เหตุผลที่เกี่ยวกับงานวันนี้]
   - [อันตรายที่ 2]

2) อุปกรณ์ป้องกันที่ต้องใส่วันนี้
   - [ ] [PPE 1]
   - [ ] [PPE 2]

3) จุดเสี่ยงในพื้นที่วันนี้
   - [จุดเสี่ยง]: [สิ่งที่ต้องทำ]

4) ถ้าเกิดเหตุฉุกเฉิน
   - ขั้นตอนแรก: [ระบุ]
   - เบอร์ติดต่อฉุกเฉิน: หัวหน้ากะ [เบอร์], เจ้าหน้าที่ความปลอดภัย [เบอร์], 1669

[ปิดบท] "ถ้าใครไม่แน่ใจจุดไหนให้ถามก่อนเริ่มงาน ทำงานปลอดภัยกันทุกคนนะครับ/ค่ะ"
```

## ตัวอย่าง

**Input:** ทีมก่อสร้างวันนี้จะเทปูนพื้นชั้น 3 มีปั้นจั่นยกวัสดุขึ้น-ลงตลอดวัน

**Output (คร่าวๆ):**
- อันตรายวันนี้: ทำงานที่สูงเสี่ยงตก, ปั้นจั่นยกของเสี่ยงของหล่นทับ
- PPE ที่ต้องใส่: หมวกนิรภัย รองเท้าหัวเหล็ก สายรัดนิรภัยเมื่ออยู่ใกล้ขอบพื้นที่ยังไม่มีราวกัน
- จุดเสี่ยง: ใต้แนวปั้นจั่นห้ามยืนหรือเดินผ่านขณะกำลังยกของ
- ฉุกเฉิน: พบเหตุแจ้งหัวหน้ากะทันที เบอร์ 08X-XXX-XXXX, เหตุร้ายแรงโทร 1669

## เกณฑ์คุณภาพ

- [ ] อันตรายที่ระบุเชื่อมโยงกับงานจริงของวันนั้น ไม่ใช่คำเตือนทั่วไปที่ใช้ซ้ำทุกวันโดยไม่เปลี่ยน
- [ ] ระบุ PPE ที่ต้องใส่ชัดเจนตามลักษณะงานวันนั้น
- [ ] มีขั้นตอนกรณีฉุกเฉินและเบอร์ติดต่อครบถ้วน รวมเบอร์ 1669
- [ ] สคริปต์สั้น พูดจบภายใน 2-3 นาที ไม่ยาวจนคนงานฟังไม่ครบ
- [ ] ภาษาที่ใช้เป็นภาษาพูด อ่านออกเสียงหน้าแถวได้ทันทีโดยไม่ต้องแก้คำ
- [ ] ไม่กำหนดมาตรฐานความปลอดภัยหรือกฎหมายเฉพาะทางแทนเจ้าหน้าที่ความปลอดภัยในงาน (จป.) ให้ระบุว่าควรตรวจสอบกับ จป. ประจำไซต์เมื่อไม่แน่ใจ
