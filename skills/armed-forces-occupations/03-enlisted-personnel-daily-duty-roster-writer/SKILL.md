# Enlisted Personnel Daily Duty Roster Writer

Skill นี้ช่วยจัดทำตารางเวรประจำวัน (daily duty roster) และตารางกิจวัตรประจำกองพัก/หน่วยสำหรับพลทหาร เพื่อให้การจัดเวร การหมุนเวียนหน้าที่ และตารางเวลาประจำวันเป็นระบบ ยุติธรรม ตรวจสอบได้ และสื่อสารให้กำลังพลทุกคนเข้าใจตรงกัน

## เมื่อไหร่ควรใช้ skill นี้

- ผู้ใช้ต้องการจัดตารางเวรประจำวันสำหรับพลทหารเกณฑ์หรือพลทหารอาสาสมัคร เช่น เวรรักษาการณ์ทั่วไป เวรทำความสะอาด เวรครัว
- ต้องการตารางกิจวัตรประจำวันของกองพัก เช่น เวลาปลุก เวลาออกกำลังกาย เวลาอาหาร เวลาเข้านอน
- ต้องการหมุนเวียนหน้าที่เวรอย่างเป็นธรรมและมีบันทึกประวัติการเข้าเวรของแต่ละนาย
- ต้องการแบบฟอร์มรายงานสรุปเวรประจำวันส่งให้ผู้บังคับหมวด/หมู่รับทราบ
- **ข้อควรทราบ:** skill นี้จำกัดเฉพาะงานจัดตารางเวรและกิจวัตรประจำวันเชิงธุรการเท่านั้น ไม่เกี่ยวข้องกับการวางกำลังเชิงยุทธวิธี ไม่มีข้อมูลลับ หรือข้อมูลความมั่นคงที่ละเอียดอ่อนใดๆ

## ขั้นตอนการทำงาน

### 1. รวบรวมข้อมูลพื้นฐาน
สอบถาม: ชื่อหน่วย/กองพักแบบทั่วไป, รายชื่อพลทหารที่อยู่ในผลัดเวร, ประเภทเวรที่ต้องจัด (เช่น เวรรักษาการณ์ทั่วไป เวรทำความสะอาด เวรครัว), จำนวนคนต่อผลัดเวร

### 2. กำหนดประเภทและช่วงเวลาของแต่ละเวร
ระบุเวรแต่ละประเภทพร้อมช่วงเวลาที่ชัดเจน (เช่น เวรกลางวัน 08:00-16:00 น., เวรกลางคืน 16:00-24:00 น., เวรดึก 00:00-08:00 น.)

### 3. จัดสรรรายชื่อลงตารางเวรแบบหมุนเวียน
กระจายชื่อพลทหารลงแต่ละผลัดเวรอย่างเป็นธรรม หมุนเวียนไม่ให้คนใดคนหนึ่งเข้าเวรถี่เกินไป และเว้นวันพักที่เหมาะสม

### 4. จัดทำตารางกิจวัตรประจำวันของกองพัก
ระบุเวลากิจกรรมประจำวันตามปกติ เช่น เวลาปลุก เวลาออกกำลังกาย เวลาอาหารเช้า/กลางวัน/เย็น เวลาทำความสะอาด เวลาเข้านอน

### 5. จัดทำแบบบันทึกการเข้าเวร (Duty Log)
สร้างช่องให้ผู้เข้าเวรลงชื่อ/เวลาเริ่ม-เลิกเวร และช่องสำหรับส่งมอบเวรถัดไป

### 6. สรุปรายงานเวรประจำวันส่งผู้บังคับหมวด/หมู่
รวบรวมข้อมูลว่าใครเข้าเวรอะไร ช่วงเวลาใด มีการขาด/สลับเวรหรือไม่ พร้อมเหตุผลแบบธุรการ

### 7. ตรวจทานความเป็นธรรมและความครบถ้วนของตาราง
ตรวจสอบว่าไม่มีชื่อซ้ำเวรในเวลาเดียวกัน การหมุนเวียนเป็นธรรม และตารางครอบคลุมทุกวันในช่วงที่กำหนด

```

| ประเภทเวร        | ช่วงเวลา          | ผู้ปฏิบัติเวร      | หมายเหตุ |
|--------------------|--------------------|---------------------|----------|
| เวรรักษาการณ์      | [เวลาเริ่ม-สิ้นสุด] | [ยศ ชื่อ]           | -        |
| เวรทำความสะอาด     | [เวลาเริ่ม-สิ้นสุด] | [ยศ ชื่อ]           | -        |
| เวรครัว             | [เวลาเริ่ม-สิ้นสุด] | [ยศ ชื่อ]           | -        |

ตารางกิจวัตรประจำวันกองพัก
| เวลา        | กิจกรรม            |
|-------------|---------------------|
| [เวลา]      | [กิจกรรมประจำวัน]  |

บันทึกการเข้าเวร (Duty Log)
| ผู้เข้าเวร | เวลาเริ่มเวร | เวลาเลิกเวร | ผู้รับมอบเวรต่อ | หมายเหตุ |

```

## ตัวอย่าง

**Input:** หมู่ปืนเล็กสมมติมีพลทหาร 12 นาย ต้องจัดเวรรักษาการณ์ทั่วไปหน้าหมวดพัก 3 ผลัดต่อวัน (เช้า/บ่าย/ดึก) พร้อมตารางกิจวัตรกองพัก

**Output (ตัวอย่างบางส่วน):**
```
| ประเภทเวร     | ช่วงเวลา       | ผู้ปฏิบัติเวร      | หมายเหตุ |
|-----------------|------------------|---------------------|----------|
| เวรรักษาการณ์  | 08:00-16:00 น.  | พลฯ สมชาย ใจดี    | -        |
| เวรรักษาการณ์  | 16:00-24:00 น.  | พลฯ วิชัย มั่นคง  | -        |
| เวรรักษาการณ์  | 00:00-08:00 น.  | พลฯ ประยุทธ์ แกร่งกล้า | -   |

ตารางกิจวัตรประจำวันกองพัก
| เวลา       | กิจกรรม              |
|-------------|-----------------------|
| 05:30 น.    | ปลุก/เข้าแถวเช้า      |
| 06:00 น.    | ออกกำลังกาย           |
| 07:00 น.    | อาหารเช้า             |
| 21:00 น.    | เข้านอน               |
```

## เกณฑ์คุณภาพ

- [ ] ตารางเวรครอบคลุมทุกผลัดในแต่ละวัน ไม่มีช่วงเวลาว่างหรือซ้อนทับ
- [ ] การหมุนเวียนรายชื่อเป็นธรรม ไม่มีผู้ใดเข้าเวรถี่เกินสมควรโดยไม่มีเหตุผล
- [ ] ตารางกิจวัตรประจำวันระบุเวลาและกิจกรรมชัดเจน ครบตั้งแต่ตื่นถึงเข้านอน
- [ ] มีแบบบันทึกการเข้าเวรที่ตรวจสอบย้อนหลังได้
- [ ] ต้องไม่มีเนื้อหาเชิงยุทธวิธี ข้อมูลลับ หรือข้อมูลความมั่นคงที่ละเอียดอ่อน — จำกัดเฉพาะงานเอกสารธุรการ/บริหารจัดการกำลังพลทั่วไปเท่านั้น
- [ ] ใช้ชื่อหน่วยและบุคคลแบบทั่วไป/สมมติ ไม่ระบุข้อมูลระบุตัวตนจริงที่ละเอียดอ่อน
