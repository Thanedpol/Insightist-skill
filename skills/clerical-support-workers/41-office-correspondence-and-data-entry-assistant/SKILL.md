# Office Correspondence and Data Entry Assistant

Skill นี้ช่วยงานสองด้านที่เสมียนสำนักงานต้องทำเป็นประจำ คือการร่างหนังสือโต้ตอบภายในและภายนอกองค์กรให้ถูกรูปแบบและมืออาชีพ และการจัดระเบียบ/ตรวจสอบชุดข้อมูลก่อนนำเข้าสู่ระบบ เพื่อลดความผิดพลาดจากการคีย์ข้อมูลซ้ำ ข้อมูลไม่ครบ หรือรูปแบบไม่ตรงกัน เหมาะสำหรับงานเอกสารประจำวันที่ต้องรวดเร็วแต่ยังต้องแม่นยำ

## เมื่อไหร่ควรใช้ skill นี้

- เสมียนสำนักงานต้องร่างบันทึกข้อความ หนังสือเวียน หรือจดหมายโต้ตอบหน่วยงานภายนอก
- เลขานุการต้องเตรียมจดหมายนัดหมาย สรุปการประชุมสั้นๆ หรือหนังสือตอบรับ/ปฏิเสธ
- พนักงานคีย์ข้อมูลได้รับไฟล์ดิบ (เช่น จากแบบฟอร์มกระดาษหรือสแกน) แล้วต้องคีย์เข้าระบบให้ถูกต้องและสอดคล้องกัน
- พนักงานพิมพ์ดีด/ถอดเทปต้องแปลงข้อความที่เขียนด้วยลายมือหรือไฟล์เสียงสั้นๆ ให้เป็นเอกสารพิมพ์ที่จัดรูปแบบเรียบร้อย
- ต้องการเช็คลิสต์เพื่อตรวจสอบว่าข้อมูลชุดหนึ่งพร้อมนำเข้าระบบหรือยัง ก่อนส่งต่อให้ฝ่ายอื่น

## ขั้นตอนการทำงาน

### 1. ระบุประเภทงานและผู้รับสาร
แยกก่อนว่าเป็นงาน "ร่างหนังสือ" หรือ "จัดการข้อมูล" เพราะขั้นตอนถัดไปต่างกัน สำหรับหนังสือ ให้สอบถาม/ระบุ: ผู้รับ, วัตถุประสงค์ (แจ้ง/ขอ/ตอบรับ/ปฏิเสธ/เชิญ), ระดับความเป็นทางการ (ราชการ/ธุรกิจ/ภายใน)

### 2. ร่างหนังสือโต้ตอบตามรูปแบบมาตรฐาน
- ใช้โครงสร้างมาตรฐานไทย: ที่/เลขที่หนังสือ, วันที่, เรื่อง, เรียน, เนื้อหา (อ้างถึง–เหตุผล–ขอ/แจ้ง), ลงท้ายแบบสุภาพ, ผู้ลงนาม
- เนื้อหาต้องกระชับ ตรงประเด็น หลีกเลี่ยงคำฟุ่มเฟือย และใช้ภาษาที่เหมาะกับระดับความเป็นทางการที่ระบุไว้
- ถ้าเป็นอีเมลหรือบันทึกภายใน ให้ปรับให้สั้นลงและเป็นกันเองขึ้นตามบริบทองค์กร

### 3. ตรวจทานหนังสือก่อนส่ง
- ตรวจการสะกดคำ ชื่อบุคคล ชื่อหน่วยงาน และตัวเลข (วันที่ เลขที่ จำนวนเงิน) ให้ตรงกับต้นฉบับที่ผู้ใช้ให้มา
- ตรวจว่าน้ำเสียงเหมาะสมกับผู้รับ ไม่ก้าวร้าวหรือเป็นทางการเกินความจำเป็น

### 4. รับและสำรวจชุดข้อมูลดิบ (สำหรับงานคีย์ข้อมูล)
- ดูโครงสร้างคอลัมน์/ฟิลด์ที่มีอยู่ เทียบกับฟิลด์ที่ระบบปลายทางต้องการ
- สังเกตรูปแบบที่ไม่สม่ำเสมอ เช่น วันที่เขียนหลายแบบ, ชื่อบริษัทสะกดต่างกัน, ช่องว่างเกิน, ตัวเลขปนตัวอักษร

### 5. สร้างเช็คลิสต์ความสอดคล้องของข้อมูล
- ฟิลด์บังคับครบทุกแถวหรือไม่ (ไม่มีค่าว่างในฟิลด์ที่จำเป็น)
- รูปแบบวันที่/ตัวเลข/สกุลเงินสอดคล้องกันทั้งไฟล์
- ไม่มีแถวซ้ำ (duplicate) โดยไม่ได้ตั้งใจ
- ค่าที่ควรอยู่ในชุดตัวเลือกจำกัด (เช่น สถานะ, ประเภท) ไม่มีคำสะกดผิดหรือรูปแบบแปลกปลอม
- ความยาว/รูปแบบของรหัส (เลขบัตร, รหัสลูกค้า) ตรงตามมาตรฐานที่กำหนด

### 6. จัดระเบียบและทำความสะอาดข้อมูล
- แก้ไขเฉพาะรูปแบบ (format) ให้สอดคล้องกัน เช่น วันที่เป็น พ.ศ. หรือ ค.ศ. แบบเดียวกันทั้งไฟล์
- **ห้ามเดา ห้ามเติม หรือห้ามแก้ไขค่าข้อมูลจริงที่ผู้ใช้ไม่ได้ให้มา** — ถ้าข้อมูลขาดหรือดูผิดปกติ ให้ทำเครื่องหมายไว้ให้ผู้ใช้ตรวจสอบเอง ไม่ใช่เติมค่าขึ้นเอง
- จัดเรียงคอลัมน์ให้ตรงกับฟิลด์ปลายทางก่อนส่งมอบ

### 7. สรุปรายงานก่อนส่งมอบ
- แจ้งจำนวนแถวที่ตรวจแล้ว, จำนวนรายการที่พบปัญหาและต้องให้ผู้ใช้ยืนยัน, และจำนวนรายการที่พร้อมนำเข้าระบบ

## โครงสร้าง Output

```
=== [หนังสือโต้ตอบ] หรือ [รายงานตรวจสอบข้อมูล] ===

--- กรณีร่างหนังสือ ---
ที่ [เลขที่/วันที่]
เรื่อง: [หัวเรื่อง]
เรียน: [ผู้รับ]

[เนื้อหาหนังสือ ย่อหน้า 1: อ้างถึง/เหตุผล]
[เนื้อหาหนังสือ ย่อหน้า 2: ข้อความหลักที่ต้องการสื่อสาร]
[คำลงท้าย]

ลงชื่อ: [ผู้ลงนาม/ตำแหน่ง]

--- กรณีตรวจสอบข้อมูล ---
จำนวนแถวทั้งหมด: [n]
รายการที่ข้อมูลไม่ครบ: [รายการ + เลขแถว]
รายการที่รูปแบบไม่สอดคล้อง: [รายการ + เลขแถว]
รายการที่สงสัยว่าซ้ำ: [รายการ + เลขแถว]
สรุป: พร้อมนำเข้าระบบ [n] แถว / ต้องตรวจสอบเพิ่ม [n] แถว
```

## ตัวอย่าง

**Input:** "ช่วยร่างบันทึกข้อความแจ้งเปลี่ยนเวลาประชุมทีมจากบ่ายโมงเป็นบ่ายสามโมง วันพฤหัสนี้"

**Output (คร่าวๆ):**
```
บันทึกข้อความ
เรื่อง: ขอแจ้งเปลี่ยนแปลงเวลาประชุมทีม
เรียน: ทีมงานทุกท่าน

ตามที่ได้นัดหมายประชุมทีมในวันพฤหัสบดีนี้ เวลา 13.00 น. นั้น
เนื่องจากมีความจำเป็นต้องปรับตารางงาน จึงขอแจ้งเปลี่ยนเวลาประชุมเป็น 15.00 น.
ในวันและสถานที่เดิม จึงเรียนมาเพื่อโปรดทราบและปรับตารางงานของท่าน

ขอบคุณค่ะ/ครับ
[ชื่อผู้ส่ง]
```

## เกณฑ์คุณภาพ

- [ ] หนังสือที่ร่างใช้โครงสร้างและระดับภาษาที่ตรงกับผู้รับและวัตถุประสงค์
- [ ] ตรวจตัวเลข ชื่อบุคคล และวันที่ในหนังสือให้ตรงกับข้อมูลต้นฉบับทุกจุด
- [ ] เช็คลิสต์ข้อมูลครอบคลุมทั้งความครบถ้วน รูปแบบ และรายการซ้ำ
- [ ] ไม่แก้ไขหรือเดาค่าข้อมูลจริงที่ผู้ใช้ไม่ได้ให้มา รวมถึงไม่เติมตัวเลขหรือข้อความที่ไม่มีต้นทาง
- [ ] รายงานสรุปแยกชัดเจนระหว่างรายการที่พร้อมใช้งานกับรายการที่ต้องให้ผู้ใช้ยืนยันเพิ่ม
- [ ] ภาษาที่ใช้กระชับ ไม่ฟุ่มเฟือย เหมาะกับงานเอกสารสำนักงานจริง
